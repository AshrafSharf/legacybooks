Turning equations into pictures — plotting points, drawing lines, and reading the stories graphs tell

1. Ordered Pairs and the Coordinate Plane

Every point on a flat surface can be described by two numbers — its coordinates. We write them as an ordered pair \((x,\,y)\), where the first number tells us the horizontal position and the second number tells us the vertical position.

Definition — Ordered Pair

An ordered pair \((x,\,y)\) gives the location of a point. The first component \(x\) (called the abscissa) is the horizontal distance from the origin; the second component \(y\) (called the ordinate) is the vertical distance from the origin.

The Rectangular Coordinate System

The Cartesian coordinate system (named after René Descartes) is formed by placing two perpendicular number lines so that their zero points coincide at the origin \(O\).

  • The horizontal line is the \(x\)-axis.
  • The vertical line is the \(y\)-axis.
  • Together the axes divide the plane into four quadrants, numbered I–IV counterclockwise from the upper right.
Key Insight — Reading Coordinates

Always read \(x\) first, then \(y\). Start at the origin: move right (positive) or left (negative) for the \(x\)-value, then up (positive) or down (negative) for the \(y\)-value. The order matters — \((2,\,5)\) and \((5,\,2)\) are entirely different points!

2. Functions

When two variables are linked by a rule so that each value of \(x\) produces exactly one value of \(y\), we call the rule a function.

Definition — Function

A function is a relation in which every first component (input) has exactly one second component (output). We write \(y = f(x)\), read “\(y\) equals \(f\) of \(x\)”.

  • Independent variable (\(x\)) — the input; we freely choose its values.
  • Dependent variable (\(y\)) — the output; its value depends on \(x\).
  • Domain — the set of all allowable \(x\)-values.
  • Range — the set of all resulting \(y\)-values.
Example — Generating Ordered Pairs

For the function \(y = 2x\), each value of \(x\) produces a unique \(y\):

\(x\)\(y = 2x\)Ordered pair
\(-2\)\(-4\)\((-2,\,-4)\)
\(0\)\(0\)\((0,\,0)\)
\(1\)\(2\)\((1,\,2)\)
\(3\)\(6\)\((3,\,6)\)

Because every \(x\) gives exactly one \(y\), this relation is indeed a function.

3. Linear Functions and Slope

A linear equation in two variables is one where both variables have exponent 1 and there are no products of variables. When graphed, it always produces a straight line.

Formula — Slope-Intercept Form

The most common form of a linear equation is:

$$y = mx + b$$
  • \(m\) = slope (steepness of the line)
  • \(b\) = \(y\)-intercept (where the line crosses the \(y\)-axis)

Slope: Rise over Run

The slope of a line measures how steeply it rises or falls. Given two points \((x_1,\,y_1)\) and \((x_2,\,y_2)\):

Formula — Slope
$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\text{rise}}{\text{run}}$$

Graph of \(y = 2x + 1\) with Slope Triangle

Key Insight — What Slope Tells You

Slope is the rate of change. A slope of \(m = 2\) means that for every 1 unit you move to the right, the line rises 2 units. Think of it as “rise over run” — the vertical change divided by the horizontal change.

4. Intercepts and Graphing Linear Equations

The intercepts are the points where a line crosses the axes — they give you two easy points for drawing the graph.

Formula — Finding Intercepts
  • \(x\)-intercept: Set \(y = 0\) and solve for \(x\). The point is \((x,\;0)\).
  • \(y\)-intercept: Set \(x = 0\) and solve for \(y\). The point is \((0,\;y)\).
Example — Intercepts of \(4x - 2y = 8\)

\(x\)-intercept (set \(y = 0\)):

$$4x - 0 = 8 \;\;\Longrightarrow\;\; x = 2 \quad\Rightarrow\quad (2,\;0)$$

\(y\)-intercept (set \(x = 0\)):

$$0 - 2y = 8 \;\;\Longrightarrow\;\; y = -4 \quad\Rightarrow\quad (0,\;-4)$$

Two Methods for Graphing

Method 1 — Intercept method: Find the \(x\)- and \(y\)-intercepts, plot them, connect with a straight line, and check with a third point.

Method 2 — Slope-intercept method: Write the equation as \(y = mx + b\). Plot the \(y\)-intercept \((0,\,b)\). From that point, use the slope “rise over run” to locate a second point. Draw the line.

Common Mistake

Always find at least three points when graphing. Two points determine a line, but the third point checks your work. If all three are not collinear, you have an arithmetic error somewhere!

5. Parallel and Perpendicular Lines

The slope of a line tells you not only how steep it is but also how it relates to other lines.

Rules — Parallel & Perpendicular

Parallel lines have the same slope:

$$m_1 = m_2$$

Perpendicular lines have slopes that are negative reciprocals:

$$m_1 \cdot m_2 = -1 \qquad\text{or equivalently}\qquad m_2 = -\frac{1}{m_1}$$
Example — Parallel Lines

The lines \(y = 2x + 1\) and \(y = 2x - 3\) both have slope \(m = 2\).

Since \(m_1 = m_2 = 2\), the lines are parallel — they will never intersect.

Example — Perpendicular Lines

Line A has slope \(m_1 = 3\). Line B has slope \(m_2 = -\tfrac{1}{3}\).

Check: \(3 \times \bigl(-\tfrac{1}{3}\bigr) = -1\). The lines are perpendicular.

6. Systems of Linear Equations

A single linear equation in two unknowns has infinitely many solutions (every point on the line). To find a unique solution, you need two equations — a system.

Graphical Solution

Graph both equations on the same coordinate plane. The point of intersection is the solution — it is the one ordered pair that satisfies both equations simultaneously.

The system \(2x - y = 5\) and \(x + y = 7\) has the unique solution \((4,\,3)\). We can verify: \(2(4) - 3 = 5\) and \(4 + 3 = 7\). Both check out.

Three Possible Outcomes

CaseGraphSolution
Consistent (independent)Lines intersect at one pointExactly one solution
InconsistentLines are parallel (same slope, different intercept)No solution
DependentLines are identical (same equation)Infinitely many solutions

Algebraic Methods

Elimination

Add or subtract equations to cancel one variable, then solve for the other.

Substitution

Solve one equation for one variable, then substitute that expression into the other equation.

Key Insight — Why Both Methods?

Graphing gives you a visual picture and is great for understanding. Algebraic methods (elimination and substitution) give you exact answers without the imprecision of reading a graph. Master both!

7. A Glimpse Beyond: Nonlinear Functions

Not every equation produces a straight line. When the exponent of a variable is greater than 1, the graph curves. The simplest example is the parabola \(y = x^2\).

Notice that the parabola is symmetric about the \(y\)-axis — the point \((-2,\,4)\) mirrors \((2,\,4)\). This is because \((-x)^2 = x^2\). We will study quadratic equations in depth in Chapter 9.

Summary of Key Rules

Rule 1

The graph of a first-degree (linear) equation is always a straight line.

Rule 2

If a point lies on the graph of an equation, its coordinates satisfy the equation (make it a true statement).

Rule 3

Conversely, the coordinates of a point not on the graph do not satisfy the equation.

Rule 4

The graph of a first-degree equation in one unknown is a line that lies on an axis or is parallel to an axis (e.g., \(x = 3\) is a vertical line; \(y = -2\) is a horizontal line).

Worked Problems

Problem 1 — Plotting Points

Plot the points \(A(2,\,3)\), \(B(-1,\,4)\), \(C(-3,\,-2)\), and \(D(0,\,5)\) on a coordinate plane. Identify which quadrant each point lies in.

Solution
1Draw the \(x\)- and \(y\)-axes and mark a scale.
2\(A(2,\,3)\): Move 2 right, 3 up — Quadrant I.
3\(B(-1,\,4)\): Move 1 left, 4 up — Quadrant II.
4\(C(-3,\,-2)\): Move 3 left, 2 down — Quadrant III.
5\(D(0,\,5)\): \(x = 0\), so the point lies on the \(y\)-axis (not in any quadrant).

See the coordinate plane diagram in Section 1 above for the plot.

Problem 2 — Finding Slope

Find the slope of the line passing through \((1,\,2)\) and \((4,\,8)\).

Solution

Apply the slope formula with \((x_1,\,y_1) = (1,\,2)\) and \((x_2,\,y_2) = (4,\,8)\):

$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{8 - 2}{4 - 1} = \frac{6}{3} = 2$$

The slope is \(m = 2\). This means the line rises 2 units for every 1 unit it moves to the right.

Problem 3 — Graphing a Line

Graph \(y = -x + 3\). Identify the slope and \(y\)-intercept.

Solution

The equation is already in slope-intercept form \(y = mx + b\):

1Slope: \(m = -1\). The line falls 1 unit for each unit to the right.
2\(y\)-intercept: \(b = 3\), giving the point \((0,\,3)\).
3From \((0,\,3)\), move right 1 and down 1 to get \((1,\,2)\).
4Check point: when \(x = 3\), \(y = -3 + 3 = 0\), giving \((3,\,0)\) — the \(x\)-intercept.

All three points — \((0,\,3)\), \((1,\,2)\), and \((3,\,0)\) — lie on the same straight line.

Problem 4 — Finding an Equation

Find the equation of the line that passes through \((2,\,5)\) with slope \(m = 3\).

Solution

Use the point-slope form and convert to slope-intercept form:

1Start with \(y = mx + b\) and substitute \(m = 3\), \(x = 2\), \(y = 5\):
$$5 = 3(2) + b$$ $$5 = 6 + b$$ $$b = -1$$
2Write the equation:
$$\boxed{y = 3x - 1}$$

Check: At \(x = 2\): \(y = 3(2) - 1 = 5\). Correct!

Problem 5 — Finding Intercepts

Find the \(x\)- and \(y\)-intercepts of \(2x + 3y = 6\).

Solution

\(x\)-intercept (set \(y = 0\)):

$$2x + 3(0) = 6 \;\;\Longrightarrow\;\; 2x = 6 \;\;\Longrightarrow\;\; x = 3$$

So the \(x\)-intercept is \((3,\;0)\).

\(y\)-intercept (set \(x = 0\)):

$$2(0) + 3y = 6 \;\;\Longrightarrow\;\; 3y = 6 \;\;\Longrightarrow\;\; y = 2$$

So the \(y\)-intercept is \((0,\;2)\).

Problem 6 — Parallel Lines

Are the lines \(y = 2x + 1\) and \(y = 2x - 3\) parallel?

Solution
1Identify slopes: Line 1 has \(m_1 = 2\). Line 2 has \(m_2 = 2\).
2Since \(m_1 = m_2 = 2\), the lines have the same slope.
3The \(y\)-intercepts differ (\(b_1 = 1 \neq -3 = b_2\)), so they are not the same line.

Conclusion: Yes, the lines are parallel. They will never intersect, forming an inconsistent system if treated as simultaneous equations.
