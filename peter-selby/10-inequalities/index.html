Inequalities

When expressions aren't equal — comparing, solving, and graphing relationships of order

What You'll Learn

Equations tell us when two expressions are equal. But mathematics often demands we describe when one quantity is greater than or less than another. Inequalities give us the language and tools to do exactly that.

◆ Apply the three key properties of inequalities

1. Inequality Symbols

An inequality is a statement that one expression is greater than or less than another. We use five fundamental symbols to express these relationships:

< Less than
> Greater than
≤ Less than or equal
≥ Greater than or equal
≠ Not equal to
Key Insight

The vertex (point) of the inequality symbol always points toward the smaller quantity. Think of the symbol as a hungry alligator that always wants to eat the bigger number! For example, \(3 < 7\) and \(7 > 3\) say exactly the same thing.

Reading Inequalities on the Number Line

On a horizontal number line, any number to the right of another is the greater of the two. So \(+4 > +1\), and \(+2 > -6\), and \(-1 > -5\).

Definition — Greater Than and Less Than

For any two real numbers \(a\) and \(b\):

  • \(a > b\) means \(a - b\) is positive
  • \(a < b\) means \(a - b\) is negative
  • \(a = b\) means \(a - b\) is zero

This is the trichotomy principle: for any two real numbers, exactly one of \(a > b\), \(a = b\), or \(a < b\) is true.

2. Properties of Inequalities

Inequalities follow rules similar to equations — with one crucial exception when you multiply or divide by a negative number.

Property 1 — Addition / Subtraction

The sense of an inequality is unchanged if the same number is added to or subtracted from both sides.

$$\text{If } a > b, \text{ then } a + c > b + c \text{ for any number } c$$

Example: Since \(4 > 3\), we know \(4 + 2 > 3 + 2\), i.e., \(6 > 5\). ✓

Property 2 — Multiplication / Division by a Positive Number

The sense of an inequality is unchanged if both sides are multiplied or divided by the same positive number.

$$\text{If } a > b \text{ and } c > 0, \text{ then } ac > bc$$

Example: Since \(4 > 3\), we know \(4 \times 2 > 3 \times 2\), i.e., \(8 > 6\). ✓

Property 3 — Multiplication / Division by a Negative Number

The sense of an inequality is REVERSED if both sides are multiplied or divided by the same negative number.

$$\text{If } a > b \text{ and } c < 0, \text{ then } ac \mathbin{\color{#9b2c2c}{<}} bc$$

Example: Since \(4 > 3\), multiplying both sides by \(-1\) gives \(-4 < -3\). The sign flips!

Why? Multiplying by a negative number reflects values across zero on the number line, reversing their order.

Key Insight — The #1 Mistake

Forgetting to flip the inequality sign when multiplying or dividing by a negative number is the most common error students make. Every time you multiply or divide both sides, ask yourself: "Is this number negative?" If yes, reverse the sign.

3. Solving Linear Inequalities

Solving an inequality works just like solving an equation — isolate the variable on one side. The only difference: flip the inequality sign whenever you multiply or divide by a negative.

Example — Solving Step by Step

Solve: \(6x - 4 > 3x + 2\)

1Subtract \(3x\) from both sides:   \(3x - 4 > 2\)
2Add \(4\) to both sides:   \(3x > 6\)
3Divide both sides by \(3\) (positive, no flip):   \(x > 2\)

Check: Pick \(x = 3\): \(6(3) - 4 = 14\) and \(3(3) + 2 = 11\). Indeed, \(14 > 11\). ✓

Graphing Solutions on a Number Line

We represent solutions on a number line using circles and shading:

Number Line Notation
SymbolCircleMeaning
\( < \) or \( > \)Open (hollow) circleEndpoint not included
\( \le \) or \( \ge \)Closed (filled) circleEndpoint is included

Shade to the right for \( > \) or \( \ge \). Shade to the left for \( < \) or \( \le \).

4. Compound Inequalities

A compound inequality combines two inequalities into a single statement. There are two types:

AND Inequalities (Intersection)

Both conditions must be true simultaneously. Written as:

$$a < x < b \quad \text{means} \quad x > a \;\textbf{ and }\; x < b$$

The solution is the overlap (intersection) of the two individual solutions.

OR Inequalities (Union)

At least one condition must be true. Written as:

$$x < a \;\textbf{ or }\; x > b$$

The solution is the combined set (union) of the two individual solutions.

Example — Solving a Compound AND Inequality

Solve: \(-3 < 2x + 1 < 7\)

1Subtract \(1\) from all three parts: \(-3 - 1 < 2x < 7 - 1\)   gives   \(-4 < 2x < 6\)
2Divide all three parts by \(2\) (positive, no flip): \(-2 < x < 3\)

Solution: All values of \(x\) strictly between \(-2\) and \(3\).

5. Absolute Value Inequalities

The absolute value \(|x|\) measures the distance of \(x\) from zero. This distance interpretation gives us two fundamental patterns:

Pattern 1 — Less Than (distance is small)
$$|x| < a \quad \Longleftrightarrow \quad -a < x < a \qquad (a > 0)$$

The values of \(x\) lie between \(-a\) and \(a\). This is a compound AND inequality.

Pattern 2 — Greater Than (distance is large)
$$|x| > a \quad \Longleftrightarrow \quad x < -a \;\textbf{ or }\; x > a \qquad (a > 0)$$

The values of \(x\) lie outside the interval \([-a, a]\). This is a compound OR inequality.

Key Insight — "Less thAND, GreatOR"

A handy mnemonic: Less than gives an AND compound inequality (values between). Greator gives an OR compound inequality (values outside). The same pattern applies to \(\le\) and \(\ge\).

Example — Absolute Value (Less Than)

Solve: \(|x - 3| < 5\)

1Apply the "less than" pattern: \(-5 < x - 3 < 5\)
2Add \(3\) to all parts: \(-2 < x < 8\)

Solution: \(x\) lies strictly between \(-2\) and \(8\).

Example — Absolute Value (Greater Than or Equal)

Solve: \(|2x + 1| \ge 7\)

1Apply the "greater than" pattern: \(2x + 1 \le -7\)   or   \(2x + 1 \ge 7\)
2Solve each:   \(2x \le -8 \;\Rightarrow\; x \le -4\)   or   \(2x \ge 6 \;\Rightarrow\; x \ge 3\)

Solution: \(x \le -4\) or \(x \ge 3\).

6. Quadratic Inequalities

A quadratic inequality involves a second-degree term. We solve it by finding the roots and then analyzing the sign of the expression in each interval.

The Sign Analysis Method

  1. Move everything to one side so you have \(f(x) > 0\) (or \(< 0\), \(\ge 0\), \(\le 0\)).
  2. Factor the quadratic (or find its roots).
  3. Plot the roots on a number line, dividing it into intervals.
  4. Test a point in each interval to determine the sign of \(f(x)\).
  5. Select the intervals that satisfy your inequality.
Example — Quadratic Inequality

Solve: \(x^2 - 4 > 0\)

1Factor: \((x - 2)(x + 2) > 0\)
2Roots: \(x = -2\) and \(x = 2\). These divide the number line into three intervals.
3Test each interval using the sign chart below.

The product \((x-2)(x+2)\) is positive when both factors have the same sign. From the chart, this happens when \(x < -2\) (both negative) or \(x > 2\) (both positive).

7. Types of Inequalities

Inequalities can be classified into three types based on their solution sets:

Absolute Inequality

True for all values of the variable. For example, \((a - b)^2 \ge 0\) is always true for any real numbers \(a\) and \(b\), since a square is never negative.

Conditional Inequality

True only for certain values of the variable. For example, \(x - 3 > 0\) is only true when \(x > 3\). Most inequalities we solve are conditional.

Inconsistent Inequality

True for no real values. For example, \(x^2 < 0\) has no solution, since the square of any real number is never negative.

8. Graphing Two-Variable Inequalities

When an inequality involves two variables, its solution is a region of the coordinate plane rather than a segment of a number line.

Steps for Graphing

  1. Replace the inequality with an equals sign to get the boundary line.
  2. Graph the boundary line. Use a dashed line for \(<\) or \(>\), or a solid line for \(\le\) or \(\ge\).
  3. Pick a test point not on the line (the origin \((0,0)\) is usually easiest).
  4. Substitute the test point into the original inequality.
  5. If the result is true, shade the side containing the test point. If false, shade the opposite side.
Example — Graphing 2x - y + 4 > 0
1Boundary line: \(2x - y + 4 = 0\), i.e., \(y = 2x + 4\)
2Test point \((0, 0)\): \(2(0) - 0 + 4 = 4 > 0\). True!
3Shade the side containing \((0,0)\) — the region below the line.

Worked Problems

Problem 1

Solve: \(3x - 7 > 5\)

1Add \(7\) to both sides:   \(3x > 12\)
2Divide both sides by \(3\) (positive — no flip):   \(x > 4\)

Solution: \(\boxed{x > 4}\) — all values greater than \(4\).

Problem 2 — Sign Flip!

Solve: \(-2x + 6 \le 10\)

1Subtract \(6\) from both sides:   \(-2x \le 4\)
2Divide both sides by \(-2\). Flip the sign!   \(x \ge -2\)

Solution: \(\boxed{x \ge -2}\)

Check: Try \(x = 0\): \(-2(0) + 6 = 6\). Is \(6 \le 10\)? Yes. ✓

Problem 3 — Compound Inequality

Solve: \(-3 < 2x + 1 < 7\)

1Subtract \(1\) from all three parts:   \(-4 < 2x < 6\)
2Divide all parts by \(2\):   \(-2 < x < 3\)

Solution: \(\boxed{-2 < x < 3}\) — all values strictly between \(-2\) and \(3\).

Problem 4 — Absolute Value (Less Than)

Solve: \(|x - 3| < 5\)

1Apply the "less than" pattern:   \(-5 < x - 3 < 5\)
2Add \(3\) to all parts:   \(-2 < x < 8\)

Solution: \(\boxed{-2 < x < 8}\)

Problem 5 — Absolute Value (Greater Than or Equal)

Solve: \(|2x + 1| \ge 7\)

1Apply the "greater than" pattern — split into two cases:

Case A: \(2x + 1 \le -7\)   ⇒   \(2x \le -8\)   ⇒   \(x \le -4\)

Case B: \(2x + 1 \ge 7\)   ⇒   \(2x \ge 6\)   ⇒   \(x \ge 3\)

Solution: \(\boxed{x \le -4 \text{ or } x \ge 3}\)

Problem 6 — Quadratic Inequality

Solve: \(x^2 - 4 > 0\)

1Factor: \((x - 2)(x + 2) > 0\)
2Find roots: \(x = -2\) and \(x = 2\)
3Test intervals:
  • \(x = -3\): \((-3-2)(-3+2) = (-5)(-1) = 5 > 0\) ✓
  • \(x = 0\): \((0-2)(0+2) = (-2)(2) = -4 < 0\) ✗
  • \(x = 3\): \((3-2)(3+2) = (1)(5) = 5 > 0\) ✓

Solution: \(\boxed{x < -2 \text{ or } x > 2}\)
