1. Equations vs. Expressions

One of the ways that algebra differs from arithmetic is that algebra uses equations. Equations help us solve problems that would be difficult, or even impossible, to solve using arithmetic alone.

Definition — Equation

An equation is a statement that two algebraic expressions are equal — it contains an equals sign (\(=\)). For example, \(3n = 12\) says "three times a number equals 12."

Definition — Expression

An expression is a mathematical phrase that combines numbers, variables, and operations but does not contain an equals sign. For example, \(3n + 5\) is an expression.

Three Types of Equations

Not all equations behave the same way. Every equation falls into one of three categories:

Identity

True for all admissible values of the variable.

Example: \(2(x+3)=2x+6\)

False Statement

False for every value of the variable.

Example: \(x = x + 3\)

Conditional Equation

True only for specific values (the roots).

Example: \(2a+1=7\)  (true only when \(a=3\))

In this chapter, when we say "equation" we mean a conditional linear equation — one with the variable raised to the first power, which has exactly one root.

Definition — Root of an Equation

The root (or solution) of an equation is the value that, when substituted for the unknown, makes both sides of the equation identical. Solving an equation means finding its root.

In \(3c = 18\), the root is \(c = 6\) because \(3 \times 6 = 18\). We say that 6 satisfies the equation.

2. The Balance Principle

An equation is like a balance scale — both sides must stay equal. Whatever operation you perform on one side, you must perform on the other. This idea is captured by two fundamental axioms:

Axiom 1 — Multiplication / Division

An equivalent equation is produced if both members are multiplied (or divided) by the same nonzero number.

Axiom 2 — Addition / Subtraction

An equivalent equation is produced if the same number is added to (or subtracted from) both members.

Key Insight

Think of the equals sign as the fulcrum of a balance. If you add weight to one pan (one side of the equation), you must add the same weight to the other pan to keep the scale level. This is the single most important idea behind solving any equation.

3. Solving Equations with Inverse Operations

To isolate a variable, we "undo" whatever has been done to it using the opposite — or inverse — operation:

Additive Inverses

Addition \(\longleftrightarrow\) Subtraction

To undo \(+3\), subtract 3
To undo \(-5\), add 5

Multiplicative Inverses

Multiplication \(\longleftrightarrow\) Division

To undo \(\times 4\), divide by 4
To undo \(\div 3\), multiply by 3

The Two-Step Strategy

Most linear equations require two operations to solve. The general order is:

  1. Add or subtract to move constant terms away from the variable (make them zero).
  2. Multiply or divide to make the coefficient of the variable equal to 1.
Example — Two-Step Solution

Solve \(2k + 3 = 7\).

$$2k + 3 = 7$$

Step 1: Subtract 3 from both sides (undo the \(+3\)):

$$2k = 4$$

Step 2: Divide both sides by 2 (undo the \(\times 2\)):

$$k = 2$$

Check: \(2(2) + 3 = 4 + 3 = 7\) ✓

Transposing Terms

Moving a term from one side of the equation to the other is called transposing. When a term is transposed, its sign changes. This is simply a shortcut for adding or subtracting from both sides.

Key Insight — Transposition Shortcut

Instead of writing "subtract 3 from both sides," experienced algebraists simply move the \(+3\) to the other side and write \(-3\). The sign always flips when a term crosses the equals sign: \(+\) becomes \(-\), and \(-\) becomes \(+\).

4. Equations with the Unknown on Both Sides

When the variable appears on both sides of the equation, use addition or subtraction to collect all variable terms on one side and all constant terms on the other.

Strategy
  1. Move all terms with the variable to one side (usually the left).
  2. Move all constant terms to the other side.
  3. Combine like terms on each side.
  4. Divide both sides by the coefficient of the variable.
Example

Solve \(6x - 2 = 8 + 4x\).

Subtract \(4x\) from both sides and add 2 to both sides:

$$6x - 4x = 8 + 2$$ $$2x = 10$$ $$x = 5$$

Check: \(6(5) - 2 = 28\) and \(8 + 4(5) = 28\) ✓

Removing Parentheses

If the equation contains parentheses, remove them first by distributing, then proceed as above. Remember: a minus sign before parentheses changes the sign of every term inside.

Example — Parentheses

Solve \(2(x - 5) - 3(2x + 1) = 7\).

Distribute:

$$2x - 10 - 6x - 3 = 7$$

Combine like terms:

$$-4x - 13 = 7$$

Add 13 to both sides:

$$-4x = 20$$

Divide by \(-4\):

$$x = -5$$

Check: \(2(-5 - 5) - 3(2(-5)+1) = 2(-10) - 3(-9) = -20 + 27 = 7\) ✓

5. Equations with Fractions

Equations containing fractions are usually easier to solve once the fractions are removed. We do this by clearing fractions — multiplying every term by the Lowest Common Denominator (LCD).

Rule — Clearing Fractions

Multiply every term on both sides of the equation by the LCD of all fractions present. This produces an equivalent equation with no fractions.

Example — Same Denominator

Solve \(\dfrac{x}{3} + 2x = 7\).

The LCD is 3. Multiply every term by 3:

$$3 \cdot \frac{x}{3} + 3 \cdot 2x = 3 \cdot 7$$ $$x + 6x = 21$$ $$7x = 21 \implies x = 3$$
Example — Different Denominators

Solve \(\dfrac{x}{2} + \dfrac{x}{3} = 5\).

The LCD of 2 and 3 is 6. Multiply every term by 6:

$$6 \cdot \frac{x}{2} + 6 \cdot \frac{x}{3} = 6 \cdot 5$$ $$3x + 2x = 30$$ $$5x = 30 \implies x = 6$$

Cross Multiplication

When an equation has the form of a proportion — one fraction equal to another — we can use cross multiplication:

Cross Multiplication Rule
$$\text{If } \frac{a}{b} = \frac{c}{d}, \text{ then } ad = bc \quad (b \neq 0, \; d \neq 0)$$
Example — Cross Multiplication

Solve \(\dfrac{3}{x} = \dfrac{7}{14}\).

Cross multiply:

$$3 \cdot 14 = 7 \cdot x$$ $$42 = 7x$$ $$x = 6$$

Check: \(\dfrac{3}{6} = \dfrac{1}{2}\) and \(\dfrac{7}{14} = \dfrac{1}{2}\) ✓

Caution — Multiplying by the Unknown

When you multiply both sides by an expression containing the variable, you may introduce extraneous roots — values that satisfy the new equation but not the original. Always check your answer in the original equation, and make sure you are not dividing by zero.

6. Literal Equations and Formulas

A formula is an equation that expresses a rule in concise form. Formulas appear everywhere: in geometry (areas, volumes), in physics (speed, force, energy), and in everyday life. When a formula contains several variables, we often need to rearrange it to solve for a different variable.

Three Steps for Using a Formula
  1. Write the formula in its standard form.
  2. Transform (rearrange) it to isolate the desired variable on one side.
  3. Substitute known values and simplify.

The same inverse-operation rules that solve numeric equations work for literal equations. Treat the other letters as constants and isolate the target variable.

Example — Rearranging D = TS

The distance formula is \(D = T \cdot S\). Solve for \(T\):

$$D = T \cdot S$$

Divide both sides by \(S\):

$$T = \frac{D}{S} \quad (S \neq 0)$$
Example — Rearranging with a Square

Solve \(A = \pi r^2\) for \(r\):

$$A = \pi r^2$$

Divide both sides by \(\pi\):

$$\frac{A}{\pi} = r^2$$

Take the square root of both sides:

$$r = \sqrt{\frac{A}{\pi}} \quad (r > 0)$$
Example — Multi-Term Formula

Solve \(A = p + prt\) for \(r\):

Subtract \(p\) from both sides:

$$A - p = prt$$

Divide both sides by \(pt\):

$$r = \frac{A - p}{pt} \quad (p \neq 0, \; t \neq 0)$$

7. From Words to Equations

Many real-world problems are stated in words. To solve them algebraically, follow these steps:

Word-Problem Strategy
  1. Read the problem carefully and identify the unknown.
  2. Let a variable represent the unknown quantity.
  3. Translate the English sentence into an equation.
  4. Solve the equation.
  5. Check your answer against the original words (not just the equation).

Common Translations

English PhraseAlgebraic Translation
"a number"\(n\) (or \(x\))
"five more than"\(+ 5\)
"three less than"\(- 3\)
"twice a number"\(2n\)
"the quotient of a number and 4"\(\dfrac{n}{4}\)
"is" / "equals" / "the result is"\(=\)
Example — Word Problem

"Five more than twice a number is 17. Find the number."

Let \(n\) = the number. Translate:

$$2n + 5 = 17$$

Subtract 5:

$$2n = 12$$

Divide by 2:

$$n = 6$$

Check: Twice 6 is 12; five more than 12 is 17 ✓

Worked Problems

Problem 1

Practice Problem

Solve: \(3x + 7 = 22\)

Solution
  • Subtract 7 from both sides: $$3x + 7 - 7 = 22 - 7$$ $$3x = 15$$
  • Divide both sides by 3: $$\frac{3x}{3} = \frac{15}{3}$$ $$x = 5$$
  • Check: \(3(5) + 7 = 15 + 7 = 22\) ✓

Problem 2

Practice Problem

Solve: \(\dfrac{x}{3} + \dfrac{x}{4} = 7\)

Solution
  • Find the LCD. The LCD of 3 and 4 is 12.
  • Multiply every term by 12: $$12 \cdot \frac{x}{3} + 12 \cdot \frac{x}{4} = 12 \cdot 7$$ $$4x + 3x = 84$$
  • Combine like terms: $$7x = 84$$
  • Divide by 7: $$x = 12$$
  • Check: \(\dfrac{12}{3} + \dfrac{12}{4} = 4 + 3 = 7\) ✓

Problem 3

Practice Problem

Solve: \(2(x - 3) + 5 = 3x - 4\)

Solution
  • Distribute the 2: $$2x - 6 + 5 = 3x - 4$$
  • Combine like terms on the left: $$2x - 1 = 3x - 4$$
  • Subtract \(2x\) from both sides: $$-1 = x - 4$$
  • Add 4 to both sides: $$3 = x$$ $$x = 3$$
  • Check: Left side: \(2(3-3)+5 = 2(0)+5 = 5\). Right side: \(3(3)-4 = 9-4 = 5\) ✓

Problem 4

Practice Problem

Solve \(A = \pi r^2\) for \(r\) (assuming \(r > 0\)).

Solution
  • Divide both sides by \(\pi\): $$\frac{A}{\pi} = r^2$$
  • Take the positive square root of both sides: $$r = \sqrt{\frac{A}{\pi}}$$

For instance, if \(A = 50\), then \(r = \sqrt{\dfrac{50}{\pi}} = \sqrt{\dfrac{50}{3.14159\ldots}} \approx \sqrt{15.915} \approx 3.99\).

Problem 5

Practice Problem

Solve by cross multiplication: \(\dfrac{3}{x} = \dfrac{7}{14}\)

Solution
  • Cross multiply: $$3 \times 14 = 7 \times x$$ $$42 = 7x$$
  • Divide both sides by 7: $$x = 6$$
  • Check: \(\dfrac{3}{6} = \dfrac{1}{2}\) and \(\dfrac{7}{14} = \dfrac{1}{2}\) ✓

Problem 6

Practice Problem

"Five more than twice a number is 17. Find the number."

Solution
  • Define the variable: Let \(n\) = the number.
  • Translate to an equation:
    "Twice a number" → \(2n\)
    "Five more than" → \(+5\)
    "is 17" → \(= 17\) $$2n + 5 = 17$$
  • Subtract 5 from both sides: $$2n = 12$$
  • Divide by 2: $$n = 6$$
  • Check the original words: Twice 6 is 12. Five more than 12 is 17 ✓

Key Insights to Remember

Insight 1 — Equations Are Balanced

Every equation is a statement of equality. If you change one side, you must make the exact same change to the other. Think of it as the Golden Rule of algebra.

Insight 2 — Undo Operations in Reverse Order

If a variable has been multiplied by 3 and then had 5 added (\(3x + 5\)), undo in reverse: subtract 5 first, then divide by 3. This mirrors the order of operations in reverse.

Insight 3 — Fractions Are Not Scary

Clearing fractions by multiplying through by the LCD converts any fractional equation into a simpler integer equation. The fractions vanish, and you solve as usual.

Insight 4 — Formulas Are Just Equations with Letters

Rearranging \(A = \pi r^2\) for \(r\) uses exactly the same principles as solving \(3x + 7 = 22\) for \(x\). Treat every letter except your target as if it were a number.

Insight 5 — Always Check Your Answer

Substituting your solution back into the original equation catches arithmetic mistakes and extraneous roots. This single habit will improve your accuracy dramatically.

Core Formulas from This Chapter

Balance Axioms

If \(a = b\), then:

  • \(a + c = b + c\)
  • \(a - c = b - c\)
  • \(ac = bc\)
  • \(\dfrac{a}{c} = \dfrac{b}{c}\)  (\(c \neq 0\))

Cross Multiplication

$$\frac{a}{b} = \frac{c}{d} \;\Longleftrightarrow\; ad = bc$$

Reciprocal Rule

If \(\dfrac{m}{n}\,x = k\), then \(x = k \cdot \dfrac{n}{m}\)
