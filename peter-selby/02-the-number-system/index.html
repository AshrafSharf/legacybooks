The Number System

Extending arithmetic into the world of signed numbers, absolute value, and the real number hierarchy

What You'll Learn

  • Understand positive and negative numbers on the number line
  • Compute absolute values and distances between numbers
  • Add, subtract, multiply, and divide signed numbers with proper sign handling
  • Raise signed numbers to higher powers (even vs. odd exponents)
  • Identify irrational numbers and classify numbers within the real number system
  • Evaluate algebraic expressions containing signed numbers

The Real Number System

The numbers you first learned to count with are called natural numbers (or counting numbers): \(1, 2, 3, 4, \ldots\) They are whole numbers greater than zero. You learned to add, subtract, multiply, and divide them. But some divisions—such as \(5 \div 2\) or \(7 \div 3\)—do not produce whole numbers. To handle these results, fractions were introduced.

Arithmetic uses whole numbers, zero, and fractions. But there is a limitation: you cannot subtract a larger number from a smaller one and stay within this system. To overcome this, mathematicians invented negative numbers—numbers less than zero. For every positive number there exists a corresponding negative (opposite) number.

Definition — Key Number Sets
  • Natural numbers (counting numbers): \(1, 2, 3, 4, \ldots\)
  • Whole numbers: \(0, 1, 2, 3, 4, \ldots\) (natural numbers plus zero)
  • Integers: \(\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots\) (whole numbers and their negatives)
  • Rational numbers: numbers expressible as \(\dfrac{p}{q}\) where \(p, q\) are integers and \(q \neq 0\)
  • Irrational numbers: numbers that cannot be expressed as a ratio of integers (e.g., \(\pi\), \(\sqrt{2}\))
  • Real numbers: all rational and irrational numbers together

Irrational Numbers

Some numbers cannot be written as fractions of integers. Two famous examples:

  • \(\pi \approx 3.14159\ldots\) — the ratio of a circle's circumference to its diameter
  • \(\sqrt{2} \approx 1.41421\ldots\) — the length of the diagonal of a unit square

Their decimal representations go on forever without repeating. These are irrational numbers. Together, the rational and irrational numbers form the complete family of real numbers.

Key Insight

Every natural number is also a whole number, every whole number is also an integer, and every integer is also a rational number. But not every real number is rational—irrational numbers like \(\pi\) and \(\sqrt{2}\) fill in the "gaps" on the number line that fractions cannot reach.

Signed Numbers and the Number Line

You are already familiar with signed numbers from everyday life. A thermometer has temperatures above zero (positive, indicated by \(+\)) and below zero (negative, indicated by \(-\)). If \(+15\) represents 15° above zero, then \(-15\) represents 15° below zero.

Signed numbers represent opposites: profit and loss, north and south, above and below sea level. A positive number may be written with a plus sign or with no sign at all; a negative number must always carry a minus sign.

The Number Line

The number line represents all real numbers as points on a line. Every point corresponds to exactly one real number, and every real number corresponds to exactly one point.

Figure 2.2 — The horizontal number line with the origin at zero

Key Insight — Comparing Signed Numbers

On the number line, a number is greater if it lies further to the right. This means any positive number is greater than any negative number. For example, \(+10\) is greater than \(-30\), even though \(|-30| = 30\) is numerically larger than \(|+10| = 10\).

Absolute Value

Definition — Absolute Value

The absolute value of a number \(n\), written \(|n|\), is its distance from zero on the number line, regardless of direction. Absolute value is always non-negative.

$$|n| = \begin{cases} n & \text{if } n \geq 0 \\ -n & \text{if } n < 0 \end{cases}$$

Since \(+3\) and \(-3\) are each three units from zero, they have the same absolute value:

$$|+3| = 3 \qquad \text{and} \qquad |-3| = 3$$

Similarly:

$$|+5| = 5 \qquad \text{and} \qquad |-5| = 5$$

Notice that the absolute value of \(-5\) is greater than the absolute value of \(+3\), even though \(+3\) is the larger number on the number line. Absolute value strips away the sign and measures only distance.

Key Insight — Two Ways to Think About It

Geometric view: \(|n|\) is the distance from \(n\) to zero on the number line.
Algebraic view: \(|n|\) is the value of a number when its sign is ignored.

Adding Signed Numbers

When we say add in algebra, we really mean combine—finding a single number that represents the total of two quantities taken together.

Rule 1 — Adding Numbers with Like Signs

To add two numbers with the same sign, add their absolute values and prefix their common sign.

$$\underbrace{(+4) + (+6)}_{\text{same sign: both }+} = +(|{+4}| + |{+6}|) = +(4+6) = +10$$ $$\underbrace{(-4) + (-6)}_{\text{same sign: both }-} = -(|{-4}| + |{-6}|) = -(4+6) = -10$$
Rule 2 — Adding Numbers with Unlike Signs

To add two numbers with opposite signs, subtract the smaller absolute value from the larger, then prefix the sign of the number with the larger absolute value.

$$\underbrace{(+4) + (-6)}_{\text{unlike signs}} = -(|{-6}| - |{+4}|) = -(6-4) = -2$$
Common Mistake

Don't confuse the sign of the number (positive or negative quality) with the sign of operation (adding or subtracting). In expressions like \(-5 + (-8)\), the parentheses help distinguish between the two. Without parentheses, this simplifies to \(-5 - 8\).

Combining Multiple Signed Numbers

When adding a series of positive and negative values, a convenient method is:

  1. Add all the positive numbers (their sum is positive)
  2. Add all the negative numbers (their sum is negative)
  3. Combine the two sums using Rule 2

For example:

$$20.2 + 3.7 - 12.9 + 1.1 - 6.4$$ $$\text{Positives: } 20.2 + 3.7 + 1.1 = +25.0$$ $$\text{Negatives: } -12.9 + (-6.4) = -19.3$$ $$\text{Combined: } 25.0 + (-19.3) = +5.7$$

Subtracting Signed Numbers

Subtraction can be thought of as finding the directed distance from one position to another on the number line. Unlike arithmetic (where you never subtract a larger number from a smaller one), in algebra we often do—this is precisely why negative numbers were invented.

Rule 3 — Subtraction of Signed Numbers

To subtract a number, add its opposite (its additive inverse):

$$a - b = a + (-b)$$

Change the sign of the subtrahend (the number being subtracted) and then add.

This single rule covers every combination of signs:

Problem Rewritten as Addition Result
\(+5 - (+3)\) \(+5 + (-3)\) \(+2\)
\(+5 - (-3)\) \(+5 + (+3)\) \(+8\)
\(-5 - (+3)\) \(-5 + (-3)\) \(-8\)
\(-5 - (-3)\) \(-5 + (+3)\) \(-2\)
Key Insight — Subtracting a Negative

Subtracting a negative number is the same as adding its positive counterpart. This is because the "opposite of a negative" is positive: \(-(-b) = +b\). So \(5 - (-3) = 5 + 3 = 8\).

Multiplying Signed Numbers

Rule 4 — Same Signs → Positive Product

When multiplying two numbers with the same sign, the product is positive.

$$(+3)(+4) = +12 \qquad \text{and} \qquad (-3)(-4) = +12$$
Rule 5 — Different Signs → Negative Product

When multiplying two numbers with different signs, the product is negative.

$$(-3)(+4) = -12 \qquad \text{and} \qquad (+3)(-4) = -12$$

More Than Two Factors

Rule 6 — Multiple Factors

When multiplying more than two numbers:

  • Odd number of negative factors → product is negative
  • Even number of negative factors → product is positive
  • If any factor is zero, the entire product is zero
$$(2)(-3)(4)(-5) = +120 \quad \text{(two negatives = even)}$$ $$(-2)(+3)(-4)(-5) = -120 \quad \text{(three negatives = odd)}$$

Dividing Signed Numbers

Rule — Sign of the Quotient

Division follows the same sign rules as multiplication:

  • Same signs → quotient is positive: \(\;\dfrac{+6}{+3} = +2\), \(\;\dfrac{-6}{-3} = +2\)
  • Different signs → quotient is negative: \(\;\dfrac{+6}{-3} = -2\), \(\;\dfrac{-6}{+3} = -2\)
Caution — Division by Zero

Division by zero is undefined. There is no number that satisfies \(\dfrac{a}{0}\) for any value of \(a\). Whenever you encounter a zero in the denominator, the expression has no value.

Even and Odd Powers of Negative Numbers

Raising a negative number to a power is just repeated multiplication. The sign of the result depends on whether the exponent is even or odd:

Rule — Powers of Negatives

Odd powers of negative numbers are negative:

$$(-2)^3 = (-2)(-2)(-2) = -8$$

Even powers of negative numbers are positive:

$$(-2)^4 = (-2)(-2)(-2)(-2) = +16$$

This follows directly from Rule 6: an odd exponent means an odd number of negative factors (negative result), while an even exponent means an even number (positive result).

A few more examples:

$$(-4)^2 = +16 \qquad (-3)^2 = +9 \qquad (-5)^3 = -125 \qquad (-1)^9 = -1$$
Key Insight — Pattern

Even powers always produce positive results; odd powers preserve the negative sign. This holds for any negative base, including variables: \((-a)^4 = +a^4\) and \((-a)^3 = -a^3\).

Worked Problems

Problem 1 — Same-Sign Addition

Compute: \(\;-7 + (-3)\)

Solution
Step 1: Both numbers are negative (same sign). Use Rule 1.
Step 2: Add the absolute values: \(|-7| + |-3| = 7 + 3 = 10\).
Step 3: Prefix the common sign (negative):
$$-7 + (-3) = -10$$
Problem 2 — Unlike-Sign Addition

Compute: \(\;-15 + 8\)

Solution
Step 1: The signs are different. Use Rule 2.
Step 2: Subtract the smaller absolute value from the larger: \(|-15| - |8| = 15 - 8 = 7\).
Step 3: The number with the larger absolute value is \(-15\) (negative), so prefix \(-\):
$$-15 + 8 = -7$$
Problem 3 — Subtracting a Negative

Compute: \(\;5 - (-3)\)

Solution
Step 1: Apply Rule 3: change the sign of the subtrahend and add.
$$5 - (-3) = 5 + (+3)$$
Step 2: Now both are positive (same sign), so add:
$$5 + 3 = 8$$
Problem 4 — Multiplying Two Negatives

Compute: \(\;(-4)(-6)\)

Solution
Step 1: Both factors are negative (same sign). By Rule 4, the product is positive.
Step 2: Multiply the absolute values: \(4 \times 6 = 24\).
$$(-4)(-6) = +24$$
Problem 5 — Even vs. Odd Powers

Compute: \(\;(-2)^3\) and \(\;(-2)^4\)

Solution

Part (a): \((-2)^3\)

Step 1: Expand: \((-2)^3 = (-2)(-2)(-2)\).
Step 2: Three negative factors (odd) → negative result.
$$(-2)^3 = -8$$

Part (b): \((-2)^4\)

Step 1: Expand: \((-2)^4 = (-2)(-2)(-2)(-2)\).
Step 2: Four negative factors (even) → positive result.
$$(-2)^4 = +16$$
Problem 6 — Absolute Value Computation

Compute: \(\;|-7| - |3|\)

Solution
Step 1: Evaluate each absolute value: \(|-7| = 7\) and \(|3| = 3\).
Step 2: Subtract:
$$|-7| - |3| = 7 - 3 = 4$$
