Objective Type Questions

  1. Data is a collection of \(\underline{\qquad}\)

    (A) numbers   (B) words   (C) measurements   (D) all the three

  2. The number of times an observation occurs in the given data is called \(\underline{\qquad}\)

    (A) tally marks   (B) data   (C) frequency   (D) none of these

  3. The difference between the largest value and the smallest value of the given data is \(\underline{\qquad}\)

    (A) range   (B) frequency   (C) variable   (D) none of these

  4. The data that can take values between a certain range is called \(\underline{\qquad}\)

    (A) ungrouped   (B) grouped   (C) frequency   (D) none of these

  5. Inclusive series is a \(\underline{\qquad}\) series.

    (A) continuous   (B) discontinuous   (C) both   (D) none of these

  6. In a class interval the upper limit of one class is the lower limit of the other class. This is \(\underline{\qquad}\) series.

    (A) inclusive   (B) exclusive   (C) ungrouped   (D) none of these

  8. Histogram is a graph of a \(\underline{\qquad}\) frequency distribution.
