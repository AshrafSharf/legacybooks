Objective Type Questions

  1. If \(x^{2} - y^{2} = 16\) and \((x + y) = 8\) then \((x - y)\) is \(\underline{\qquad\qquad}\)
    1. 8
    2. 3
    3. 2
    4. 1
  2. \(\dfrac{(a + b)(a^{3} - b^{3})}{(a^{2} - b^{2})} = \underline{\qquad\qquad}\)
    1. \(a^{2} - ab + b^{2}\)
    2. \(a^{2} + ab + b^{2}\)
    3. \(a^{2} + 2ab + b^{2}\)
    4. \(a^{2} - 2ab + b^{2}\)
  3. \((p + q)(p^{2} - pq + q^{2})\) is equal to \(\underline{\qquad\qquad}\)
    1. \(p^{3} + q^{3}\)
    2. \((p + q)^{3}\)
    3. \(p^{3} - q^{3}\)
    4. \((p - q)^{3}\)
  4. \((a - b) = 3\) and \(ab = 5\) then \(a^{3} - b^{3} = \underline{\qquad\qquad}\)
    1. 15
    2. 18
    3. 62
    4. 72
  5. \(a^{3} + b^{3} = (a + b)^{3} - \underline{\qquad\qquad}\)
    1. \(3a(a + b)\)
    2. \(3ab(a - b)\)
    3. \(-3ab(a + b)\)
    4. \(3ab(a + b)\)
