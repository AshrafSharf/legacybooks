Chapter 3 · Algebra

Exercise 3.2

Textbook pages 12–13

  1. Fill in the blanks:
    1. \(\frac{18m^{4}(\underline{\qquad})}{2m^{3}n^{3}} = \underline{\qquad}\,mn^{5}\)
    2. \(\frac{l^{4}m^{5}n^{(\underline{\quad})}}{2lm^{(\underline{\quad})}n^{6}} = \frac{l^{3}m^{2}n}{(\underline{\qquad})}\)
    3. \(\frac{42a^{4}b^{5}(\underline{\qquad})}{6a^{4}b^{2}} = (\underline{\qquad})b^{(\underline{\quad})}c^{2}\)
  2. Say True or False
    1. \(8x^{3}y \div 4x^{2} = 2xy\)
    2. \(7ab^{3} \div 14ab = 2b^{2}\)
  3. Divide
    1. \(27y^{3}\) by \(3y\)
    2. \(x^{3}y^{2}\) by \(x^{2}y\)
    3. \(45x^{3}y^{2}z^{4}\) by \((-15xyz)\)
    4. \((3xy)^{2}\) by \(9xy\)
  4. Simplify
    1. \(\frac{3m^{2}}{m} + \frac{2m^{4}}{m^{3}}\)
    2. \(\frac{14p^{5}q^{3}}{2p^{2}q} - \frac{12p^{3}q^{4}}{3q^{2}}\)
  5. Divide:
    1. \((32y^{2} - 8yz)\) by \(2y\)
    2. \((4m^{2}n^{3} + 16m^{4}n^{2} - mn)\) by \(2mn\)
    3. \(5xy^{2} - 18x^{2}y^{3} + 6xy\) by \(6xy\)
    4. \(81(p^{4}q^{2}r^{3} + 2p^{3}q^{3}r^{2} - 5p^{2}q^{2}r^{2})\) by \((3pqr)^{2}\)
  6. Identify the errors and correct them.
    1. \(7y^{2} - y^{2} + 3y^{2} = 10y^{2}\)
    2. \(6xy + 3xy = 9x^{2}y^{2}\)
    3. \(m(4m - 3) = 4m^{2} - 3\)
    4. \((4n)^{2} - 2n + 3 = 4n^{2} - 2n + 3\)
    5. \((x - 2)(x + 3) = x^{2} - 6\)
    6. \(-3p^{2} + 4p - 7 = -(3p^{2} + 4p - 7)\)
  7. Statement A: If \(24p^{2}q\) is divided by \(3pq\), then the quotient is \(8p\).

    Statement B: Simplification of \(\frac{(5x+5)}{5}\) is \(5x\).

    1. Both A and B are true
    2. A is true but B is false
    3. A is false but B is true
    4. Both A and B are false
  8. Statement A: \(4x^{2} + 3x - 2 = 2\left(2x^{2} + \frac{3x}{2} - 1\right)\)

    Statement B: \((2m - 5) - (5 - 2m) = (2m - 5) + (2m - 5)\)

    1. Both A and B are true
    2. A is true but B is false
    3. A is false but B is true
    4. Both A and B are false
