Chapter 11 · The World of Algorithms

11.3 Data Structures

Textbook pages 7

When we execute an algorithm, we compute intermediate quantities, such as the list divisors-of-m and the list divisors-of-n. To keep track of these values, we use names such as divisors-of-m and divisors-of-n, respectively, so that we can refer to them later in the algorithm. As we remarked earlier, assigning names to intermediate values is important for writing down algorithms concisely.

Also, these intermediate values are typically more complicated than just simple numbers. In this case, we maintain lists of numbers and, in fact, lists that are arranged in ascending order. A list is an example of a data structure. Data structures allow us to organise information in a manner that helps make an algorithm more efficient. We will explore this idea in higher grades.
