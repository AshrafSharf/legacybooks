  • •An Iterative process is a procedure that is repeated many times to give new results.

  • •If a number ‘a’ is divided by some number ‘b’ then we get the quotient ‘q’ and

remainder ‘r ’, and ‘a’ can be written in a unique way as \(a =\) (b x q) \(+ r\). that is., Dividend = (Divisor x Quotient) + Remainder. This is called the Euclidean algorithm.
