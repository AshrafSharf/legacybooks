9.4.2 Homogeneous Differential Equations

When dy/dx depends only on the ratio y/x, the substitution y = vx separates the variables

In This Section

  • What it means for a function \(F(x, y)\) to be homogeneous of degree \(n\)
  • The equivalent forms \(x^n g\!\left(\frac{y}{x}\right)\) and \(y^n h\!\left(\frac{x}{y}\right)\)
  • Which differential equations are called homogeneous
  • The substitution \(y = vx\) (or \(x = vy\)) that reduces them to variables separable form
  • Four worked examples, including a family of curves defined by its tangent slope

Homogeneous Functions

Consider the following functions in \(x\) and \(y\):

\[ F_1(x, y) = y^2 + 2xy, \qquad F_2(x, y) = 2x - 3y, \] \[ F_3(x, y) = \cos\left(\frac{y}{x}\right), \qquad F_4(x, y) = \sin x + \cos y \]

If we replace \(x\) and \(y\) by \(\lambda x\) and \(\lambda y\) respectively in the above functions, for any nonzero constant \(\lambda\), we get

\[ \begin{aligned} F_1(\lambda x, \lambda y) &= \lambda^2 (y^2 + 2xy) = \lambda^2 F_1(x, y)\\ F_2(\lambda x, \lambda y) &= \lambda (2x - 3y) = \lambda F_2(x, y)\\ F_3(\lambda x, \lambda y) &= \cos\left(\frac{\lambda y}{\lambda x}\right) = \cos\left(\frac{y}{x}\right) = \lambda^0 F_3(x, y)\\ F_4(\lambda x, \lambda y) &= \sin \lambda x + \cos \lambda y \neq \lambda^n F_4(x, y), \text{ for any } n \in \mathbf{N} \end{aligned} \]

Here, we observe that the functions \(F_1, F_2, F_3\) can be written in the form \(F(\lambda x, \lambda y) = \lambda^n F(x, y)\) but \(F_4\) can not be written in this form. This leads to the following definition:

Definition — Homogeneous Function of Degree n

A function \(F(x, y)\) is said to be homogeneous function of degree \(n\) if

\[ F(\lambda x, \lambda y) = \lambda^n F(x, y) \]

for any nonzero constant \(\lambda\).

We note that in the above examples, \(F_1, F_2, F_3\) are homogeneous functions of degree 2, 1, 0 respectively but \(F_4\) is not a homogeneous function.

An Equivalent Form

We also observe that

\[ \begin{aligned} F_1(x, y) &= x^2\left(\frac{y^2}{x^2} + \frac{2y}{x}\right) = x^2 h_1\left(\frac{y}{x}\right)\\ \text{or}\quad F_1(x, y) &= y^2\left(1 + \frac{2x}{y}\right) = y^2 h_2\left(\frac{x}{y}\right)\\[4pt] F_2(x, y) &= x^1\left(2 - \frac{3y}{x}\right) = x^1 h_3\left(\frac{y}{x}\right)\\ \text{or}\quad F_2(x, y) &= y^1\left(2\frac{x}{y} - 3\right) = y^1 h_4\left(\frac{x}{y}\right)\\[4pt] F_3(x, y) &= x^0 \cos\left(\frac{y}{x}\right) = x^0 h_5\left(\frac{y}{x}\right)\\[4pt] F_4(x, y) &\neq x^n h_6\left(\frac{y}{x}\right), \text{ for any } n \in \mathbf{N}\\ \text{or}\quad F_4(x, y) &\neq y^n h_7\left(\frac{x}{y}\right), \text{ for any } n \in \mathbf{N} \end{aligned} \]
Result

A function \(F(x, y)\) is a homogeneous function of degree \(n\) if

\[ F(x, y) = x^n g\left(\frac{y}{x}\right) \quad \text{or} \quad y^n h\left(\frac{x}{y}\right) \]
Definition — Homogeneous Differential Equation

A differential equation of the form \(\dfrac{dy}{dx} = F(x, y)\) is said to be homogenous if \(F(x, y)\) is a homogenous function of degree zero.

Method of Solution

To solve a homogeneous differential equation of the type

\[ \frac{dy}{dx} = F(x, y) = g\left(\frac{y}{x}\right) \tag{1} \]
1

We make the substitution

\[ y = v\cdot x \tag{2} \]
2

Differentiating equation (2) with respect to \(x\), we get

\[ \frac{dy}{dx} = v + x\frac{dv}{dx} \tag{3} \]
3

Substituting the value of \(\dfrac{dy}{dx}\) from equation (3) in equation (1), we get

\[ v + x\frac{dv}{dx} = g(v) \]

or

\[ x\frac{dv}{dx} = g(v) - v \tag{4} \]
4

Separating the variables in equation (4), we get

\[ \frac{dv}{g(v) - v} = \frac{dx}{x} \tag{5} \]
5

Integrating both sides of equation (5), we get

\[ \int \frac{dv}{g(v) - v} = \int \frac{1}{x}\,dx + C \tag{6} \]

Equation (6) gives general solution (primitive) of the differential equation (1) when we replace \(v\) by \(\dfrac{y}{x}\).

Note

If the homogeneous differential equation is in the form \(\dfrac{dx}{dy} = F(x, y)\) where, \(F(x, y)\) is homogenous function of degree zero, then we make substitution \(\dfrac{x}{y} = v\) i.e., \(x = vy\) and we proceed further to find the general solution as discussed above by writing \(\dfrac{dx}{dy} = F(x, y) = h\left(\dfrac{x}{y}\right)\).

Worked Examples

Example 10

Show that the differential equation \((x - y)\dfrac{dy}{dx} = x + 2y\) is homogeneous and solve it.

Solution The given differential equation can be expressed as

\[ \frac{dy}{dx} = \frac{x + 2y}{x - y} \tag{1} \]

Let

\[ F(x, y) = \frac{x + 2y}{x - y} \]

Now

\[ F(\lambda x, \lambda y) = \frac{\lambda(x + 2y)}{\lambda(x - y)} = \lambda^0 \cdot f(x, y) \]

Therefore, \(F(x, y)\) is a homogenous function of degree zero. So, the given differential equation is a homogenous differential equation.

Alternatively,

\[ \frac{dy}{dx} = \left(\frac{1 + \dfrac{2y}{x}}{1 - \dfrac{y}{x}}\right) = g\left(\frac{y}{x}\right) \tag{2} \]

R.H.S. of differential equation (2) is of the form \(g\left(\dfrac{y}{x}\right)\) and so it is a homogeneous function of degree zero. Therefore, equation (1) is a homogeneous differential equation.

To solve it we make the substitution

\[ y = vx \tag{3} \]

Differentiating equation (3) with respect to \(x\), we get

\[ \frac{dy}{dx} = v + x\frac{dv}{dx} \tag{4} \]

Substituting the value of \(y\) and \(\dfrac{dy}{dx}\) in equation (1) we get

\[ \begin{aligned} v + x\frac{dv}{dx} &= \frac{1 + 2v}{1 - v}\\ \text{or}\quad x\frac{dv}{dx} &= \frac{1 + 2v}{1 - v} - v\\ \text{or}\quad x\frac{dv}{dx} &= \frac{v^2 + v + 1}{1 - v}\\ \text{or}\quad \frac{v - 1}{v^2 + v + 1}\,dv &= \frac{-dx}{x} \qquad \text{... (5)} \end{aligned} \]

Integrating both sides of equation (5), we get

\[ \begin{aligned} \int \frac{v - 1}{v^2 + v + 1}\,dv &= -\int \frac{dx}{x}\\ \text{or}\quad \frac{1}{2}\int \frac{2v + 1 - 3}{v^2 + v + 1}\,dv &= -\log|x| + C_1\\ \text{or}\quad \frac{1}{2}\int \frac{2v + 1}{v^2 + v + 1}\,dv - \frac{3}{2}\int \frac{1}{v^2 + v + 1}\,dv &= -\log|x| + C_1\\ \text{or}\quad \frac{1}{2}\log\left|v^2 + v + 1\right| - \frac{3}{2}\int \frac{1}{\left(v + \frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2}\,dv &= -\log|x| + C_1\\ \text{or}\quad \frac{1}{2}\log\left|v^2 + v + 1\right| - \frac{3}{2}\cdot\frac{2}{\sqrt{3}}\tan^{-1}\left(\frac{2v + 1}{\sqrt{3}}\right) &= -\log|x| + C_1\\ \text{or}\quad \frac{1}{2}\log\left|v^2 + v + 1\right| + \frac{1}{2}\log x^2 &= \sqrt{3}\tan^{-1}\left(\frac{2v + 1}{\sqrt{3}}\right) + C_1 \quad \text{(Why?)} \end{aligned} \]

Replacing \(v\) by \(\dfrac{y}{x}\), we get

\[ \begin{aligned} \text{or}\quad \frac{1}{2}\log\left|\frac{y^2}{x^2} + \frac{y}{x} + 1\right| + \frac{1}{2}\log x^2 &= \sqrt{3}\tan^{-1}\left(\frac{2y + x}{\sqrt{3}x}\right) + C_1\\ \text{or}\quad \frac{1}{2}\log\left|\left(\frac{y^2}{x^2} + \frac{y}{x} + 1\right)x^2\right| &= \sqrt{3}\tan^{-1}\left(\frac{2y + x}{\sqrt{3}x}\right) + C_1\\ \text{or}\quad \log\left|(y^2 + xy + x^2)\right| &= 2\sqrt{3}\tan^{-1}\left(\frac{2y + x}{\sqrt{3}x}\right) + 2C_1\\ \text{or}\quad \log\left|(x^2 + xy + y^2)\right| &= 2\sqrt{3}\tan^{-1}\left(\frac{x + 2y}{\sqrt{3}x}\right) + C \end{aligned} \]

which is the general solution of the differential equation (1).

Example 11

Show that the differential equation \(x\cos\left(\dfrac{y}{x}\right)\dfrac{dy}{dx} = y\cos\left(\dfrac{y}{x}\right) + x\) is homogeneous and solve it.

Solution The given differential equation can be written as

\[ \frac{dy}{dx} = \frac{y\cos\left(\frac{y}{x}\right) + x}{x\cos\left(\frac{y}{x}\right)} \tag{1} \]

It is a differential equation of the form \(\dfrac{dy}{dx} = F(x, y)\).

Here

\[ F(x, y) = \frac{y\cos\left(\frac{y}{x}\right) + x}{x\cos\left(\frac{y}{x}\right)} \]

Replacing \(x\) by \(\lambda x\) and \(y\) by \(\lambda y\), we get

\[ F(\lambda x, \lambda y) = \frac{\lambda\left[y\cos\left(\frac{y}{x}\right) + x\right]}{\lambda\left(x\cos\frac{y}{x}\right)} = \lambda^0\left[F(x, y)\right] \]

Thus, \(F(x, y)\) is a homogeneous function of degree zero.

Therefore, the given differential equation is a homogeneous differential equation. To solve it we make the substitution

\[ y = vx \tag{2} \]

Differentiating equation (2) with respect to \(x\), we get

\[ \frac{dy}{dx} = v + x\frac{dv}{dx} \tag{3} \]

Substituting the value of \(y\) and \(\dfrac{dy}{dx}\) in equation (1), we get

\[ \begin{aligned} v + x\frac{dv}{dx} &= \frac{v\cos v + 1}{\cos v}\\ \text{or}\quad x\frac{dv}{dx} &= \frac{v\cos v + 1}{\cos v} - v\\ \text{or}\quad x\frac{dv}{dx} &= \frac{1}{\cos v}\\ \text{or}\quad \cos v\,dv &= \frac{dx}{x} \end{aligned} \]

Therefore

\[ \begin{aligned} \int \cos v\,dv &= \int \frac{1}{x}\,dx\\ \text{or}\quad \sin v &= \log|x| + \log|C|\\ \text{or}\quad \sin v &= \log|Cx| \end{aligned} \]

Replacing \(v\) by \(\dfrac{y}{x}\), we get

\[ \sin\left(\frac{y}{x}\right) = \log|Cx| \]

which is the general solution of the differential equation (1).

Example 12

Show that the differential equation \(2y\,e^{\frac{x}{y}}\,dx + \left(y - 2x\,e^{\frac{x}{y}}\right)dy = 0\) is homogeneous and find its particular solution, given that, \(x = 0\) when \(y = 1\).

Solution The given differential equation can be written as

\[ \frac{dx}{dy} = \frac{2x\,e^{\frac{x}{y}} - y}{2y\,e^{\frac{x}{y}}} \tag{1} \]

Let

\[ F(x, y) = \frac{2x e^{\frac{x}{y}} - y}{2y e^{\frac{x}{y}}} \]

Then

\[ F(\lambda x, \lambda y) = \frac{\lambda\left(2x e^{\frac{x}{y}} - y\right)}{\lambda\left(2y e^{\frac{x}{y}}\right)} = \lambda^0\left[F(x, y)\right] \]

Thus, \(F(x, y)\) is a homogeneous function of degree zero. Therefore, the given differential equation is a homogeneous differential equation.

To solve it, we make the substitution

\[ x = vy \tag{2} \]

Differentiating equation (2) with respect to \(y\), we get

\[ \frac{dx}{dy} = v + y\frac{dv}{dy} \]

Substituting the value of \(x\) and \(\dfrac{dx}{dy}\) in equation (1), we get

\[ \begin{aligned} v + y\frac{dv}{dy} &= \frac{2v\,e^{v} - 1}{2e^{v}}\\ \text{or}\quad y\frac{dv}{dy} &= \frac{2v\,e^{v} - 1}{2e^{v}} - v\\ \text{or}\quad y\frac{dv}{dy} &= -\frac{1}{2e^{v}}\\ \text{or}\quad 2e^{v}\,dv &= \frac{-dy}{y}\\ \text{or}\quad \int 2e^{v}\cdot dv &= -\int \frac{dy}{y}\\ \text{or}\quad 2\,e^{v} &= -\log|y| + C \end{aligned} \]

and replacing \(v\) by \(\dfrac{x}{y}\), we get

\[ 2\,e^{\frac{x}{y}} + \log|y| = C \tag{3} \]

Substituting \(x = 0\) and \(y = 1\) in equation (3), we get

\[ 2\,e^{0} + \log|1| = C \Rightarrow C = 2 \]

Substituting the value of C in equation (3), we get

\[ 2\,e^{\frac{x}{y}} + \log|y| = 2 \]

which is the particular solution of the given differential equation.

Example 13

Show that the family of curves for which the slope of the tangent at any point \((x, y)\) on it is \(\dfrac{x^2 + y^2}{2xy}\), is given by \(x^2 - y^2 = cx\).

Solution We know that the slope of the tangent at any point on a curve is \(\dfrac{dy}{dx}\).

Therefore,

\[ \frac{dy}{dx} = \frac{x^2 + y^2}{2xy} \]

or

\[ \frac{dy}{dx} = \frac{1 + \dfrac{y^2}{x^2}}{\dfrac{2y}{x}} \tag{1} \]

Clearly, (1) is a homogenous differential equation. To solve it we make substitution

\[ y = vx \]

Differentiating \(y = vx\) with respect to \(x\), we get

\[ \begin{aligned} \frac{dy}{dx} &= v + x\frac{dv}{dx}\\ \text{or}\quad v + x\frac{dv}{dx} &= \frac{1 + v^2}{2v}\\ \text{or}\quad x\frac{dv}{dx} &= \frac{1 - v^2}{2v}\\ \frac{2v}{1 - v^2}\,dv &= \frac{dx}{x}\\ \text{or}\quad \frac{2v}{v^2 - 1}\,dv &= -\frac{dx}{x} \end{aligned} \]

Therefore

\[ \begin{aligned} \int \frac{2v}{v^2 - 1}\,dv &= -\int \frac{1}{x}\,dx\\ \text{or}\quad \log|v^2 - 1| &= -\log|x| + \log|C_1|\\ \text{or}\quad \log|(v^2 - 1)(x)| &= \log|C_1|\\ \text{or}\quad (v^2 - 1)\,x &= \pm C_1 \end{aligned} \]

Replacing \(v\) by \(\dfrac{y}{x}\), we get

\[ \left(\frac{y^2}{x^2} - 1\right)x = \pm C_1 \]

or

\[ (y^2 - x^2) = \pm C_1\,x \quad \text{or} \quad x^2 - y^2 = Cx \]
Key Insight

Every example follows the same pattern: check that \(F(\lambda x, \lambda y) = \lambda^0 F(x, y)\), substitute \(y = vx\) (or \(x = vy\) when the equation is given as \(\frac{dx}{dy}\)), separate \(v\) from \(x\), integrate, and finally put back \(v = \frac{y}{x}\).
