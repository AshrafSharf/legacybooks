Miscellaneous Examples

Verification, separation, homogeneity and linearity all in one place

Verifying a Solution

Example 19

Verify that the function \(y = c_1 e^{ax}\cos bx + c_2 e^{ax}\sin bx\), where \(c_1, c_2\) are arbitrary constants is a solution of the differential equation

\[ \frac{d^2y}{dx^2} - 2a\frac{dy}{dx} + \left(a^2 + b^2\right)y = 0 \]

Solution The given function is

\[ y = e^{ax}\left[c_1\cos bx + c_2\sin bx\right] \tag{1} \]

Differentiating both sides of equation (1) with respect to \(x\), we get

\[ \frac{dy}{dx} = e^{ax}\left[-bc_1\sin bx + bc_2\cos bx\right] + \left[c_1\cos bx + c_2\sin bx\right]e^{ax}\cdot a \]

or

\[ \frac{dy}{dx} = e^{ax}\left[(bc_2 + ac_1)\cos bx + (ac_2 - bc_1)\sin bx\right] \tag{2} \]

Differentiating both sides of equation (2) with respect to \(x\), we get

\[ \begin{aligned} \frac{d^2y}{dx^2} &= e^{ax}\left[(bc_2 + ac_1)(-b\sin bx) + (ac_2 - bc_1)(b\cos bx)\right]\\ &\quad + \left[(bc_2 + ac_1)\cos bx + (ac_2 - bc_1)\sin bx\right]e^{ax}.a\\ &= e^{ax}\left[(a^2c_2 - 2abc_1 - b^2c_2)\sin bx + (a^2c_1 + 2abc_2 - b^2c_1)\cos bx\right] \end{aligned} \]

Substituting the values of \(\dfrac{d^2y}{dx^2}, \dfrac{dy}{dx}\) and \(y\) in the given differential equation, we get

\[ \begin{aligned} \text{L.H.S.} &= e^{ax}\left[(a^2c_2 - 2abc_1 - b^2c_2)\sin bx + (a^2c_1 + 2abc_2 - b^2c_1)\cos bx\right]\\ &\quad - 2ae^{ax}\left[(bc_2 + ac_1)\cos bx + (ac_2 - bc_1)\sin bx\right]\\ &\quad + (a^2 + b^2)\,e^{ax}\left[c_1\cos bx + c_2\sin bx\right]\\ &= e^{ax}\left[\begin{aligned} &\left(a^2c_2 - 2abc_1 - b^2c_2 - 2a^2c_2 + 2abc_1 + a^2c_2 + b^2c_2\right)\sin bx\\ &+ \left(a^2c_1 + 2abc_2 - b^2c_1 - 2abc_2 - 2a^2c_1 + a^2c_1 + b^2c_1\right)\cos bx \end{aligned}\right]\\ &= e^{ax}\left[0 \times \sin bx + 0\cos bx\right] = e^{ax} \times 0 = 0 = \text{R.H.S.} \end{aligned} \]

Hence, the given function is a solution of the given differential equation.

A Particular Solution by Separation

Example 20

Find the particular solution of the differential equation \(\log\left(\dfrac{dy}{dx}\right) = 3x + 4y\) given that \(y = 0\) when \(x = 0\).

Solution The given differential equation can be written as

\[ \frac{dy}{dx} = e^{(3x + 4y)} \]

or

\[ \frac{dy}{dx} = e^{3x}\,.\,e^{4y} \tag{1} \]

Separating the variables, we get

\[ \frac{dy}{e^{4y}} = e^{3x}\,dx \]

Therefore

\[ \begin{aligned} \int e^{-4y}\,dy &= \int e^{3x}\,dx\\ \text{or}\quad \frac{e^{-4y}}{-4} &= \frac{e^{3x}}{3} + C\\ \text{or}\quad 4\,e^{3x} + 3\,e^{-4y} + 12\,C &= 0 \qquad \text{... (2)} \end{aligned} \]

Substituting \(x = 0\) and \(y = 0\) in (2), we get

\[ 4 + 3 + 12\,C = 0 \quad \text{or} \quad C = \frac{-7}{12} \]

Substituting the value of C in equation (2), we get

\[ 4\,e^{3x} + 3\,e^{-4y} - 7 = 0, \]

which is a particular solution of the given differential equation.

A Homogeneous Equation

Example 21

Solve the differential equation

\[ (x\,dy - y\,dx)\,y\sin\left(\frac{y}{x}\right) = (y\,dx + x\,dy)\,x\cos\left(\frac{y}{x}\right). \]

Solution The given differential equation can be written as

\[ \left[xy\sin\left(\frac{y}{x}\right) - x^2\cos\left(\frac{y}{x}\right)\right]dy = \left[xy\cos\left(\frac{y}{x}\right) + y^2\sin\left(\frac{y}{x}\right)\right]dx \]

or

\[ \frac{dy}{dx} = \frac{xy\cos\left(\frac{y}{x}\right) + y^2\sin\left(\frac{y}{x}\right)}{xy\sin\left(\frac{y}{x}\right) - x^2\cos\left(\frac{y}{x}\right)} \]

Dividing numerator and denominator on RHS by \(x^2\), we get

\[ \frac{dy}{dx} = \frac{\frac{y}{x}\cos\left(\frac{y}{x}\right) + \left(\frac{y^2}{x^2}\right)\sin\left(\frac{y}{x}\right)}{\frac{y}{x}\sin\left(\frac{y}{x}\right) - \cos\left(\frac{y}{x}\right)} \tag{1} \]

Clearly, equation (1) is a homogeneous differential equation of the form \(\dfrac{dy}{dx} = g\left(\dfrac{y}{x}\right)\).

To solve it, we make the substitution

\[ y = vx \tag{2} \] \[ \begin{aligned} \text{or}\quad \frac{dy}{dx} &= v + x\frac{dv}{dx}\\ \text{or}\quad v + x\frac{dv}{dx} &= \frac{v\cos v + v^2\sin v}{v\sin v - \cos v} \qquad \text{(using (1) and (2))}\\ \text{or}\quad x\frac{dv}{dx} &= \frac{2v\cos v}{v\sin v - \cos v}\\ \text{or}\quad \left(\frac{v\sin v - \cos v}{v\cos v}\right)dv &= \frac{2\,dx}{x} \end{aligned} \]

Therefore

\[ \begin{aligned} \int\left(\frac{v\sin v - \cos v}{v\cos v}\right)dv &= 2\int \frac{1}{x}\,dx\\ \text{or}\quad \int \tan v\,dv - \int \frac{1}{v}\,dv &= 2\int \frac{1}{x}\,dx\\ \text{or}\quad \log|\sec v| - \log|v| &= 2\log|x| + \log|C_1|\\ \text{or}\quad \log\left|\frac{\sec v}{v\,x^2}\right| &= \log|C_1|\\ \text{or}\quad \frac{\sec v}{v\,x^2} &= \pm C_1 \qquad \text{... (3)} \end{aligned} \]

Replacing \(v\) by \(\dfrac{y}{x}\) in equation (3), we get

\[ \frac{\sec\left(\frac{y}{x}\right)}{\left(\frac{y}{x}\right)(x^2)} = C \quad \text{where, } C = \pm C_1 \]

or

\[ \sec\left(\frac{y}{x}\right) = C\,xy \]

which is the general solution of the given differential equation.

A Linear Equation in x

Example 22

Solve the differential equation

\[ (\tan^{-1} y - x)\,dy = (1 + y^2)\,dx. \]

Solution The given differential equation can be written as

\[ \frac{dx}{dy} + \frac{x}{1 + y^2} = \frac{\tan^{-1} y}{1 + y^2} \tag{1} \]

Now (1) is a linear differential equation of the form \(\dfrac{dx}{dy} + P_1 x = Q_1\),

where, \(P_1 = \dfrac{1}{1 + y^2}\) and \(Q_1 = \dfrac{\tan^{-1} y}{1 + y^2}\).

Therefore,

\[ \text{I.F} = e^{\int \frac{1}{1 + y^2}\,dy} = e^{\tan^{-1} y} \]

Thus, the solution of the given differential equation is

\[ x\,e^{\tan^{-1} y} = \int\left(\frac{\tan^{-1} y}{1 + y^2}\right)e^{\tan^{-1} y}\,dy + C \tag{2} \]

Let

\[ I = \int\left(\frac{\tan^{-1} y}{1 + y^2}\right)e^{\tan^{-1} y}\,dy \]

Substituting \(\tan^{-1} y = t\) so that \(\left(\dfrac{1}{1 + y^2}\right)dy = dt\), we get

\[ I = \int t\,e^{t}\,dt = t\,e^{t} - \int 1\,.\,e^{t}\,dt = t\,e^{t} - e^{t} = e^{t}(t - 1) \]

or

\[ I = e^{\tan^{-1} y}(\tan^{-1} y - 1) \]

Substituting the value of I in equation (2), we get

\[ x\,.\,e^{\tan^{-1} y} = e^{\tan^{-1} y}(\tan^{-1} y - 1) + C \]

or

\[ x = (\tan^{-1} y - 1) + C\,e^{-\tan^{-1} y} \]

which is the general solution of the given differential equation.
