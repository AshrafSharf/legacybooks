7.6.1 Integral of the type ∫eˣ[f(x) + f′(x)] dx

Spot a function paired with its own derivative, and the answer is simply eˣ f(x) + C

In This Section

  • A shortcut result obtained from integration by parts
  • Recognising integrands of the form \( e^x[f(x) + f'(x)] \)
  • Rewriting an integrand to expose the pattern (Example 22)

Deriving the Result

We have

\[ \begin{aligned} I = \int e^x [f(x) + f'(x)]\,dx &= \int e^x f(x)\,dx + \int e^x f'(x)\,dx \\ &= I_1 + \int e^x f'(x)\,dx, \quad \text{where } I_1 = \int e^x f(x)\,dx \end{aligned} \tag{1} \]

Taking \(f(x)\) and \(e^x\) as the first function and second function, respectively, in \(I_1\) and integrating it by parts, we have

\[ I_1 = f(x)\,e^x - \int f'(x)\,e^x\,dx + C \]

Substituting \(I_1\) in (1), we get

\[ I = e^x f(x) - \int f'(x)\,e^x\,dx + \int e^x f'(x)\,dx + C = e^x f(x) + C \]

Thus,

Result
\[ \int e^x [f(x) + f'(x)]\,dx = e^x f(x) + C \]
Key Insight

This is just the product rule read backwards: \( \dfrac{d}{dx}\left[ e^x f(x) \right] = e^x f(x) + e^x f'(x) \). Whenever the bracket beside \(e^x\) splits into “a function plus its derivative”, you can write the answer down at once.

Worked Example

Example 22

Find (i) \( \displaystyle \int e^x \left( \tan^{-1} x + \frac{1}{1 + x^2} \right) dx \)     (ii) \( \displaystyle \int \frac{(x^2 + 1)\,e^x}{(x + 1)^2}\,dx \)

Solution

(i) We have

\[ I = \int e^x \left( \tan^{-1} x + \frac{1}{1 + x^2} \right) dx \]

Consider \( f(x) = \tan^{-1} x \), then \( f'(x) = \dfrac{1}{1 + x^2} \)

Thus, the given integrand is of the form \( e^x[f(x) + f'(x)] \).

Therefore,

\[ I = \int e^x \left( \tan^{-1} x + \frac{1}{1 + x^2} \right) dx = e^x \tan^{-1} x + C \]

(ii) We have

\[ \begin{aligned} I = \int \frac{(x^2 + 1)\,e^x}{(x + 1)^2}\,dx &= \int e^x \left[ \frac{x^2 - 1 + 1 + 1}{(x + 1)^2} \right] dx \\ &= \int e^x \left[ \frac{x^2 - 1}{(x + 1)^2} + \frac{2}{(x + 1)^2} \right] dx = \int e^x \left[ \frac{x - 1}{x + 1} + \frac{2}{(x + 1)^2} \right] dx \end{aligned} \]

Consider \( f(x) = \dfrac{x - 1}{x + 1} \), then \( f'(x) = \dfrac{2}{(x + 1)^2} \)

Thus, the given integrand is of the form \( e^x[f(x) + f'(x)] \).

Therefore,

\[ \int \frac{x^2 + 1}{(x + 1)^2}\,e^x\,dx = \frac{x - 1}{x + 1}\,e^x + C \]
