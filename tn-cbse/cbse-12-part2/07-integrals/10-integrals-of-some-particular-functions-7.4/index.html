7.4 Integrals of Some Particular Functions

Six standard integrals &mdash; and how completing the square turns any quadratic denominator into one of them

In This Section

  • Six standard integrals involving \(x^2 \pm a^2\), \(a^2 - x^2\) and their square roots
  • Proofs of the six formulae using partial splitting and trigonometric substitutions
  • Integrating \(\dfrac{1}{ax^2+bx+c}\) and \(\dfrac{1}{\sqrt{ax^2+bx+c}}\) by completing the square
  • Integrating \(\dfrac{px+q}{ax^2+bx+c}\) and \(\dfrac{px+q}{\sqrt{ax^2+bx+c}}\) by writing the numerator as A(derivative) + B
  • Worked Examples 8, 9 and 10

Six Important Formulae

In this section, we mention below some important formulae of integrals and apply them for integrating many other related standard integrals:

Standard Integrals
(1)\( \displaystyle \int \frac{dx}{x^2 - a^2} = \frac{1}{2a} \log \left| \frac{x-a}{x+a} \right| + C \)
(2)\( \displaystyle \int \frac{dx}{a^2 - x^2} = \frac{1}{2a} \log \left| \frac{a+x}{a-x} \right| + C \)
(3)\( \displaystyle \int \frac{dx}{x^2 + a^2} = \frac{1}{a} \tan^{-1} \frac{x}{a} + C \)
(4)\( \displaystyle \int \frac{dx}{\sqrt{x^2 - a^2}} = \log \left| x + \sqrt{x^2 - a^2} \right| + C \)
(5)\( \displaystyle \int \frac{dx}{\sqrt{a^2 - x^2}} = \sin^{-1} \frac{x}{a} + C \)
(6)\( \displaystyle \int \frac{dx}{\sqrt{x^2 + a^2}} = \log \left| x + \sqrt{x^2 + a^2} \right| + C \)
Key Insight

Formulae (1)–(3) have a quadratic denominator with no root; (4)–(6) have its square root. Notice the pattern: a difference of squares gives a logarithm, while \(a^2 - x^2\) under a root and \(x^2 + a^2\) without a root give inverse trigonometric functions.

Proofs of the Formulae

We now prove the above results:

(1) \( \int \frac{dx}{x^2 - a^2} \)

We have

\[ \frac{1}{x^2 - a^2} = \frac{1}{(x-a)(x+a)} = \frac{1}{2a}\left[ \frac{(x+a) - (x-a)}{(x-a)(x+a)} \right] = \frac{1}{2a}\left[ \frac{1}{x-a} - \frac{1}{x+a} \right] \]

Therefore,

\[ \begin{aligned} \int \frac{dx}{x^2 - a^2} &= \frac{1}{2a}\left[ \int \frac{dx}{x-a} - \int \frac{dx}{x+a} \right] \\ &= \frac{1}{2a}\left[ \log|(x-a)| - \log|(x+a)| \right] + C \\ &= \frac{1}{2a} \log \left| \frac{x-a}{x+a} \right| + C \end{aligned} \]

(2) \( \int \frac{dx}{a^2 - x^2} \)

In view of (1) above, we have

\[ \frac{1}{a^2 - x^2} = \frac{1}{2a}\left[ \frac{(a+x) + (a-x)}{(a+x)(a-x)} \right] = \frac{1}{2a}\left[ \frac{1}{a-x} + \frac{1}{a+x} \right] \]

Therefore,

\[ \begin{aligned} \int \frac{dx}{a^2 - x^2} &= \frac{1}{2a}\left[ \int \frac{dx}{a-x} + \int \frac{dx}{a+x} \right] \\ &= \frac{1}{2a}\left[ -\log|a-x| + \log|a+x| \right] + C \\ &= \frac{1}{2a} \log \left| \frac{a+x}{a-x} \right| + C \end{aligned} \]
Note

The technique used in (1) will be explained in Section 7.5.

(3) \( \int \frac{dx}{x^2 + a^2} \)

Put \(x = a \tan\theta\). Then \(dx = a \sec^2\theta \, d\theta\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{x^2 + a^2} &= \int \frac{a \sec^2\theta \, d\theta}{a^2 \tan^2\theta + a^2} \\ &= \frac{1}{a} \int d\theta = \frac{1}{a}\theta + C = \frac{1}{a} \tan^{-1} \frac{x}{a} + C \end{aligned} \]

(4) \( \int \frac{dx}{\sqrt{x^2 - a^2}} \)

Let \(x = a \sec\theta\). Then \(dx = a \sec\theta \tan\theta \, d\theta\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{\sqrt{x^2 - a^2}} &= \int \frac{a \sec\theta \tan\theta \, d\theta}{\sqrt{a^2 \sec^2\theta - a^2}} \\ &= \int \sec\theta \, d\theta = \log|\sec\theta + \tan\theta| + C_1 \\ &= \log \left| \frac{x}{a} + \sqrt{\frac{x^2}{a^2} - 1} \right| + C_1 \\ &= \log \left| x + \sqrt{x^2 - a^2} \right| - \log|a| + C_1 \\ &= \log \left| x + \sqrt{x^2 - a^2} \right| + C, \quad \text{where } C = C_1 - \log|a| \end{aligned} \]

(5) \( \int \frac{dx}{\sqrt{a^2 - x^2}} \)

Let \(x = a \sin\theta\). Then \(dx = a \cos\theta \, d\theta\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{\sqrt{a^2 - x^2}} &= \int \frac{a \cos\theta \, d\theta}{\sqrt{a^2 - a^2 \sin^2\theta}} \\ &= \int d\theta = \theta + C = \sin^{-1} \frac{x}{a} + C \end{aligned} \]

(6) \( \int \frac{dx}{\sqrt{x^2 + a^2}} \)

Let \(x = a \tan\theta\). Then \(dx = a \sec^2\theta \, d\theta\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{\sqrt{x^2 + a^2}} &= \int \frac{a \sec^2\theta \, d\theta}{\sqrt{a^2 \tan^2\theta + a^2}} \\ &= \int \sec\theta \, d\theta = \log|(\sec\theta + \tan\theta)| + C_1 \\ &= \log \left| \frac{x}{a} + \sqrt{\frac{x^2}{a^2} + 1} \right| + C_1 \\ &= \log \left| x + \sqrt{x^2 + a^2} \right| - \log|a| + C_1 \\ &= \log \left| x + \sqrt{x^2 + a^2} \right| + C, \quad \text{where } C = C_1 - \log|a| \end{aligned} \]

More Formulae from the Standard Ones

Applying these standard formulae, we now obtain some more formulae which are useful from applications point of view and can be applied directly to evaluate other integrals.

(7) To find the integral \( \int \frac{dx}{ax^2 + bx + c} \)

We write

\[ ax^2 + bx + c = a\left[ x^2 + \frac{b}{a}x + \frac{c}{a} \right] = a\left[ \left( x + \frac{b}{2a} \right)^2 + \left( \frac{c}{a} - \frac{b^2}{4a^2} \right) \right] \]

Now, put \( x + \dfrac{b}{2a} = t \) so that \(dx = dt\) and writing \( \dfrac{c}{a} - \dfrac{b^2}{4a^2} = \pm k^2 \). We find the integral reduced to the form \( \dfrac{1}{a} \displaystyle\int \frac{dt}{t^2 \pm k^2} \) depending upon the sign of \( \left( \dfrac{c}{a} - \dfrac{b^2}{4a^2} \right) \) and hence can be evaluated.

(8) To find the integral of the type \( \int \frac{dx}{\sqrt{ax^2 + bx + c}} \)

Proceeding as in (7), we obtain the integral using the standard formulae.

(9) To find the integral of the type \( \int \frac{px + q}{ax^2 + bx + c}\,dx \)

where \(p, q, a, b, c\) are constants, we are to find real numbers A, B such that

\[ px + q = A \frac{d}{dx}(ax^2 + bx + c) + B = A(2ax + b) + B \]

To determine A and B, we equate from both sides the coefficients of \(x\) and the constant terms. A and B are thus obtained and hence the integral is reduced to one of the known forms.

(10) For the evaluation of the integral of the type \( \int \frac{(px + q)\,dx}{\sqrt{ax^2 + bx + c}} \)

We proceed as in (9) and transform the integral into known standard forms.

Key Insight

In (9) and (10) the numerator is split into a multiple of the derivative of the denominator (handled by the substitution \(t = ax^2+bx+c\)) plus a constant (handled by completing the square, as in (7) or (8)).

Let us illustrate the above methods by some examples.

Worked Examples

Example 8

Find the following integrals:

(i) \( \displaystyle \int \frac{dx}{x^2 - 16} \)     (ii) \( \displaystyle \int \frac{dx}{\sqrt{2x - x^2}} \)

Solution

(i) We have

\[ \int \frac{dx}{x^2 - 16} = \int \frac{dx}{x^2 - 4^2} = \frac{1}{8} \log \left| \frac{x-4}{x+4} \right| + C \qquad \text{[by 7.4 (1)]} \]

(ii)

\[ \int \frac{dx}{\sqrt{2x - x^2}} = \int \frac{dx}{\sqrt{1 - (x-1)^2}} \]

Put \(x - 1 = t\). Then \(dx = dt\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{\sqrt{2x - x^2}} &= \int \frac{dt}{\sqrt{1 - t^2}} = \sin^{-1}(t) + C && \text{[by 7.4 (5)]} \\ &= \sin^{-1}(x - 1) + C \end{aligned} \]
Example 9

Find the following integrals:

(i) \( \displaystyle \int \frac{dx}{x^2 - 6x + 13} \)     (ii) \( \displaystyle \int \frac{dx}{3x^2 + 13x - 10} \)     (iii) \( \displaystyle \int \frac{dx}{\sqrt{5x^2 - 2x}} \)

Solution

(i) We have \( x^2 - 6x + 13 = x^2 - 6x + 3^2 - 3^2 + 13 = (x-3)^2 + 4 \)

So,

\[ \int \frac{dx}{x^2 - 6x + 13} = \int \frac{1}{(x-3)^2 + 2^2}\,dx \]

Let \(x - 3 = t\). Then \(dx = dt\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{x^2 - 6x + 13} &= \int \frac{dt}{t^2 + 2^2} = \frac{1}{2} \tan^{-1} \frac{t}{2} + C && \text{[by 7.4 (3)]} \\ &= \frac{1}{2} \tan^{-1} \frac{x-3}{2} + C \end{aligned} \]

(ii) The given integral is of the form 7.4 (7). We write the denominator of the integrand,

\[ \begin{aligned} 3x^2 + 13x - 10 &= 3\left( x^2 + \frac{13x}{3} - \frac{10}{3} \right) \\ &= 3\left[ \left( x + \frac{13}{6} \right)^2 - \left( \frac{17}{6} \right)^2 \right] \quad \text{(completing the square)} \end{aligned} \]

Thus

\[ \int \frac{dx}{3x^2 + 13x - 10} = \frac{1}{3} \int \frac{dx}{\left( x + \frac{13}{6} \right)^2 - \left( \frac{17}{6} \right)^2} \]

Put \( x + \dfrac{13}{6} = t \). Then \(dx = dt\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{3x^2 + 13x - 10} &= \frac{1}{3} \int \frac{dt}{t^2 - \left( \frac{17}{6} \right)^2} \\ &= \frac{1}{3 \times 2 \times \frac{17}{6}} \log \left| \frac{t - \frac{17}{6}}{t + \frac{17}{6}} \right| + C_1 \qquad \text{[by 7.4 (1)]} \\ &= \frac{1}{17} \log \left| \frac{x + \frac{13}{6} - \frac{17}{6}}{x + \frac{13}{6} + \frac{17}{6}} \right| + C_1 \\ &= \frac{1}{17} \log \left| \frac{6x - 4}{6x + 30} \right| + C_1 \\ &= \frac{1}{17} \log \left| \frac{3x - 2}{x + 5} \right| + C_1 + \frac{1}{17} \log \frac{1}{3} \\ &= \frac{1}{17} \log \left| \frac{3x - 2}{x + 5} \right| + C, \quad \text{where } C = C_1 + \frac{1}{17} \log \frac{1}{3} \end{aligned} \]

(iii) We have

\[ \begin{aligned} \int \frac{dx}{\sqrt{5x^2 - 2x}} &= \int \frac{dx}{\sqrt{5\left( x^2 - \frac{2x}{5} \right)}} \\ &= \frac{1}{\sqrt{5}} \int \frac{dx}{\sqrt{\left( x - \frac{1}{5} \right)^2 - \left( \frac{1}{5} \right)^2}} \quad \text{(completing the square)} \end{aligned} \]

Put \( x - \dfrac{1}{5} = t \). Then \(dx = dt\).

Therefore,

\[ \begin{aligned} \int \frac{dx}{\sqrt{5x^2 - 2x}} &= \frac{1}{\sqrt{5}} \int \frac{dt}{\sqrt{t^2 - \left( \frac{1}{5} \right)^2}} \\ &= \frac{1}{\sqrt{5}} \log \left| t + \sqrt{t^2 - \left( \frac{1}{5} \right)^2} \right| + C \qquad \text{[by 7.4 (4)]} \\ &= \frac{1}{\sqrt{5}} \log \left| x - \frac{1}{5} + \sqrt{x^2 - \frac{2x}{5}} \right| + C \end{aligned} \]
Example 10

Find the following integrals:

(i) \( \displaystyle \int \frac{x + 2}{2x^2 + 6x + 5}\,dx \)     (ii) \( \displaystyle \int \frac{x + 3}{\sqrt{5 - 4x - x^2}}\,dx \)

Solution

(i) Using the formula 7.4 (9), we express

\[ x + 2 = A \frac{d}{dx}\left( 2x^2 + 6x + 5 \right) + B = A(4x + 6) + B \]

Equating the coefficients of \(x\) and the constant terms from both sides, we get

\[ 4A = 1 \ \text{ and } \ 6A + B = 2 \quad \text{or} \quad A = \frac{1}{4} \ \text{ and } \ B = \frac{1}{2}. \]

Therefore,

\[ \begin{aligned} \int \frac{x + 2}{2x^2 + 6x + 5} &= \frac{1}{4} \int \frac{4x + 6}{2x^2 + 6x + 5}\,dx + \frac{1}{2} \int \frac{dx}{2x^2 + 6x + 5} \\ &= \frac{1}{4} I_1 + \frac{1}{2} I_2 \quad \text{(say)} \end{aligned} \tag{1} \]

In \(I_1\), put \(2x^2 + 6x + 5 = t\), so that \((4x + 6)\,dx = dt\).

Therefore,

\[ \begin{aligned} I_1 &= \int \frac{dt}{t} = \log|t| + C_1 \\ &= \log|2x^2 + 6x + 5| + C_1 \end{aligned} \tag{2} \]

and

\[ \begin{aligned} I_2 &= \int \frac{dx}{2x^2 + 6x + 5} = \frac{1}{2} \int \frac{dx}{x^2 + 3x + \frac{5}{2}} \\ &= \frac{1}{2} \int \frac{dx}{\left( x + \frac{3}{2} \right)^2 + \left( \frac{1}{2} \right)^2} \end{aligned} \]

Put \( x + \dfrac{3}{2} = t \), so that \(dx = dt\), we get

\[ \begin{aligned} I_2 &= \frac{1}{2} \int \frac{dt}{t^2 + \left( \frac{1}{2} \right)^2} = \frac{1}{2 \times \frac{1}{2}} \tan^{-1} 2t + C_2 \qquad \text{[by 7.4 (3)]} \\ &= \tan^{-1} 2\left( x + \frac{3}{2} \right) + C_2 = \tan^{-1}(2x + 3) + C_2 \end{aligned} \tag{3} \]

Using (2) and (3) in (1), we get

\[ \int \frac{x + 2}{2x^2 + 6x + 5}\,dx = \frac{1}{4} \log\left| 2x^2 + 6x + 5 \right| + \frac{1}{2} \tan^{-1}(2x + 3) + C \]

where, \( C = \dfrac{C_1}{4} + \dfrac{C_2}{2} \)

(ii) This integral is of the form given in 7.4 (10). Let us express

\[ x + 3 = A \frac{d}{dx}(5 - 4x - x^2) + B = A(-4 - 2x) + B \]

Equating the coefficients of \(x\) and the constant terms from both sides, we get

\[ -2A = 1 \ \text{ and } \ -4A + B = 3, \ \text{ i.e., } \ A = -\frac{1}{2} \ \text{ and } \ B = 1 \]

Therefore,

\[ \begin{aligned} \int \frac{x + 3}{\sqrt{5 - 4x - x^2}}\,dx &= -\frac{1}{2} \int \frac{(-4 - 2x)\,dx}{\sqrt{5 - 4x - x^2}} + \int \frac{dx}{\sqrt{5 - 4x - x^2}} \\ &= -\frac{1}{2} I_1 + I_2 \end{aligned} \tag{1} \]

In \(I_1\), put \(5 - 4x - x^2 = t\), so that \((-4 - 2x)\,dx = dt\).

Therefore,

\[ \begin{aligned} I_1 &= \int \frac{(-4 - 2x)\,dx}{\sqrt{5 - 4x - x^2}} = \int \frac{dt}{\sqrt{t}} = 2\sqrt{t} + C_1 \\ &= 2\sqrt{5 - 4x - x^2} + C_1 \end{aligned} \tag{2} \]

Now consider

\[ I_2 = \int \frac{dx}{\sqrt{5 - 4x - x^2}} = \int \frac{dx}{\sqrt{9 - (x + 2)^2}} \]

Put \(x + 2 = t\), so that \(dx = dt\).

Therefore,

\[ \begin{aligned} I_2 &= \int \frac{dt}{\sqrt{3^2 - t^2}} = \sin^{-1} \frac{t}{3} + C_2 \qquad \text{[by 7.4 (5)]} \\ &= \sin^{-1} \frac{x + 2}{3} + C_2 \end{aligned} \tag{3} \]

Substituting (2) and (3) in (1), we obtain

\[ \int \frac{x + 3}{\sqrt{5 - 4x - x^2}} = -\sqrt{5 - 4x - x^2} + \sin^{-1} \frac{x + 2}{3} + C, \quad \text{where } C = C_2 - \frac{C_1}{2} \]
