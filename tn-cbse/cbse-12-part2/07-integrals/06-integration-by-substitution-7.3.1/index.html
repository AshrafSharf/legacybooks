7.3.1 Integration by substitution

Change the variable, and a tangled integrand collapses into a standard form

In This Section

  • The change of variable formula \( \int f(x)\,dx = \int f(g(t))\,g'(t)\,dt \)
  • Choosing a substitution: look for a function whose derivative also occurs in the integrand
  • Standard integrals of \( \tan x,\ \cot x,\ \sec x \) and \( \operatorname{cosec} x \)
  • Worked Examples 5 and 6

The Change of Variable Formula

In this section, we consider the method of integration by substitution.

The given integral \( \int f(x)\,dx \) can be transformed into another form by changing the independent variable \( x \) to \( t \) by substituting \( x = g(t) \).

1
Consider \( \text{I} = \int f(x)\,dx \).
2
Put \( x = g(t) \) so that \( \dfrac{dx}{dt} = g'(t) \).
3
We write \( dx = g'(t)\,dt \).
4
Thus \( \text{I} = \displaystyle\int f(x)\,dx = \int f(g(t))\,g'(t)\,dt \).
Integration by Substitution
\[ \int f(x)\,dx = \int f(g(t))\,g'(t)\,dt,\qquad x = g(t) \]

This change of variable formula is one of the important tools available to us in the name of integration by substitution. It is often important to guess what will be the useful substitution. Usually, we make a substitution for a function whose derivative also occurs in the integrand as illustrated in the following examples.

Example 5

Integrate the following functions w.r.t. \( x \):

(i) \( \sin mx \)     (ii) \( 2x\sin(x^2 + 1) \)     (iii) \( \dfrac{\tan^4\sqrt{x}\,\sec^2\sqrt{x}}{\sqrt{x}} \)     (iv) \( \dfrac{\sin(\tan^{-1} x)}{1 + x^2} \)

Solution

(i) We know that derivative of \( mx \) is \( m \). Thus, we make the substitution \( mx = t \) so that \( m\,dx = dt \).

\[ \text{Therefore,}\quad \int \sin mx\,dx = \frac{1}{m}\int \sin t\,dt = -\frac{1}{m}\cos t + \text{C} = -\frac{1}{m}\cos mx + \text{C} \]

(ii) Derivative of \( x^2 + 1 \) is \( 2x \). Thus, we use the substitution \( x^2 + 1 = t \) so that \( 2x\,dx = dt \).

\[ \text{Therefore,}\quad \int 2x\sin(x^2 + 1)\,dx = \int \sin t\,dt = -\cos t + \text{C} = -\cos(x^2 + 1) + \text{C} \]

(iii) Derivative of \( \sqrt{x} \) is \( \dfrac{1}{2}x^{-\frac{1}{2}} = \dfrac{1}{2\sqrt{x}} \). Thus, we use the substitution

\[ \sqrt{x} = t \ \text{ so that }\ \frac{1}{2\sqrt{x}}\,dx = dt \ \text{ giving }\ dx = 2t\,dt. \] \[ \text{Thus,}\quad \int \frac{\tan^4\sqrt{x}\,\sec^2\sqrt{x}}{\sqrt{x}}\,dx = \int \frac{2t\tan^4 t\,\sec^2 t\,dt}{t} = 2\int \tan^4 t\,\sec^2 t\,dt \]

Again, we make another substitution \( \tan t = u \) so that \( \sec^2 t\,dt = du \).

\[ \begin{aligned} \text{Therefore,}\quad 2\int \tan^4 t\,\sec^2 t\,dt &= 2\int u^4\,du = 2\frac{u^5}{5} + \text{C} \\ &= \frac{2}{5}\tan^5 t + \text{C} \quad (\text{since } u = \tan t) \\ &= \frac{2}{5}\tan^5\sqrt{x} + \text{C} \quad (\text{since } t = \sqrt{x}) \end{aligned} \] \[ \text{Hence,}\quad \int \frac{\tan^4\sqrt{x}\,\sec^2\sqrt{x}}{\sqrt{x}}\,dx = \frac{2}{5}\tan^5\sqrt{x} + \text{C} \]

Alternatively, make the substitution \( \tan\sqrt{x} = t \).

(iv) Derivative of \( \tan^{-1} x = \dfrac{1}{1 + x^2} \). Thus, we use the substitution

\[ \tan^{-1} x = t \ \text{ so that }\ \frac{dx}{1 + x^2} = dt. \] \[ \text{Therefore,}\quad \int \frac{\sin(\tan^{-1} x)}{1 + x^2}\,dx = \int \sin t\,dt = -\cos t + \text{C} = -\cos(\tan^{-1} x) + \text{C} \]

Four Important Trigonometric Integrals

Now, we discuss some important integrals involving trigonometric functions and their standard integrals using substitution technique. These will be used later without reference.

Standard Integrals
(i)\( \displaystyle\int \tan x\,dx = \log|\sec x| + \text{C} \)
(ii)\( \displaystyle\int \cot x\,dx = \log|\sin x| + \text{C} \)
(iii)\( \displaystyle\int \sec x\,dx = \log|\sec x + \tan x| + \text{C} \)
(iv)\( \displaystyle\int \operatorname{cosec} x\,dx = \log|\operatorname{cosec} x - \cot x| + \text{C} \)

(i) \( \int \tan x\,dx = \log|\sec x| + \text{C} \)

We have

\[ \int \tan x\,dx = \int \frac{\sin x}{\cos x}\,dx \]

Put \( \cos x = t \) so that \( \sin x\,dx = -dt \).

\[ \text{Then}\quad \int \tan x\,dx = -\int \frac{dt}{t} = -\log|t| + \text{C} = -\log|\cos x| + \text{C} \] \[ \text{or}\quad \int \tan x\,dx = \log|\sec x| + \text{C} \]

(ii) \( \int \cot x\,dx = \log|\sin x| + \text{C} \)

We have \( \displaystyle\int \cot x\,dx = \int \frac{\cos x}{\sin x}\,dx \).

Put \( \sin x = t \) so that \( \cos x\,dx = dt \).

\[ \text{Then}\quad \int \cot x\,dx = \int \frac{dt}{t} = \log|t| + \text{C} = \log|\sin x| + \text{C} \]

(iii) \( \int \sec x\,dx = \log|\sec x + \tan x| + \text{C} \)

We have

\[ \int \sec x\,dx = \int \frac{\sec x\,(\sec x + \tan x)}{\sec x + \tan x}\,dx \]

Put \( \sec x + \tan x = t \) so that \( \sec x\,(\tan x + \sec x)\,dx = dt \).

\[ \text{Therefore,}\quad \int \sec x\,dx = \int \frac{dt}{t} = \log|t| + \text{C} = \log|\sec x + \tan x| + \text{C} \]

(iv) \( \int \operatorname{cosec} x\,dx = \log|\operatorname{cosec} x - \cot x| + \text{C} \)

We have

\[ \int \operatorname{cosec} x\,dx = \int \frac{\operatorname{cosec} x\,(\operatorname{cosec} x + \cot x)}{(\operatorname{cosec} x + \cot x)}\,dx \]

Put \( \operatorname{cosec} x + \cot x = t \) so that \( -\operatorname{cosec} x\,(\operatorname{cosec} x + \cot x)\,dx = dt \).

\[ \begin{aligned} \text{So}\quad \int \operatorname{cosec} x\,dx &= -\int \frac{dt}{t} = -\log|t| = -\log|\operatorname{cosec} x + \cot x| + \text{C} \\ &= -\log\left|\frac{\operatorname{cosec}^2 x - \cot^2 x}{\operatorname{cosec} x - \cot x}\right| + \text{C} \\ &= \log|\operatorname{cosec} x - \cot x| + \text{C} \end{aligned} \]

More Substitutions

Example 6

Find the following integrals:

(i) \( \int \sin^3 x\cos^2 x\,dx \)     (ii) \( \displaystyle\int \frac{\sin x}{\sin(x + a)}\,dx \)     (iii) \( \displaystyle\int \frac{1}{1 + \tan x}\,dx \)

Solution

(i) We have

\[ \begin{aligned} \int \sin^3 x\cos^2 x\,dx &= \int \sin^2 x\cos^2 x\,(\sin x)\,dx \\ &= \int (1 - \cos^2 x)\cos^2 x\,(\sin x)\,dx \end{aligned} \]

Put \( t = \cos x \) so that \( dt = -\sin x\,dx \).

\[ \begin{aligned} \text{Therefore,}\quad \int \sin^2 x\cos^2 x\,(\sin x)\,dx &= -\int (1 - t^2)\,t^2\,dt \\ &= -\int (t^2 - t^4)\,dt = -\left(\frac{t^3}{3} - \frac{t^5}{5}\right) + \text{C} \\ &= -\frac{1}{3}\cos^3 x + \frac{1}{5}\cos^5 x + \text{C} \end{aligned} \]

(ii) Put \( x + a = t \). Then \( dx = dt \). Therefore

\[ \begin{aligned} \int \frac{\sin x}{\sin(x + a)}\,dx &= \int \frac{\sin(t - a)}{\sin t}\,dt \\ &= \int \frac{\sin t\cos a - \cos t\sin a}{\sin t}\,dt \\ &= \cos a\int dt - \sin a\int \cot t\,dt \\ &= (\cos a)\,t - (\sin a)\big[\log|\sin t| + \text{C}_1\big] \\ &= (\cos a)(x + a) - (\sin a)\big[\log|\sin(x + a)| + \text{C}_1\big] \\ &= x\cos a + a\cos a - (\sin a)\log|\sin(x + a)| - \text{C}_1\sin a \end{aligned} \] \[ \text{Hence,}\quad \int \frac{\sin x}{\sin(x + a)}\,dx = x\cos a - \sin a\log|\sin(x + a)| + \text{C}, \]

where, \( \text{C} = -\text{C}_1\sin a + a\cos a \), is another arbitrary constant.

(iii)

\[ \begin{aligned} \int \frac{dx}{1 + \tan x} &= \int \frac{\cos x\,dx}{\cos x + \sin x} \\ &= \frac{1}{2}\int \frac{(\cos x + \sin x + \cos x - \sin x)\,dx}{\cos x + \sin x} \\ &= \frac{1}{2}\int dx + \frac{1}{2}\int \frac{\cos x - \sin x}{\cos x + \sin x}\,dx \\ &= \frac{x}{2} + \frac{\text{C}_1}{2} + \frac{1}{2}\int \frac{\cos x - \sin x}{\cos x + \sin x}\,dx \end{aligned} \tag{1} \]

Now, consider \( \text{I} = \displaystyle\int \frac{\cos x - \sin x}{\cos x + \sin x}\,dx \).

Put \( \cos x + \sin x = t \) so that \( (\cos x - \sin x)\,dx = dt \).

\[ \text{Therefore}\quad \text{I} = \int \frac{dt}{t} = \log|t| + \text{C}_2 = \log|\cos x + \sin x| + \text{C}_2 \]

Putting it in (1), we get

\[ \begin{aligned} \int \frac{dx}{1 + \tan x} &= \frac{x}{2} + \frac{\text{C}_1}{2} + \frac{1}{2}\log|\cos x + \sin x| + \frac{\text{C}_2}{2} \\ &= \frac{x}{2} + \frac{1}{2}\log|\cos x + \sin x| + \frac{\text{C}_1}{2} + \frac{\text{C}_2}{2} \\ &= \frac{x}{2} + \frac{1}{2}\log|\cos x + \sin x| + \text{C},\ \left(\text{C} = \frac{\text{C}_1}{2} + \frac{\text{C}_2}{2}\right) \end{aligned} \]
