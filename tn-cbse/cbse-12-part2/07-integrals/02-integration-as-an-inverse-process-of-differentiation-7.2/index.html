7.2 Integration as an Inverse Process of Differentiation

Run differentiation backwards — and meet the arbitrary constant C that comes along for the ride

In This Section

  • Integration (anti differentiation) as the reverse of differentiation
  • Why anti derivatives are not unique: the arbitrary constant C
  • Why functions with the same derivative differ only by a constant
  • The symbol \( \int f(x)\,dx \) and the vocabulary of integration (Table 7.1)
  • The list of standard integrals read off from known derivatives

Undoing a Derivative

Integration is the inverse process of differentiation. Instead of differentiating a function, we are given the derivative of a function and asked to find its primitive, i.e., the original function. Such a process is called integration or anti differentiation.

Let us consider the following examples. We know that

\[ \frac{d}{dx}(\sin x) = \cos x \tag{1} \] \[ \frac{d}{dx}\left(\frac{x^3}{3}\right) = x^2 \tag{2} \] \[ \text{and}\qquad \frac{d}{dx}\left(e^x\right) = e^x \tag{3} \]

We observe that in (1), the function \( \cos x \) is the derived function of \( \sin x \). We say that \( \sin x \) is an anti derivative (or an integral) of \( \cos x \). Similarly, in (2) and (3), \( \dfrac{x^3}{3} \) and \( e^x \) are the anti derivatives (or integrals) of \( x^2 \) and \( e^x \), respectively.

Again, we note that for any real number C, treated as constant function, its derivative is zero and hence, we can write (1), (2) and (3) as follows:

\[ \frac{d}{dx}(\sin x + \text{C}) = \cos x,\qquad \frac{d}{dx}\left(\frac{x^3}{3} + \text{C}\right) = x^2 \qquad\text{and}\qquad \frac{d}{dx}\left(e^x + \text{C}\right) = e^x \]

Thus, anti derivatives (or integrals) of the above cited functions are not unique. Actually, there exist infinitely many anti derivatives of each of these functions which can be obtained by choosing C arbitrarily from the set of real numbers. For this reason C is customarily referred to as arbitrary constant. In fact, C is the parameter by varying which one gets different anti derivatives (or integrals) of the given function.

Family of Anti derivatives

More generally, if there is a function F such that \( \dfrac{d}{dx}\text{F}(x) = f(x),\ \forall\, x \in \text{I} \) (interval), then for any arbitrary real number C, (also called constant of integration)

\[ \frac{d}{dx}\big[\text{F}(x) + \text{C}\big] = f(x),\quad x \in \text{I} \]

Thus, \( \{\text{F} + \text{C},\ \text{C} \in \mathbf{R}\} \) denotes a family of anti derivatives of \( f \).

Same Derivative, Differ by a Constant

Remark

Functions with same derivatives differ by a constant. To show this, let \( g \) and \( h \) be two functions having the same derivatives on an interval I.

Consider the function \( f = g - h \) defined by \( f(x) = g(x) - h(x),\ \forall\, x \in \text{I} \). Then

\[ \frac{df}{dx} = f' = g' - h' \quad\text{giving}\quad f'(x) = g'(x) - h'(x)\ \ \forall\, x \in \text{I} \] \[ \text{or}\qquad f'(x) = 0,\ \forall\, x \in \text{I} \ \text{ by hypothesis,} \]

i.e., the rate of change of \( f \) with respect to \( x \) is zero on I and hence \( f \) is constant.

In view of the above remark, it is justified to infer that the family \( \{\text{F} + \text{C},\ \text{C} \in \mathbf{R}\} \) provides all possible anti derivatives of \( f \).

The Integral Sign

We introduce a new symbol, namely, \( \int f(x)\,dx \) which will represent the entire class of anti derivatives read as the indefinite integral of \( f \) with respect to \( x \).

Symbolically
\[ \int f(x)\,dx = \text{F}(x) + \text{C} \]

Notation Given that \( \dfrac{dy}{dx} = f(x) \), we write \( y = \int f(x)\,dx \).

Standard Formulae

We already know the formulae for the derivatives of many important functions. From these formulae, we can write down immediately the corresponding formulae (referred to as standard formulae) for the integrals of these functions, as listed below which will be used to find integrals of other functions.

Standard Integrals
DerivativesIntegrals (Anti derivatives)
(i)\( \dfrac{d}{dx}\left(\dfrac{x^{n+1}}{n+1}\right) = x^n \)\( \displaystyle\int x^n\,dx = \frac{x^{n+1}}{n+1} + \text{C},\ n \ne -1 \)
Particularly, we note that
\( \dfrac{d}{dx}(x) = 1 \)\( \displaystyle\int dx = x + \text{C} \)
(ii)\( \dfrac{d}{dx}(\sin x) = \cos x \)\( \displaystyle\int \cos x\,dx = \sin x + \text{C} \)
(iii)\( \dfrac{d}{dx}(-\cos x) = \sin x \)\( \displaystyle\int \sin x\,dx = -\cos x + \text{C} \)
(iv)\( \dfrac{d}{dx}(\tan x) = \sec^2 x \)\( \displaystyle\int \sec^2 x\,dx = \tan x + \text{C} \)
(v)\( \dfrac{d}{dx}(-\cot x) = \operatorname{cosec}^2 x \)\( \displaystyle\int \operatorname{cosec}^2 x\,dx = -\cot x + \text{C} \)
(vi)\( \dfrac{d}{dx}(\sec x) = \sec x \tan x \)\( \displaystyle\int \sec x \tan x\,dx = \sec x + \text{C} \)
(vii)\( \dfrac{d}{dx}(-\operatorname{cosec} x) = \operatorname{cosec} x \cot x \)\( \displaystyle\int \operatorname{cosec} x \cot x\,dx = -\operatorname{cosec} x + \text{C} \)
(viii)\( \dfrac{d}{dx}\left(\sin^{-1} x\right) = \dfrac{1}{\sqrt{1 - x^2}} \)\( \displaystyle\int \frac{dx}{\sqrt{1 - x^2}} = \sin^{-1} x + \text{C} \)
(ix)\( \dfrac{d}{dx}\left(-\cos^{-1} x\right) = \dfrac{1}{\sqrt{1 - x^2}} \)\( \displaystyle\int \frac{dx}{\sqrt{1 - x^2}} = -\cos^{-1} x + \text{C} \)
(x)\( \dfrac{d}{dx}\left(\tan^{-1} x\right) = \dfrac{1}{1 + x^2} \)\( \displaystyle\int \frac{dx}{1 + x^2} = \tan^{-1} x + \text{C} \)
(xi)\( \dfrac{d}{dx}\left(e^x\right) = e^x \)\( \displaystyle\int e^x\,dx = e^x + \text{C} \)
(xii)\( \dfrac{d}{dx}\left(\log |x|\right) = \dfrac{1}{x} \)\( \displaystyle\int \frac{1}{x}\,dx = \log |x| + \text{C} \)
(xiii)\( \dfrac{d}{dx}\left(\dfrac{a^x}{\log a}\right) = a^x \)\( \displaystyle\int a^x\,dx = \frac{a^x}{\log a} + \text{C} \)
Note

In practice, we normally do not mention the interval over which the various functions are defined. However, in any specific problem one has to keep it in mind.
