3.3 Algebraic Methods of Solving a Pair of Linear Equations

In the previous section, we discussed how to solve a pair of linear equations graphically. The graphical method is not convenient in cases when the point representing the solution of the linear equations has non-integral coordinates like \(\left(\sqrt{3}, 2\sqrt{7}\right)\), \((-1.75, 3.3)\), \(\left(\frac{4}{13}, \frac{1}{19}\right)\), etc. There is every possibility of making mistakes while reading such coordinates. Is there any alternative method of finding the solution? There are several algebraic methods, which we shall now discuss.
