7.3 Mind the Mistake, Mend the Mistake

Textbook pages 18–19

The following are some equations along with the steps used to solve them to find the value of the letter-number. Go through each solution and decide whether the steps are correct. If there is a mistake, describe the mistake, correct it and solve the equation.

1

\(4x + 6 = 10\)

\(4x = 10 + 6\)

\(4x = 16\)

\(x = 4\)

2

\(7 - 8z = 5\)

\(8z = 7 - 5\)

\(8z = 2\)

\(z = 4\)

3

\(2v - 4 = 6\)

\(v - 4 = 6 - 2\)

\(v - 4 = 4\)

\(v = 8\)

4

\(5z + 2 = 3z - 4\)

\(5z + 3z = -4 + 2\)

\(8z = -2\)

\(z = -\frac{2}{8}\)

5

\(15w - 4w = 26\)

\(15w = 26 + 4w\)

\(15w = 30\)

\(w = 2\)

6

\(3x + 1 = -12\)

\(x + 1 = -\frac{12}{3}\)

\(x + 1 = -4\)

\(x = -5\)

7

\(4(4q + 2) = 50\)

\(4(4q) = 50 - 2\)

\(16q = 48\)

\(q = 3\)

8

\(-2(3 - 4x) = 14\)

\(-6v - 8x = 14\)

\(-8x = 14 + 6\)

\(-8x = 20\)

\(x = -\frac{20}{8}\)

9

\(3(7y + 4) = 9 + 5y\)

\(7y + 4 = \frac{9}{3} + 5y\)

\(7y + 4 = 3 + 5y\)

\(7y - 5y + 4 = 3\)

\(2y = 4 - 3\)

\(y = \frac{1}{2}\)
