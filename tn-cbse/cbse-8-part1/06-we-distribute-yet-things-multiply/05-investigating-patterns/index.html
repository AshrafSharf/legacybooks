Investigating Patterns

Textbook pages 12–14 · 11 figures

Pattern 1

Look at the following pattern.

\(2 (2 + 1\) ) \(= 3 + 1\)

\(2 (3 + 1\) ) \(= 4 + 2\)

\(2 (6 + 5\) ) \(= 11 + 1\)

\(2 (5 + 3\) ) \(= 8 + 2\) .

Can you write twice this sum as a sum of two squares? Try this with other pairs of numbers. Have you figured out a pattern?

Notice that \(2 (5 + 6\) ) \(= (6 + 5) + (6 - 5)\) . Do the identities below help in explaining the observed pattern?

(a + b) \(= a + 2ab + b\)

(a - b) \(= a - 2ab + b\)

(a + b) + (a - b) = (a \(+ 2ab + b\) ) + (a \(- 2ab + b\) )

Adding the like terms \(a + a = 2a\) , \(b + b = 2b\) and \(2ab - 2ab = 0\), we get

2 (a \(+ b\) ) = (a + b) + (a - b) .

Pattern 2

Here is a related pattern. Try to describe the pattern using algebra to determine if the pattern always holds.

\(9 \times 9 - 1 \times 1= 10 \times 8\)

\(8 \times 8 - 6 \times 6 = 14 \times 2\)

\(7 \times 7 - 2 \times 2 = 9 \times 5\)

\(10 \times 10 - 4 \times 4 = 14 \times 6\)

The pattern here appears to be \(a - b =\) (a + b) \(\times\) (a - b). Is this a true identity? Using the distributive property, we get

(a + b) \(\times\) (a - b) \(= a -\) ab + ba \(- a\) .

Adding the like terms, ab + ( - ab) \(= 0\), we see that indeed

Show that (a + b) \(\times\) (a - b) \(= a - b\) geometrically.

Hint:

What do we get when this piece is moved?

Sridharacharya (750 CE) gave an interesting method to quickly compute the squares of numbers using Identity 1C! Consider the following modified form of this identity -

\(a =\) (a + b) (a - b) \(+ b\)

Why is this identity true?

Now, for example, 31 can be found by taking \(a = 31\) and \(b = 1\).

\(31 = (31 + 1) (31 - 1) + 1\)

\(= 32 \times 30 + 1\)

\(= 961\).

197 can be found by taking \(a = 197\), and \(b = 3\).

\(197 = (197 + 3) (197 - 3) + 3\)

\(= 200 \times 194 + 9\)

\(= 38809\).
