Chapter 4 · Geometry

Exercise 4.2

Textbook pages 18

  1. Draw circles for the following measurements of radius (r)/ diameters(d).
    1. \(r = 4\ \text{cm}\)
    2. \(d = 12\ \text{cm}\).
    3. \(r = 3.5\ \text{cm}\)
    4. \(r = 6.5\ \text{cm}\).
    5. \(d = 6\ \text{cm}\)
  2. Draw concentric circles for the following measurements of radii / diameters. Find out the width of each circular ring.
    1. \(r = 3\ \text{cm}\) and \(r = 5\ \text{cm}\).
    2. \(r = 3.5\ \text{cm}\) and \(r = 6.5\ \text{cm}\).
    3. \(d = 6.4\ \text{cm}\) and \(d = 11.6\ \text{cm}\).
    4. \(r = 5\ \text{cm}\) and \(r = 7.5\ \text{cm}\).
    5. \(d = 6.2\ \text{cm}\) and \(r = 6.2\ \text{cm}\).
    6. \(r = 7.1\ \text{cm}\) and \(d = 12\ \text{cm}\).
