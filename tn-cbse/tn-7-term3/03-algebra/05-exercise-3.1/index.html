Exercise 3.1

Textbook pages 14–15 · 1 figure

  1. Fill in the blanks.
    1. \((p - q)^{2} = \underline{\qquad\qquad}\).
    2. The product of \((x + 5)\) and \((x - 5)\) is \(\underline{\qquad\qquad}\).
    3. The factors of \(x^{2} - 4x + 4\) are \(\underline{\qquad\qquad}\).
    4. Express \(24abc^{2}\) as product of its factors is \(\underline{\qquad\qquad}\).
  2. Say whether the following statements are True or False.
    1. \((7x + 3)(7x - 4) = 49x^{2} - 7x - 12\).
    2. \((a - 1)^{2} = a^{2} - 1\).
    3. \((x^{2} + y^{2})(y^{2} + x^{2}) = (x^{2} + y^{2})^{2}\).
    4. \(2p\) is a factor of \(8pq\).
  3. Express the following as the product of its factors.
    1. \(24ab^{2}c^{2}\).
    2. \(36x^{3}y^{2}z\).
    3. \(56mn^{2}p^{2}\).
  4. Using the identity \((x + a)(x + b) = x^{2} + x(a + b) + ab\), find the following product.
    1. \((x + 3)(x + 7)\)
    2. \((6a + 9)(6a - 5)\)
    3. \((4x + 3y)(4x + 5y)\)
    4. \((8 + pq)(pq + 7)\)
  5. Expand the following squares, using suitable identities.
    1. \((2x + 5)^{2}\)
    2. \((b - 7)^{2}\)
    3. \((mn + 3p)^{2}\)
    4. \((xyz - 1)^{2}\)
  6. Using the identity \((a + b)(a - b) = a^{2} - b^{2}\), find the following product.
    1. \((p + 2)(p - 2)\)
    2. \((1 + 3b)(3b - 1)\)
    3. \((4 - mn)(mn + 4)\)
    4. \((6x + 7y)(6x - 7y)\)
  7. Evaluate the following, using suitable identity.
    1. \(51^{2}\)
    2. \(103^{2}\)
    3. \(998^{2}\)
    4. \(47^{2}\)
    5. \(297 \times 303\)
    6. \(990 \times 1010\)
    7. \(51 \times 52\)
  8. Simplify: \((a + b)^{2} - 4ab\)
  9. Show that \((m - n)^{2} + (m + n)^{2} = 2(m^{2} + n^{2})\)
  10. If \(a + b = 10\) and \(ab = 18\), find the value of \(a^{2} + b^{2}\)
  11. Factorise the following algebraic expressions by using the identity \(a^{2} - b^{2} = (a + b)(a - b)\).
    1. \(z^{2} - 16\)
    2. \(9 - 4y^{2}\)
    3. \(25a^{2} - 49b^{2}\)
    4. \(x^{4} - y^{4}\)
  12. Factorise the following using suitable identity.
    1. \(x^{2} - 8x + 16\)
    2. \(y^{2} + 20y + 100\)
    3. \(36m^{2} + 60m + 25\)
    4. \(64x^{2} - 112xy + 49y^{2}\)
    5. \(a^{2} + 6ab + 9b^{2} - c^{2}\)

Objective Type Questions

  1. If \(a + b = 5\) and \(a^{2} + b^{2} = 13\), then \(ab = ?\)
    1. 12
    2. 6
    3. 5
    4. 13
  2. \((5 + 20)(-20 - 5) = ?\)
    1. \(-425\)
    2. 375
    3. \(-625\)
    4. 0
  3. The factors of \(x^{2} - 6x + 9\) are
    1. \((x - 3)(x - 3)\)
    2. \((x - 3)(x + 3)\)
    3. \((x + 3)(x + 3)\)
    4. \((x - 6)(x + 9)\)
  4. The common factors of the algebraic expressions \(ax^{2}y\), \(bxy^{2}\) and \(cxyz\) is
    1. \(x^{2}y\)
    2. \(xy^{2}\)
    3. \(xyz\)
    4. \(xy\)
