Example 5.4 If the mean of the following numbers is 38, find the value of x. 48, x, 37, 38, 36, 27, 35, 34, 38, 49, 33.

Solution

Mean = Sum of all observations Number of observations

\(38 = 48+ x + 37+ 38+ 36+ 27+ 35+ 34+ 38+ 49+ 33\)

\(38= \frac{375+ x}{11} 38 \times 11= 375+ x\)

\(x = 418 - 375 x = 43\)

Hence, the value of x is 43.
