Figure it Out

  1. For the numbers in the previous exercise, find out how to get each number by making the smallest number of button clicks and write the expression.

    Ans:

    1. \(8300 = (8 \times 1000) + (3 \times 100)\)

      Number of clicks = 11

    2. \(40629 = (4 \times 10000) + (6 \times 100) + (2 \times 10) + (9 \times 1)\)

      Number of clicks \(= 4 + 6 + 2 + 9 = 21\)

    3. \(56354 = (5 \times 10000) + (6 \times 1000) + (3 \times 100) + (5 \times 10) + (4 \times 1)\)

      Number of clicks \(= 5 + 6 + 3 + 5 + 4 = 23\)

    4. \(66666 = (6 \times 10000) + (6 \times 1000) + (6 \times 100) + (6 \times 10) + (6 \times 1)\)

      Number of clicks \(= 6 + 6 + 6 + 6 + 6 = 30\)

    5. \(367813 = (3 \times 100000) + (6 \times 10000) + (7 \times 1000) + (8 \times 100) + (1 \times 10) + (3 \times 1)\)

      Number of clicks \(= 3 + 6 + 7 + 8 + 1 + 3 = 28\)

  2. Do you see any connection between each number and the corresponding smallest number of button clicks?

    Ans: The smallest number of button clicks for each number is the sum of its digits.
