  1. Add the numbers in each picture below. Write their corresponding expressions and simplify them.

    Ans: Some of the ways are shown. The first grid gives \(2x + 6y - 6\); the second gives \(10p + 10q - 4\); the third gives \(40k - 20g\).

  2. Simplify each of the following expressions:
    1. \(p + p + p + p = 4p\); \(p + p + p + q = 3p + q\)
    2. \(p + q + p - q = 2p\)
    3. \(p - q + p - q = 2p - 2q\)
    4. \(p + q - p + q = 2q\)
    5. \(p + q - (p + q) = 0\)
    6. \(p - q - p - q = -2q\)
    7. \(2d - d - d - d = -d\)
    8. \(2d - d - d - c = -c\)
    9. \(2d - d - (d - c) = c\)
    10. \(2d - (d - d) - c = 2d - c\)
    11. \(2d - d - c - c = d - 2c\)
