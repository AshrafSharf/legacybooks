Mind the Mistake, Mend the Mistake

Textbook pages 7 · 1 figure

Some simplifications are shown below where the letter-numbers are replaced by numbers and the value of the expression is obtained.

  • 1.Observe each of them and identify if there is a mistake.
  • 2.If you think there is a mistake, try to explain what might have gone

wrong.

  • 3.Then, correct it and give the value of the expression.

If \(a = - 4\), If \(d = 6\), If \(s = 7\),

then \(10 - a = 6\). then \(3d = 36\). then \(3s - 2 = 15\).

If \(r = 8\), If \(j = 5\), If \(m = - 6\),

then \(2r + 1 = 29\). then \(2j = 10\). then 3 (m \(+ 1) = 19\).

If \(f = 3\), \(g = 1\) If \(t = 4\), \(b = 3\) If \(h = 5\), \(n = 6\)

then \(2f - 2g = 2\). then \(2t + b = 24\). then \(h - (3 -\) n) \(= 4\).
