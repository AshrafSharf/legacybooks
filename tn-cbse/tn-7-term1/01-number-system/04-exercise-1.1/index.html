Example 1.9

Mention the property for the following equations:

  1. \((- 45)+( - 12) = - 57\) (ii) \((- 15)+ 7 = (7)+( - 15)\)
  2. \(- 10 + 3 = - 7\) (iv) \((- 7)+( - 5) = (- 5)+( - 7)\)
  3. \((- 7)+\) \((- 4)+( -\) 3)= \((- 7)+( -\) 4)+\((- 3)\) (vi) \(0 +( - 7245) = - 7245\)
