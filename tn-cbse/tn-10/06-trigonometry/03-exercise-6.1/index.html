Chapter 6 · Trigonometry

Exercise 6.1

Textbook pages 11-12

  1. Prove the following identities.
    1. \(\cot\theta + \tan\theta = \sec\theta\operatorname{cosec}\theta\)
    2. \(\tan^4\theta + \tan^2\theta = \sec^4\theta - \sec^2\theta\)
  2. Prove the following identities.
    1. \(\dfrac{1 - \tan^2\theta}{\cot^2\theta - 1} = \tan^2\theta\)
    2. \(\dfrac{\cos\theta}{1 + \sin\theta} = \sec\theta - \tan\theta\)
  3. Prove the following identities.
    1. \(\sqrt{\dfrac{1 + \sin\theta}{1 - \sin\theta}} = \sec\theta + \tan\theta\)
    2. \(\sqrt{\dfrac{1 + \sin\theta}{1 - \sin\theta}} + \sqrt{\dfrac{1 - \sin\theta}{1 + \sin\theta}} = 2\sec\theta\)
  4. Prove the following identities.
    1. \(\sec^6\theta = \tan^6\theta + 3\tan^2\theta\sec^2\theta + 1\)
    2. \((\sin\theta + \sec\theta)^2 + (\cos\theta + \operatorname{cosec}\theta)^2 = 1 + (\sec\theta + \operatorname{cosec}\theta)^2\)
  5. Prove the following identities.
    1. \(\sec^4\theta(1 - \sin^4\theta) - 2\tan^2\theta = 1\)
    2. \(\dfrac{\cot\theta - \cos\theta}{\cot\theta + \cos\theta} = \dfrac{\operatorname{cosec}\theta - 1}{\operatorname{cosec}\theta + 1}\)
  6. Prove the following identities.
    1. \(\dfrac{\sin A - \sin B}{\cos A + \cos B} + \dfrac{\cos A - \cos B}{\sin A + \sin B} = 0\)
    2. \(\dfrac{\sin^3 A + \cos^3 A}{\sin A + \cos A} + \dfrac{\sin^3 A - \cos^3 A}{\sin A - \cos A} = 2\)
    1. If \(\sin\theta + \cos\theta = \sqrt{3}\), then prove that \(\tan\theta + \cot\theta = 1\).
    2. If \(\sqrt{3}\sin\theta - \cos\theta = 0\), then show that \(\tan 3\theta = \dfrac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta}\)
    1. If \(\dfrac{\cos\alpha}{\cos\beta} = m\) and \(\dfrac{\cos\alpha}{\sin\beta} = n\), then prove that \((m^2 + n^2)\cos^2\beta = n^2\)
    2. If \(\cot\theta + \tan\theta = x\) and \(\sec\theta - \cos\theta = y\), then prove that \((x^2y)^{\frac{2}{3}} - (xy^2)^{\frac{2}{3}} = 1\)
    1. If \(\sin\theta + \cos\theta = p\) and \(\sec\theta + \operatorname{cosec}\theta = q\), then prove that \(q(p^2 - 1) = 2p\)
    2. If \(\sin\theta(1 + \sin^2\theta) = \cos^2\theta\), then prove that \(\cos^6\theta - 4\cos^4\theta + 8\cos^2\theta = 4\)
  10. If \(\dfrac{\cos\theta}{1 + \sin\theta} = \dfrac{1}{a}\), then prove that \(\dfrac{a^2 - 1}{a^2 + 1} = \sin\theta\)
