3.6.7 The Relation between Roots and Coefficients of a Quadratic Equation

Textbook pages 35–38

Let \(\alpha\) and \(\beta\) are the roots of the equation \(ax^2 + bx + c = 0\) then,

\(\alpha = \dfrac{-b + \sqrt{b^2 - 4ac}}{2a}, \qquad \beta = \dfrac{-b - \sqrt{b^2 - 4ac}}{2a}\)

From 3.6.3, we get

\(\alpha + \beta = \dfrac{-b}{a} = \dfrac{-\text{Co-efficient of } x}{\text{Co-efficient of } x^2}\)

\(\alpha\beta = \dfrac{c}{a} = \dfrac{\text{Constant term}}{\text{Co-efficient of } x^2}\)

Example 3.43

If the difference between the roots of the equation \(x^2 - 13x + k = 0\) is 17 find \(k\).

Solution

\(x^2 - 13x + k = 0\) here, \(a = 1,\ b = -13,\ c = k\)

Let \(\alpha, \beta\) be the roots of the equation. Then

\(\alpha + \beta = \dfrac{-b}{a} = \dfrac{-(-13)}{1} = 13 \quad \ldots(1) \qquad \text{Also}\quad \alpha - \beta = 17 \quad \ldots(2)\)

(1)+(2) we get, \(2\alpha = 30 \Rightarrow \alpha = 15\)

Therefore, \(15 + \beta = 13\) (from (1)) \(\Rightarrow \beta = -2\)

But, \(\alpha\beta = \dfrac{c}{a} = \dfrac{k}{1} \Rightarrow 15 \times (-2) = k\) we get, \(k = -30\)

Example 3.44

If \(\alpha\) and \(\beta\) are the roots of \(x^2 + 7x + 10 = 0\) find the values of

  1. \((\alpha - \beta)\)
  2. \(\alpha^2 + \beta^2\)
  3. \(\alpha^3 - \beta^3\)
  4. \(\alpha^4 + \beta^4\)
  5. \(\dfrac{\alpha}{\beta} + \dfrac{\beta}{\alpha}\)
  6. \(\dfrac{\alpha^2}{\beta} + \dfrac{\beta^2}{\alpha}\)

Solution

\(x^2 + 7x + 10 = 0\) here, \(a = 1,\ b = 7,\ c = 10\)

If \(\alpha\) and \(\beta\) are roots of the equation then,

\(\alpha + \beta = \dfrac{-b}{a} = \dfrac{-7}{1} = -7;\quad \alpha\beta = \dfrac{c}{a} = \dfrac{10}{1} = 10\)

  1. \(\alpha - \beta = \sqrt{(\alpha + \beta)^2 - 4\alpha\beta} = \sqrt{(-7)^2 - 4 \times 10} = \sqrt{9} = 3\)
  2. \(\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = (-7)^2 - 2 \times 10 = 29\)
  3. \(\alpha^3 - \beta^3 = (\alpha - \beta)^3 + 3\alpha\beta(\alpha - \beta) = (3)^3 + 3(10)(3) = 117\)
  4. \(\alpha^4 + \beta^4 = (\alpha^2 + \beta^2)^2 - 2\alpha^2\beta^2 = 29^2 - 2 \times (10)^2 = 641\) (from (ii), \(\alpha^2 + \beta^2 = 29\))
  5. \(\dfrac{\alpha}{\beta} + \dfrac{\beta}{\alpha} = \dfrac{\alpha^2 + \beta^2}{\alpha\beta} = \dfrac{(\alpha + \beta)^2 - 2\alpha\beta}{\alpha\beta} = \dfrac{49 - 20}{10} = \dfrac{29}{10}\)
  6. \(\dfrac{\alpha^2}{\beta} + \dfrac{\beta^2}{\alpha} = \dfrac{\alpha^3 + \beta^3}{\alpha\beta} = \dfrac{(\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)}{\alpha\beta} = \dfrac{(-343) - 3(10 \times (-7))}{10} = \dfrac{-343 + 210}{10} = \dfrac{-133}{10}\)

Example 3.45

If \(\alpha, \beta\) are the roots of the equation \(3x^2 + 7x - 2 = 0\), find the values of (i) \(\dfrac{\alpha}{\beta} + \dfrac{\beta}{\alpha}\) (ii) \(\dfrac{\alpha^2}{\beta} + \dfrac{\beta^2}{\alpha}\)

Solution

\(3x^2 + 7x - 2 = 0\) here, \(a = 3,\ b = 7,\ c = -2\)

since, \(\alpha, \beta\) are the roots of the equation

(i)

\(\alpha + \beta = \dfrac{-b}{a} = \dfrac{-7}{3};\quad \alpha\beta = \dfrac{c}{a} = \dfrac{-2}{3}\)

\(\dfrac{\alpha}{\beta} + \dfrac{\beta}{\alpha} = \dfrac{\alpha^2 + \beta^2}{\alpha\beta} = \dfrac{(\alpha + \beta)^2 - 2\alpha\beta}{\alpha\beta} = \dfrac{\left(\dfrac{-7}{3}\right)^2 - 2\left(\dfrac{-2}{3}\right)}{\dfrac{-2}{3}} = \dfrac{-61}{6}\)

(ii)

\(\dfrac{\alpha^2}{\beta} + \dfrac{\beta^2}{\alpha} = \dfrac{\alpha^3 + \beta^3}{\alpha\beta} = \dfrac{(\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)}{\alpha\beta} = \dfrac{\left(-\dfrac{7}{3}\right)^3 - 3\left(-\dfrac{2}{3}\right)\left(-\dfrac{7}{3}\right)}{-\dfrac{2}{3}} = \dfrac{469}{18}\)

Example 3.46

If \(\alpha, \beta\) are the roots of the equation \(2x^2 - x - 1 = 0\), then form the equation whose roots are (i) \(\dfrac{1}{\alpha}, \dfrac{1}{\beta}\) (ii) \(\alpha^2\beta,\ \beta^2\alpha\) (iii) \(2\alpha + \beta,\ 2\beta + \alpha\)

Solution

\(2x^2 - x - 1 = 0\) here, \(a = 2,\ b = -1,\ c = -1\)

\(\alpha + \beta = \dfrac{-b}{a} = \dfrac{-(-1)}{2} = \dfrac{1}{2};\quad \alpha\beta = \dfrac{c}{a} = -\dfrac{1}{2}\)

(i) Given roots are \(\dfrac{1}{\alpha}, \dfrac{1}{\beta}\)

\(\text{Sum of the roots} = \dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha + \beta}{\alpha\beta} = \dfrac{\frac{1}{2}}{-\frac{1}{2}} = -1\)

\(\text{Product of the roots} = \dfrac{1}{\alpha} \times \dfrac{1}{\beta} = \dfrac{1}{\alpha\beta} = \dfrac{1}{-\frac{1}{2}} = -2\)

The required equation is \(x^2 - (\text{Sum of the roots})x + (\text{Product of the roots}) = 0\)

\(x^2 - (-1)x - 2 = 0 \;\Rightarrow\; x^2 + x - 2 = 0\)

(ii) Given roots are \(\alpha^2\beta,\ \beta^2\alpha\)

\(\text{Sum of the roots}\quad \alpha^2\beta + \beta^2\alpha = \alpha\beta(\alpha + \beta) = -\dfrac{1}{2}\left(\dfrac{1}{2}\right) = -\dfrac{1}{4}\)

\(\text{Product of the roots}\quad (\alpha^2\beta) \times (\beta^2\alpha) = \alpha^3\beta^3 = (\alpha\beta)^3 = \left(-\dfrac{1}{2}\right)^3 = -\dfrac{1}{8}\)

The required equation is \(x^2 - (\text{Sum of the roots})x + (\text{Product of the roots}) = 0\)

\(x^2 - \left(-\dfrac{1}{4}\right)x - \dfrac{1}{8} = 0 \;\Rightarrow\; 8x^2 + 2x - 1 = 0\)

(iii) \(2\alpha + \beta,\ 2\beta + \alpha\)

\(\text{Sum of the roots}\quad 2\alpha + \beta + 2\beta + \alpha = 3(\alpha + \beta) = 3\left(\dfrac{1}{2}\right) = \dfrac{3}{2}\)

\(\begin{aligned} \text{Product of the roots} &= (2\alpha + \beta)(2\beta + \alpha) = 4\alpha\beta + 2\alpha^2 + 2\beta^2 + \alpha\beta \\ &= 5\alpha\beta + 2(\alpha^2 + \beta^2) = 5\alpha\beta + 2\left[(\alpha + \beta)^2 - 2\alpha\beta\right] \\ &= 5\left(-\dfrac{1}{2}\right) + 2\left[\dfrac{1}{4} - 2 \times -\dfrac{1}{2}\right] = 0 \end{aligned}\)

The required equation is \(x^2 - (\text{Sum of the roots})x + (\text{Product of the roots}) = 0\)

\(x^2 - \dfrac{3}{2}x + 0 = 0 \;\Rightarrow\; 2x^2 - 3x = 0\)
