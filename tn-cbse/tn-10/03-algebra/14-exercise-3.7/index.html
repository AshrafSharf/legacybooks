Chapter 3 · Algebra

Exercise 3.7

Textbook pages 21

  1. Find the square root of the following rational expressions.
    1. \(\frac{400x^4y^{12}z^{16}}{100x^8y^4z^4}\)
    2. \(\frac{7x^2 + 2\sqrt{14}x + 2}{x^2 - \frac{1}{2}x + \frac{1}{16}}\)
    3. \(\frac{121(a + b)^8(x + y)^8(b - c)^8}{81(b - c)^4(a - b)^{12}(b - c)^4}\)
  2. Find the square root of the following
    1. \(4x^2 + 20x + 25\)
    2. \(9x^2 - 24xy + 30xz - 40yz + 25z^2 + 16y^2\)
    3. \((4x^2 - 9x + 2)(7x^2 - 13x - 2)(28x^2 - 3x - 1)\)
    4. \(\left(2x^2 + \frac{17}{6}x + 1\right)\left(\frac{3}{2}x^2 + 4x + 2\right)\left(\frac{4}{3}x^2 + \frac{11}{3}x + 2\right)\)
