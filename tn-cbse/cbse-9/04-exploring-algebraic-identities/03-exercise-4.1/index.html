Exercise 4.1

Textbook pages 4–5 · 1 figure

  1. Using the identity \((a + b)^2 = a^2 + 2ab + b^2\), expand the following:
    1. \((7x + 4y)^2\)
    2. \(\left(\frac{7}{5}x + \frac{3}{2}y\right)^2\)
    3. \((2.5p + 1.5q)^2\)
    4. \(\left(\frac{3}{4}s + 8t\right)^2\)
    5. \(\left(x + \frac{1}{2y}\right)^2\)
    6. \(\left(\frac{1}{x} + \frac{1}{y}\right)^2\)
  2. Using the same identity, find the values of the following:
    1. \((64)^2\)
    2. \((105)^2\)
    3. \((205)^2\)
