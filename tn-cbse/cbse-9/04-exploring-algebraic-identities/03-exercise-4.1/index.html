For example, \(x - 1 = 24\) is true for only \(x = 5\) or \(- 5\). Hence, it is an equation.

But (x + y) \(= x + 2xy + y\) is true for all values of x and y. Therefore, this equation is also an identity. By now you must have observed that (a \(+ b)^{2} \ne a^{2} + b^{2}\). But can you find out which one of them will be greater?

For example, if \(a = 10\) and \(b = 2\), what are the values of (a + b) and

\(a + b\) ?

(a + b) \(= (10 + 2) = 12 = 144\) and \(a + b = 10 + 2 = 104\).

So in this case, (a + b) \(> a + b\) But is it true for all numbers a and b?

Think and Reflect

  • 1.What can you say about a and b if (a + b) \(< a + b\) ?
  • 2.What can you say about a and b if (a + b) \(> a + b\) ?
  • 3.When will (a + b) be equal to \(a + b\) ?

Did you observe that (a + b) and \(a + b\) are both positive? What term will

decide which is larger? Use the expansion of (a + b) to decide.

We can use the identity (a + b) \(= a + 2ab + b\) to find the square of general binomial expressions.

Example 3: Let us try to expand \((5x + 2y)\) . Here \(a = 5x\) and

\(b = 2y\).

Then \((5x + 2y) = (5x) + 2(5x)(2y) + (2y) = 25x + 20xy + 4y\) .

We can also use the identity to help us with numerical calculations.

Example 4: To calculate 43 , we can write it as

\((40 + 3)^{2} = 40^{2} + 2 \times 40 \times 3 + 3^{2} = 1600 + 240 + 9 = 1849\).
