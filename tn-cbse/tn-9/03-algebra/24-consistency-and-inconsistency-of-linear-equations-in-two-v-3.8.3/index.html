3.8.3 Consistency and Inconsistency of Linear Equations in Two Variables

Textbook pages 54–56 · 7 figures

Consider linear equations in two variables say

\(a_1x + b_1y + c_1 = 0 \quad ...(1)\)

\(a_2x + b_2y + c_2 = 0 \quad ...(2)\)

where \(a_1, a_2, b_1, b_2, c_1\) and \(c_2\) are real numbers. Then the system has :

  1. a unique solution if \(\frac{a_1}{a_2} \neq \frac{b_1}{b_2}\) (Consistent)
  2. an Infinite number of solutions if \(\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}\) (Consistent)
  3. no solution if \(\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}\) (Inconsistent)

Example 3.54

Check whether the following system of equation is consistent or inconsistent and say how many solutions we can have if it is consistent.

  1. \(2x - 4y = 7\); \(x - 3y = -2\)
  2. \(4x + y = 3\); \(8x + 2y = 6\)
  3. \(4x + 7 = 2y\); \(2x + 9 = y\)

Example 3.55 Check the value of \(k\) for which the given system of equations \(kx + 2y = 3\); \(2x - 3y = 1\) has a unique solution.

Solution

Given linear equations are

\(kx + 2y = 3 \quad .....(1) \qquad \left[\, a_1x + b_1y + c_1 = 0 \,\right]\)

\(2x - 3y = 1 \quad .....(2) \qquad \left[\, a_2x + b_2y + c_2 = 0 \,\right]\)

Here \(a_1 = k\), \(b_1 = 2\), \(a_2 = 2\), \(b_2 = -3\);

For unique solution we take \(\frac{a_1}{a_2} \neq \frac{b_1}{b_2}\); therefore \(\frac{k}{2} \neq \frac{2}{-3}\); \(k \neq \frac{4}{-3}\), that is \(k \neq -\frac{4}{3}\).

Example 3.56 Find the value of \(k\), for the following system of equation has infinitely many solutions. \(2x - 3y = 7\); \((k + 2)x - (2k + 1)y = 3(2k - 1)\)

Solution

Given two linear equations are

\(2x - 3y = 7 \qquad \left[\, a_1x + b_1y + c_1 = 0 \,\right]\)

\((k + 2)x - (2k + 1)y = 3(2k - 1) \qquad \left[\, a_2x + b_2y + c_2 = 0 \,\right]\)

Here \(a_1 = 2\), \(b_1 = -3\), \(a_2 = (k + 2)\), \(b_2 = -(2k + 1)\), \(c_1 = 7\), \(c_2 = 3(2k - 1)\)

For infinite number of solution we consider \(\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}\)

\(\frac{2}{k + 2} = \frac{-3}{-(2k + 1)} = \frac{7}{3(2k - 1)}\)

\(\frac{2}{k + 2} = \frac{-3}{-(2k + 1)}\)

\(2(2k + 1) = 3(k + 2)\)

\(4k + 2 = 3k + 6\)

\(k = 4\)

\(\frac{-3}{-(2k + 1)} = \frac{7}{3(2k - 1)}\)

\(9(2k - 1) = 7(2k + 1)\)

\(18k - 9 = 14k + 7\)

\(4k = 16\)

\(k = 4\)

Example 3.57 Find the value of \(k\) for which the system of linear equations \(8x + 5y = 9\); \(kx + 10y = 15\) has no solution.

Solution

Given linear equations are

\(8x + 5y = 9 \qquad \left[\, a_1x + b_1y + c_1 = 0 \,\right]\)

\(kx + 10y = 15 \qquad \left[\, a_2x + b_2y + c_2 = 0 \,\right]\)

Here \(a_1 = 8\), \(b_1 = 5\), \(c_1 = 9\), \(a_2 = k\), \(b_2 = 10\), \(c_2 = 15\)

For no solution, we know that \(\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}\) and so, \(\frac{8}{k} = \frac{5}{10} \neq \frac{9}{15}\)

\(80 = 5k\)

\(k = 16\)
