Exercise 1.4

Textbook pages 22 · 1 figure

  1. If \(P = \{1, 2, 5, 7, 9\}\), \(Q = \{2, 3, 5, 9, 11\}\), \(R = \{3, 4, 5, 7, 9\}\) and \(S = \{2, 3, 4, 5, 8\}\), then find

    (i) \((P \cup Q) \cup R\)   (ii) \((P \cap Q) \cap S\)   (iii) \((Q \cap S) \cap R\)

  2. Test for the commutative property of union and intersection of the sets \(P = \{x : x \text{ is a real number between 2 and 7}\}\) and \(Q = \{x : x \text{ is a rational number between 2 and 7}\}\).
  3. If \(A = \{p, q, r, s\}\), \(B = \{m, n, q, s, t\}\) and \(C = \{m, n, p, q, s\}\), then verify the associative property of union of sets.
  4. Verify the associative property of intersection of sets for \(A = \{-11, \sqrt{2}, \sqrt{5}, 7\}\), \(B = \{\sqrt{3}, \sqrt{5}, 6, 13\}\) and \(C = \{\sqrt{2}, \sqrt{3}, \sqrt{5}, 9\}\).
  5. If \(A = \{x : x = 2^n, n \in W \text{ and } n < 4\}\), \(B = \{x : x = 2n, n \in \mathbb{N} \text{ and } n \le 4\}\) and \(C = \{0, 1, 2, 5, 6\}\), then verify the associative property of intersection of sets.
