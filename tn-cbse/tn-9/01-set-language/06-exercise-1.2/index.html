Chapter 1 · Set Language

Exercise 1.2

Textbook pages 11–12 · 4 figures

  1. Find the cardinal number of the following sets.
    1. \(M = \{p, q, r, s, t, u\}\)
    2. \(P = \{x : x = 3n+2,\ n \in \mathbb{W} \text{ and } x < 15\}\)
    3. \(Q = \{y : y = \frac{4}{3n},\ n \in \mathbb{N} \text{ and } 2 < n \le 5\}\)
    4. \(R = \{x : x \text{ is an integers, } x \in \mathbb{Z} \text{ and } -5 \le x < 5\}\)
    5. \(S =\) The set of all leap years between 1882 and 1906.
  2. Identify the following sets as finite or infinite.
    1. \(X =\) The set of all districts in Tamilnadu.
    2. \(Y =\) The set of all straight lines passing through a point.
    3. \(A = \{x : x \in \mathbb{Z} \text{ and } x < 5\}\)
    4. \(B = \{x : x^{2}-5x+6 = 0,\ x \in \mathbb{N}\}\)
  3. Which of the following sets are equivalent or unequal or equal sets?
    1. \(A =\) The set of vowels in the English alphabets.
      \(B =\) The set of all letters in the word “VOWEL”
    2. \(C = \{2,3,4,5\}\)   \(D = \{x : x \in \mathbb{W},\ 1 < x < 5\}\)
    3. \(X = \{x : x \text{ is a letter in the word ``LIFE''}\}\)   \(Y = \{F, I, L, E\}\)
    4. \(G = \{x : x \text{ is a prime number and } 3 < x < 23\}\)   \(H = \{x : x \text{ is a divisor of } 18\}\)
  4. Identify the following sets as null set or singleton set.
    1. \(A = \{x : x \in \mathbb{N},\ 1 < x < 2\}\)
    2. \(B =\) The set of all even natural numbers which are not divisible by 2
    3. \(C = \{0\}\).
    4. \(D =\) The set of all triangles having four sides.
  5. State which pairs of sets are disjoint or overlapping?
    1. \(A = \{f, i, a, s\}\) and \(B = \{a, n, f, h, s\}\)
    2. \(C = \{x : x \text{ is a prime number, } x > 2\}\) and \(D = \{x : x \text{ is an even prime number}\}\)
    3. \(E = \{x : x \text{ is a factor of } 24\}\) and \(F = \{x : x \text{ is a multiple of } 3,\ x < 30\}\)
  6. If \(S = \{\text{square, rectangle, circle, rhombus, triangle}\}\), list the elements of the following subset of \(S\).
    1. The set of shapes which have 4 equal sides.
    2. The set of shapes which have radius.
    3. The set of shapes in which the sum of all interior angles is \(180^{\circ}\).
    4. The set of shapes which have 5 sides.
  7. If \(A = \{a, \{a, b\}\}\), write all the subsets of \(A\).
  8. Write down the power set of the following sets:
    1. \(A = \{a, b\}\)
    2. \(B = \{1, 2, 3\}\)
    3. \(D = \{p, q, r, s\}\)
    4. \(E = \emptyset\)
  9. Find the number of subsets and the number of proper subsets of the following sets.
    1. \(W = \{\text{red, blue, yellow}\}\)
    2. \(X = \{x^{2} : x \in \mathbb{N},\ x^{2} \le 100\}\).
    1. If \(n(A) = 4\), find \(n[P(A)]\).
    2. If \(n(A) = 0\), find \(n[P(A)]\).
    3. If \(n[P(A)] = 256\), find \(n(A)\).
