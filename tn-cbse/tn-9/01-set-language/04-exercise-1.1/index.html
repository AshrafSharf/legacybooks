Exercise 1.1

Textbook pages 5–6 · 1 figure

  1. Which of the following are sets?
    1. The collection of prime numbers upto 100.
    2. The collection of rich people in India.
    3. The collection of all rivers in India.
    4. The collection of good Hockey players.
  2. List the set of letters of the following words in Roster form.
    1. INDIA
    2. PARALLELOGRAM
    3. MISSISSIPPI
    4. CZECHOSLOVAKIA
  3. Consider the following sets \(A = \{0, 3, 5, 8\}\), \(B = \{2, 4, 6, 10\}\) and \(C = \{12, 14, 18, 20\}\).
    1. State whether True or False:
      1. \(18 \in C\)
      2. \(6 \notin A\)
      3. \(14 \notin C\)
      4. \(10 \in B\)
      5. \(5 \in B\)
      6. \(0 \in B\)
    2. Fill in the blanks:
      1. \(3 \in \underline{\qquad}\)
      2. \(14 \in \underline{\qquad}\)
      3. \(18 \ \underline{\qquad}\ B\)
      4. \(4 \ \underline{\qquad}\ B\)
  4. Represent the following sets in Roster form.
    1. \(A =\) The set of all even natural numbers less than 20.
    2. \(B = \left\{y : y = \dfrac{1}{2n},\ n \in \mathbb{N},\ n \le 5\right\}\)
    3. \(C = \{x : x \text{ is perfect cube, } 27 < x < 216\}\)
    4. \(D = \{x : x \in \mathbb{Z},\ -5 < x \le 2\}\)
  5. Represent the following sets in set builder form.
    1. \(B =\) The set of all Cricket players in India who scored double centuries in One day Internationals.
    2. \(C = \left\{\dfrac{1}{2}, \dfrac{2}{3}, \dfrac{3}{4}, \ldots\right\}\)
    3. \(D =\) The set of all tamil months in a year.
    4. \(E =\) The set of odd Whole numbers less than 9.
  6. Represent the following sets in descriptive form.
    1. \(P = \{\text{January, June, July}\}\)
    2. \(Q = \{7, 11, 13, 17, 19, 23, 29\}\)
    3. \(R = \{x : x \in \mathbb{N},\ x < 5\}\)
    4. \(S = \{x : x \text{ is a consonant in English alphabet}\}\)
