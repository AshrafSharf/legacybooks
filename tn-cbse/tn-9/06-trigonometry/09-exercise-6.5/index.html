Multiple choice questions

  1. If \(\sin 30^{\circ} = x\) and \(\cos 60^{\circ} = y\), then \(x^{2} + y^{2}\) is

    (1) \(\frac{1}{2}\) (2) \(0\) (3) \(\sin 90^{\circ}\) (4) \(\cos 90^{\circ}\)

  2. If \(\tan\theta = \cot 37^{\circ}\), then the value of \(\theta\) is

    (1) \(37^{\circ}\) (2) \(53^{\circ}\) (3) \(90^{\circ}\) (4) \(1^{\circ}\)

  3. The value of \(\tan 72^{\circ}\tan 18^{\circ}\) is

    (1) \(0\) (2) \(1\) (3) \(18^{\circ}\) (4) \(72^{\circ}\)

  4. The value of \(\dfrac{2\tan 30^{\circ}}{1-\tan^{2}30^{\circ}}\) is equal to

    (1) \(\cos 60^{\circ}\) (2) \(\sin 60^{\circ}\) (3) \(\tan 60^{\circ}\) (4) \(\sin 30^{\circ}\)

  5. If \(2\sin 2\theta = \sqrt{3}\), then the value of \(\theta\) is

    (1) \(90^{\circ}\) (2) \(30^{\circ}\) (3) \(45^{\circ}\) (4) \(60^{\circ}\)

  6. The value of \(3\sin 70^{\circ}\sec 20^{\circ} + 2\sin 49^{\circ}\sec 51^{\circ}\) is

    (1) \(2\) (2) \(3\) (3) \(5\) (4) \(6\)

  7. The value of \(\dfrac{1-\tan^{2}45^{\circ}}{1+\tan^{2}45^{\circ}}\) is

    (1) \(2\) (2) \(1\) (3) \(0\) (4) \(\frac{1}{2}\)

  8. The value of \(\operatorname{cosec}(70^{\circ}+\theta) - \sec(20^{\circ}-\theta) + \tan(65^{\circ}+\theta) - \cot(25^{\circ}-\theta)\) is

    (1) \(0\) (2) \(1\) (3) \(2\) (4) \(3\)

  9. The value of \(\tan 1^{\circ}\tan 2^{\circ}\tan 3^{\circ}\ldots\tan 89^{\circ}\) is

    (1) \(0\) (2) \(1\) (3) \(2\) (4) \(\frac{\sqrt{3}}{2}\)

  10. Given that \(\sin\alpha = \frac{1}{2}\) and \(\cos\beta = \frac{1}{2}\), then the value of \(\alpha + \beta\) is

    (1) \(0^{\circ}\) (2) \(90^{\circ}\) (3) \(30^{\circ}\) (4) \(60^{\circ}\)
