6.2 Trigonometric Ratios of Some Special Angles

Textbook pages 7–11 · 11 figures

The values of trigonometric ratios of certain angles can be obtained geometrically. Two special triangles come to help here.

6.2.1 Trigonometric ratios of \(45 ^{\circ}\)

Consider a triangle ABC with angles \(45 ^{\circ}\) , \(45 ^{\circ}\) and \(90 ^{\circ}\) as shown in the figure 6.9.

It is the shape of half a square, cut along the square's diagonal. Note that it is also an isosceles triangle (both legs have the same length, a units).

Use Pythagoras theorem to check if the diagonal is of Fig. 6.9 length \(a\sqrt{2}\).

Now, from the right-angled triangle ABC,

\(\sin 45^\circ = \frac{\text{opposite side}}{\text{hypotenuse}} = \frac{BC}{AC} = \frac{a}{a\sqrt{2}} = \frac{1}{\sqrt{2}}\)

\(\cos 45^\circ = \frac{\text{adjacent side}}{\text{hypotenuse}} = \frac{AB}{AC} = \frac{a}{a\sqrt{2}} = \frac{1}{\sqrt{2}}\)

\(\tan 45^\circ = \frac{\text{opposite side}}{\text{adjacent side}} = \frac{BC}{AB} = \frac{a}{a} = 1\)

6.2.2 Trigonometric Ratios of \(30 ^{\circ}\) and \(60 ^{\circ}\)

Consider an equilateral triangle PQR of side length 2 units.

Draw a bisector of \(\angle P\). Let it meet QR at M.

\(PQ = QR = RP = 2\) units.

\(QM = MR = 1\) unit (Why?)

Knowing PQ and QM, we can find PM, using Pythagoras

theorem,

Fig. 6.10

we find that \(PM = \sqrt{3}\) units.

Now, from the right-angled triangle PQM,

\(\sin 30^\circ = \frac{\text{opposite side}}{\text{hypotenuse}} = \frac{QM}{PQ} = \frac{1}{2}\)

\(\cos 30^\circ = \frac{\text{adjacent side}}{\text{hypotenuse}} = \frac{PM}{PQ} = \frac{\sqrt{3}}{2}\)

\(\tan 30^\circ = \frac{\text{opposite side}}{\text{adjacent side}} = \frac{QM}{PM} = \frac{1}{\sqrt{3}}\)

We will use the same triangle but the other angle of measure \(60 ^{\circ}\) now.

\(\sin 60^\circ = \frac{\text{opposite side}}{\text{hypotenuse}} = \frac{PM}{PQ} = \frac{\sqrt{3}}{2}\)

\(\cos 60^\circ = \frac{\text{adjacent side}}{\text{hypotenuse}} = \frac{QM}{PQ} = \frac{1}{2}\)

\(\tan 60^\circ = \frac{\text{opposite side}}{\text{adjacent side}} = \frac{PM}{QM} = \frac{\sqrt{3}}{1} = \sqrt{3}\)

6.2.3 Trigonometric ratios of \(0 ^{\circ}\) and \(90 ^{\circ}\)

To find the trigonometric ratios of \(0^\circ\) and \(90^\circ\), we take the help of what is known as a unit circle.

A unit circle is a circle of unit radius (that is of radius 1 unit), centred at the origin.

Why make a circle where the radius is 1unit?

This means that every reference Fig. 6.11 triangle that we create here has a hypotenuse of 1unit, which makes it so much easier to compare angles and ratios.

We will be interested only in the positive values since we consider 'lengths' and it is hence enough to concentrate on the first quadrant. Fig. 6.12

We can see that if P(x,y) be any point on the unit circle in the first quadrant and \(\angle POQ = \theta\)

\(\sin\theta = \frac{PQ}{OP} = \frac{y}{1} = y\) ; \(\cos\theta = \frac{OQ}{OP} = \frac{x}{1} = x\) ; \(\tan\theta = \frac{PQ}{OQ} = \frac{y}{x}\)

When \(\theta = 0^\circ\), \(OP\) coincides with OA, where A is (1,0) giving \(x =1\), \(y = 0\) .

We get thereby,

\(\sin 0^\circ = 0\) ; \(\csc 0^\circ =\) not defined (why?)

\(\cos 0^\circ = 1\) ; \(\sec 0^\circ = 1\)

\(\tan 0^\circ = \frac{0}{1} = 0\) ; \(\cot 0^\circ =\) not defined (why?)

When \(\theta = 90^\circ\), \(OP\) coincides with OB, where B is (0,1) giving \(x = 0\), \(y =1\).

Hence,

\(\sin 90^\circ = 1\) ; \(\csc 90^\circ = 1\)

\(\cos 90^\circ = 0\) ; \(\sec 90^\circ =\) not defined

\(\tan 90^\circ = \frac{1}{0} =\) not defined ; \(\cot 90^\circ = 0\)

Let us summarise all the results in the table given below:

Evaluate: (i) \(\sin 30^\circ + \cos 30^\circ\) (ii) \(\tan 60^\circ \cdot \cot 60^\circ\)

(iii) \(\frac{\tan 45^\circ}{\tan 30^\circ + \tan 60^\circ}\)

(iv) \(\sin^2 45^\circ + \cos^2 45^\circ\)

Solution

  1. \(\sin 30^\circ + \cos 30^\circ = \frac{1}{2} + \frac{\sqrt{3}}{2} = \frac{1+\sqrt{3}}{2}\)
  2. \(\tan 60^\circ \cdot \cot 60^\circ = \sqrt{3} \times \frac{1}{\sqrt{3}} = 1\)
  3. \(\frac{\tan 45^\circ}{\tan 30^\circ + \tan 60^\circ} = \frac{1}{\frac{1}{\sqrt{3}} + \sqrt{3}} = \frac{1}{\frac{1+3}{\sqrt{3}}} = \frac{\sqrt{3}}{4}\)
