Exercise 6.2

Textbook pages 11 · 1 figure

  1. Verify the following equalities:
    1. \(\sin^2 60^\circ + \cos^2 60^\circ = 1\)
    2. \(1 + \tan^2 30^\circ = \sec^2 30^\circ\)
    3. \(\cos 90^\circ = 1 - 2\sin^2 45^\circ = 2\cos^2 45^\circ - 1\)
    4. \(\sin 30^\circ \cos 60^\circ + \cos 30^\circ \sin 60^\circ = \sin 90^\circ\)
  2. Find the value of the following:
    1. \(\frac{\tan 45^\circ}{\text{cosec}\, 30^\circ} + \frac{\sec 60^\circ}{\cot 45^\circ} - \frac{5\sin 90^\circ}{2\cos 0^\circ}\)
    2. \((\sin 90^\circ + \cos 60^\circ + \cos 45^\circ) \times (\sin 30^\circ + \cos 0^\circ - \cos 45^\circ)\)
    3. \(\sin^2 30^\circ - 2\cos^3 60^\circ + 3\tan^4 45^\circ\)
  3. Verify \(\cos 3A = 4\cos^3 A - 3\cos A\), when \(A = 30^\circ\)
  4. Find the value of \(8\sin 2x \cos 4x \sin 6x\), when \(x = 15^\circ\)
