4-1 · Directed Numbers

So far you have worked with the numbers of arithmetic — zero and the positive numbers — on a number line that extends only to the right of 0:

But what about temperatures below zero, debts, depths below sea level, or years B.C.? These situations call for a two-way scale that extends in both directions from 0:

Definition — Directed Numbers

The small \(+\) and \(-\) signs written above and to the left of a numeral are signs of direction, not operation symbols. They indicate whether a point lies to the right (positive) or left (negative) of zero.

  • Positive numbers \(({}^+1, {}^+2, {}^+3, \ldots)\) lie to the right of zero.
  • Negative numbers \(({}^-1, {}^-2, {}^-3, \ldots)\) lie to the left of zero.
  • The magnitude of a number is its distance from 0, regardless of direction. Thus \({}^+2\) and \({}^-2\) both have magnitude 2.
  • Zero is included in the set of directed numbers but is neither positive nor negative.
Key Insight — Real-World Uses

A profit of $3 is written \(+3\); a loss of $2 as \(-2\). Latitudes north of the equator are positive; the South Pole is at latitude \(-90°\). A clockwise rotation of 30° can be written as \(-30°\) if counterclockwise is taken as positive.

4-2 · Comparing Numbers

On the number line, every number is greater than any number to its left, and less than any number to its right. This rule applies to all directed numbers — positive, negative, or zero.

Ordering Rule

For any two numbers \(a\) and \(b\) on the number line: \(a < b\) means \(a\) is to the left of \(b\).

This gives us some results that may seem surprising at first:

  • \(-2 > -10\) — even though 10 is "bigger" than 2, negative 2 is to the right of negative 10.
  • \(-50 > -100\) — for negative numbers, the one closer to zero is greater.
  • Every positive number is greater than every negative number.
  • Zero is greater than every negative number and less than every positive number.

4-3 · Addition on the Number Line

To add directed numbers, think of displacements (changes of position). Start at the first number, then move a distance equal to the magnitude of the second number in the direction indicated by its sign.

Example: \(+2 + (+5) = +7\)

Example: \(+2 + (-5) = -3\)

Rule — Addition on the Number Line

To add two numbers: start at the position of the first number, then move a distance equal to the magnitude of the second number in the direction associated with that number. The number at the resulting position is the sum.

This addition is commutative (\(a + b = b + a\)) and associative (\((a + b) + c = a + (b + c)\)).

Key Insight — Identity Element for Addition

Adding 0 to any number gives that identical number: \(a + 0 = 0 + a = a\). Because of this property, zero is called the identity element for addition.

4-4 · The Opposite of a Directed Number

Each number on the number line can be paired with another number that is the same distance from zero but in the opposite direction. Adding two such paired numbers always gives 0.

Definition — Additive Inverse (Opposite)

The opposite (or additive inverse) of a directed number \(a\) is the number \(-a\) such that:

$$a + (-a) = (-a) + a = 0$$

For every directed number \(a\), there is a unique number \(-a\) with this property.

Some important examples:

  • \(-(+7) = -7\)   because   \(+7 + (-7) = 0\)
  • \(-(0) = 0\)   because   \(0 + 0 = 0\)
  • \(-(-3) = +3\)   because   \(-3 + (+3) = 0\)
Key Insight — The Opposite of an Opposite

The opposite of \(-a\) is \(a\). That is, \(-(-a) = a\) for every directed number \(a\).

Property — Opposite of a Sum

The opposite of the sum of two numbers is the sum of their opposites:

$$-(a + b) = (-a) + (-b)$$

Simplified Notation

Since \(+3 = 3\), we henceforth drop the small raised \(+\) sign. We write 3 rather than \({}^+3\), and \(-3\) for \({}^-3\). The symbol \(-3\) can be read as either "negative 3" or "the opposite of 3."

4-5 · Absolute Value

The magnitude of a directed number — its distance from zero on the number line, regardless of direction — is called its absolute value.

Definition — Absolute Value

The absolute value of a number \(a\), written \(|a|\), is defined as:

$$|a| = \begin{cases} a & \text{if } a \geq 0 \\ -a & \text{if } a < 0 \end{cases}$$

In words: if \(a\) is zero or positive, its absolute value is \(a\) itself. If \(a\) is negative, its absolute value is its opposite (which is positive).

Examples:

  • \(|9| = 9\)
  • \(|-56| = 56\)
  • \(|0| = 0\)
  • \(-|-7| = -7\) — note the outer minus sign is not inside the absolute value bars
Caution

Absolute value is always non-negative: \(|a| \geq 0\) for every number \(a\). The equation \(|x| = -3\) has no solution because no distance can be negative.

4-6 · Adding Directed Numbers

You can add directed numbers without the number line by using these assumed properties:

Properties of Addition for Directed Numbers

For all directed numbers \(a\), \(b\), and \(c\):

  1. Closure: \(a + b\) is a unique directed number.
  2. Commutative: \(a + b = b + a\)
  3. Associative: \((a + b) + c = a + (b + c)\)
  4. Additive identity: \(0 + a = a + 0 = a\)
  5. Opposites: \(a + (-a) = (-a) + a = 0\)
  6. Opposite of a sum: \(-(a + b) = (-a) + (-b)\)

Rules for Addition

Rule 1 — Same Signs

If \(a\) and \(b\) have the same sign, add their absolute values and keep the common sign.

  • Both positive: \(4 + 3 = 7\)
  • Both negative: \((-3) + (-4) = -(3 + 4) = -7\)
Rule 2 — Different Signs

If \(a\) and \(b\) have different signs, subtract the smaller absolute value from the larger, and give the result the sign of the number with the larger absolute value.

  • \(7 + (-3) = 4\)   (since \(|7| > |-3|\), the result is positive)
  • \(-7 + 4 = -3\)   (since \(|-7| > |4|\), the result is negative)

4-7 · Subtracting Directed Numbers

One evening the thermometer read 11° above zero. The next morning it read 5° below zero. The temperature changed by \(-5 - 11 = -16\) degrees — a 16° drop. This is subtraction with directed numbers.

Definition — Subtraction

For all directed numbers \(a\) and \(b\), the difference \(a - b\) is defined as the number \(x\) satisfying \(b + x = a\).

By solving \(b + x = a\) algebraically, we find \(x = a + (-b)\). Therefore:

Rule — Subtraction
$$a - b = a + (-b)$$

To perform a subtraction, replace the number being subtracted by its opposite, and add. This shows the set of directed numbers is closed under subtraction.

Examples:

  • \(6 - 8 = 6 + (-8) = -2\)
  • \(-4 - 2 = -4 + (-2) = -6\)
  • \(-8 - (-3) = -8 + 3 = -5\)
  • \(5 - (-7) = 5 + 7 = 12\)

4-8 · Multiplying Directed Numbers

To develop multiplication rules, consider water flowing into or out of a tank at 3 gallons per minute:

Situation Equation Sign Rule
2 min hence, flowing in at 3 gal/min \((2)(3) = 6\) \((+)(+) = +\)
2 min ago, flowing in at 3 gal/min \((-2)(3) = -6\) \((-)(+) = -\)
2 min hence, flowing out at 3 gal/min \((2)(-3) = -6\) \((+)(-) = -\)
2 min ago, flowing out at 3 gal/min \((-2)(-3) = 6\) \((-)(-) = +\)

Sign Rules for Multiplication

\((+) \times (+) = +\)
positive × positive = positive
\((-) \times (-) = +\)
negative × negative = positive
\((+) \times (-) = -\)
positive × negative = negative
\((-) \times (+) = -\)
negative × positive = negative
Properties of Multiplication

For all directed numbers \(a\), \(b\), and \(c\):

  1. Closure: \(ab\) is a unique directed number.
  2. Commutative: \(ab = ba\)
  3. Associative: \(a(bc) = (ab)c\)
  4. Distributive: \(a(b + c) = ab + ac\)
  5. Multiplicative property of 0: \(a \cdot 0 = 0 \cdot a = 0\)
  6. Multiplicative property of 1: \(a \cdot 1 = 1 \cdot a = a\)
Key Insight — Multiplicative Property of −1

Multiplying any number by \(-1\) gives its opposite:

$$a(-1) = (-1)a = -a$$

Special case: \((-1)(-1) = 1\). This is why the product of two negative numbers is positive.

Summary — Products of Multiple Factors
  1. The absolute value of a product equals the product of the absolute values: \(|ab| = |a| \cdot |b|\).
  2. A product with an odd number of negative factors is negative.
  3. A product with an even number of negative factors is positive.

4-9 · Dividing Directed Numbers

Definition — Division

If \(b \neq 0\), the quotient \(a \div b\) (or \(\frac{a}{b}\)) is the number \(x\) satisfying \(xb = a\). Division by zero is not defined.

Every nonzero number \(a\) has a reciprocal (multiplicative inverse) \(\frac{1}{a}\) such that \(a \cdot \frac{1}{a} = 1\). This lets us express division as multiplication:

Rule — Division
$$a \div b = a \cdot \frac{1}{b}, \quad b \neq 0$$

To divide, replace the divisor by its reciprocal and multiply.

The sign rules for division are the same as for multiplication:

  • \(\frac{+}{+} = +\) and \(\frac{-}{-} = +\) (same signs give a positive quotient)
  • \(\frac{+}{-} = -\) and \(\frac{-}{+} = -\) (different signs give a negative quotient)
Property — Reciprocal of a Product

The reciprocal of a product of two nonzero numbers is the product of their reciprocals:

$$\frac{1}{ab} = \frac{1}{a} \cdot \frac{1}{b}$$

4-10 · Averages and Directed Numbers (Optional)

To find the average \(A\) of a set of \(n\) numbers, use a guessed average \(G\) and compute deviations from it:

Formula — Average via Deviations
$$A = G + \frac{\text{sum of deviations}}{n}$$

where each deviation is the number's value minus \(G\).

This technique is especially handy when the data values are large or when some are negative. The closer \(G\) is to the true average, the smaller the deviations will be.

Worked Problems

Problem 1 — Adding Directed Numbers

Find the sum: \((-24) + [(-37) + 45]\)

Solution
1
Evaluate the inner brackets first: \((-37) + 45 = 8\)
2
Now add: \((-24) + 8 = -16\)

Answer: \(-16\)

Problem 2 — Subtraction as Addition

Rewrite as addition and evaluate: \(89 - 99\)

Solution
1
Rewrite: \(89 - 99 = 89 + (-99)\)
2
Since the signs differ, subtract absolute values: \(99 - 89 = 10\)
3
The larger absolute value (99) belongs to the negative number, so the result is negative.

Check: \(-10 + 99 = 89\) ✓

Answer: \(-10\)

Problem 3 — Multiplication with the Distributive Property

Evaluate: \((-3)[7 - (-2)]\)

Solution

Method (a) — Simplify inside first:

1
\((-3)[7 - (-2)] = (-3)[7 + 2] = (-3)(9) = -27\)

Method (b) — Use the distributive property:

1
\((-3)[7 - (-2)] = (-3)(7) - (-3)(-2) = -21 - 6 = -27\)

Answer: \(-27\)

Problem 4 — Opposites and Simplification

Simplify: \(-(-2) + (-5)\)

Solution
1
Apply the double-negative rule: \(-(-2) = 2\)
2
Add: \(2 + (-5) = -3\)

Answer: \(-3\)

Problem 5 — Division and Combining Terms

Simplify: \(6x - 4y - 5x + 8y + 7x - 9y\)

Solution
1
Group like terms using the distributive property:
$$(6 - 5 + 7)x + (-4 + 8 - 9)y$$
2
Simplify coefficients: \(8x + (-5)y = 8x - 5y\)

Answer: \(8x - 5y\)

Problem 6 — Average with Directed Numbers

Using an assumed average of \(-3\)°, find the true average of these hourly temperatures: \(-5°,\ -5°,\ -3°,\ -1°,\ 0°,\ 3°,\ 10°,\ 13°\)

Solution
1
Let \(G = -3\). Compute deviations (each value minus \(-3\)):
TemperatureDeviation from −3
\(-5\)\(-5 - (-3) = -2\)
\(-5\)\(-2\)
\(-3\)\(0\)
\(-1\)\(2\)
\(0\)\(3\)
\(3\)\(6\)
\(10\)\(13\)
\(13\)\(16\)
2
Sum of deviations: \(-2 + (-2) + 0 + 2 + 3 + 6 + 13 + 16 = 36\)
3
Average deviation: \(\frac{36}{8} = 4.5\)
4
True average: \(A = G + 4.5 = -3 + 4.5 = 1.5°\)

Answer: The average temperature is \(1.5°\).

Quick Reference

Chapter Summary
  1. Directed numbers include positives, negatives, and zero. On the number line, negative numbers extend to the left of 0; positive numbers to the right.
  2. Ordering: \(a < b\) means \(a\) is to the left of \(b\).
  3. Opposite (additive inverse): \(a + (-a) = 0\); also \(-(-a) = a\) and \(-(a+b) = -a + (-b)\).
  4. Absolute value: \(|a| \geq 0\); equals \(a\) if \(a \geq 0\), equals \(-a\) if \(a < 0\).
  5. Addition rules: Same signs — add magnitudes, keep sign. Different signs — subtract magnitudes, take sign of larger.
  6. Subtraction: \(a - b = a + (-b)\).
  7. Multiplication: \(|ab| = |a| \cdot |b|\). Same signs give positive; different signs give negative.
  8. Division: \(\frac{a}{b} = a \cdot \frac{1}{b}\), \(b \neq 0\). Same sign rules as multiplication.
  9. Key properties: \(a \cdot (-1) = -a\); \((-1)(-1) = 1\); \(a \cdot 0 = 0\).
