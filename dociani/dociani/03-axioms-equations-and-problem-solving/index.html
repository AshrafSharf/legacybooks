3-1 Axioms of Equality

You learned to perform many operations with numbers because you followed certain rules. These rules, which are statements accepted as true, are called assumptions, axioms, or postulates. Though some may seem simple, you must be able to understand and use them in solving complicated problems.

Reflexive Property of Equality

Any number is equal to itself.

For any number \(a\):   \(a = a\)

Symmetric Property of Equality

An equality is reversible.

For any numbers \(a\) and \(b\):   if \(a = b\), then \(b = a\)

Transitive Property of Equality

If two numbers each equal a third number, then they are equal to each other.

For any numbers \(a\), \(b\), and \(c\):   if \(a = b\) and \(b = c\), then \(a = c\)

Key Insight

These three properties — reflexive, symmetric, and transitive — define what mathematicians call an equivalence relation. They govern every use of the equals sign in algebra.

The axioms of equality form the logical foundation; the balance principle guides equation solving.

3-2 The Closure Properties

When you add two whole numbers, is the result always a whole number? After checking many examples — \(138 + 51 = 189\),   \(174 + 236 = 410\) — you would probably assume that the answer is yes. The same holds for multiplication: \(5 \times 37 = 185\),   \(23 \times 48 = 1104\).

Definition — Closure

A set \(S\) is said to be closed under an operation if each result of the operation on elements of \(S\) is itself an element of \(S\).

Closure Property of Addition

For every number \(a\) and every number \(b\), the sum \(a + b\) is a unique number (one and only one number).

Closure Property of Multiplication

For every number \(a\) and every number \(b\), the product \(ab\) is a unique number.

Key Insight

Closure depends on both the operation and the set. The set of odd numbers is closed under multiplication (\(3 \times 5 = 15\)), but not under addition (\(3 + 5 = 8\), which is even). The set of whole numbers is not closed under division, but the set of positive arithmetic numbers is.

Substitution Principle

For any numbers \(a\) and \(b\): if \(a = b\), then \(a\) and \(b\) may be substituted for each other in any expression.

3-3 Commutative and Associative Properties

You know that \(6 + 3 = 3 + 6\), and \(6 \times 3 = 3 \times 6\). These observations lead to two fundamental properties.

Commutative Properties (Order)

Commutative Property of Addition

For every number \(a\) and every number \(b\):   \(a + b = b + a\)

Commutative Property of Multiplication

For every number \(a\) and every number \(b\):   \(ab = ba\)

Caution

Subtraction and division are not commutative: \(6 - 3 \neq 3 - 6\) and \(6 \div 3 \neq 3 \div 6\).

Associative Properties (Grouping)

Associative Property of Addition

For every \(a\), \(b\), \(c\):   \(a + (b + c) = (a + b) + c\)

Associative Property of Multiplication

For every \(a\), \(b\), \(c\):   \(a(bc) = (ab)c\)

Key Insight — Why This Matters

Together, the commutative (order) and associative (grouping) properties let you omit parentheses in a sum and add in any order:

\(101 + 33 + 46 + 67 + 14 + 99 = (101 + 99) + (33 + 67) + (46 + 14) = 200 + 100 + 60 = 360\)

3-4 The Distributive Property; Special Properties of 1 and 0

Consider: you can compute \(95 \times 10\) either as \(95(3 + 7)\) or as \(95 \times 3 + 95 \times 7\). Either way you get \(950\). The number 95 is distributed as a multiplier of each term.

Distributive Property (Multiplication over Addition)

For every \(a\), \(b\), \(c\):   \(a(b + c) = ab + ac\)   and   \(ab + ac = a(b + c)\)

Distributive Property (Multiplication over Subtraction)

For each \(a\), \(b\), and \(c\) (where \(b - c\) is defined):   \(a(b - c) = ab - ac\)

The distributive property is the key tool for combining like terms:

\(5x + 3x = x(5 + 3) = x \cdot 8 = 8x\)

Similar (Like) Terms

Similar terms are numerical terms, or variable terms whose variable factors are the same. For example, \(5x\) and \(3x\) are like terms; \(7ab\) and \(4ab\) are like terms. The terms \(8x\) and \(3ab\) are unlike terms because their variable factors differ.

Special Properties of 1 and 0

Multiplicative Property of 1 (Identity)

For each \(a\):   \(1 \cdot a = a \cdot 1 = a\)

The number 1 is the multiplicative identity element.

Additive Property of 0 (Identity)

For each \(a\):   \(0 + a = a + 0 = a\)

The number 0 is the additive identity element.

Multiplicative Property of 0

For each \(a\):   \(0 \cdot a = a \cdot 0 = 0\)

Caution — Division by Zero

The statement \(\frac{a}{0} = b\) would mean \(a = 0 \cdot b\). If \(a \neq 0\), no value of \(b\) works (since \(0 \cdot b = 0\)). If \(a = 0\), every value of \(b\) works. Either way, the result is meaningless. You may never divide by 0.

3-5 Transforming Equations: Addition and Subtraction

Addition Property of Equality

If the same number is added to equal numbers, the sums are equal.

For each \(a\), \(b\), \(c\):   if \(a = b\), then \(a + c = b + c\)

Subtraction Property of Equality

If the same number is subtracted from equal numbers, the differences are equal.

For each \(a\), \(b\), \(c\) (where \(a - c\) is defined):   if \(a = b\), then \(a - c = b - c\)

Inverse Operations

Adding and subtracting the same number are inverse operations — they undo each other:

\(a - c + c = a\)    and    \(a + c - c = a\)

To undo a subtraction, add. To undo an addition, subtract. Using these operations to solve an equation produces an equivalent equation (one with the same solution set).

3-6 Multiplication and Division Properties of Equality

Multiplication Property of Equality

For each \(a\), \(b\), \(c\):   if \(a = b\), then \(ac = bc\)

Division Property of Equality

For each \(a\), \(b\), \(c\) (\(c \neq 0\)):   if \(a = b\), then \(\dfrac{a}{c} = \dfrac{b}{c}\)

Caution — Never Multiply by Zero

Multiplying both sides of an equation by 0 collapses every equation into \(0 = 0\), which is satisfied by all numbers. This does not produce an equivalent equation, so multiplication by zero is forbidden in transforming equations.

3-7 Combining Terms and Using Transformation Principles

When solving an equation, you undo the operations used to build it, but in reverse order. Consider:

Building vs. Solving

Build:\(v = 5\) → multiply by 2 → \(2v = 10\) → add 7 → \(2v + 7 = 17\)
Solve:\(2v + 7 = 17\) → subtract 7 → \(2v = 10\) → divide by 2 → \(v = 5\)
Strategy for Solving Equations
  1. Combine any similar terms in either member.
  2. Undo indicated additions or subtractions (using inverse operations).
  3. Undo indicated multiplications or divisions (using inverse operations).
  4. Check by substituting the value into the original equation.

3-8 Equations Having the Variable in Both Members

An equation such as \(3t = 2t + 16\) has the variable on both sides. The transformation properties let you add or subtract any expression involving the variable from each member without changing the solution set.

Special Cases
  • No solution (empty set): If simplifying leads to a false statement like \(13 = 15\), the solution set is \(\varnothing\).
  • Identity (all numbers): If simplifying leads to a statement that is always true, like \(15d + 15 = 15d + 15\), the equation is an identity and every number is a solution.

Worked Problems

Problem 1 — Identifying Properties of Equality

Given: \(5 + 6 = 14 - 3\). Name the property that tells us \(14 - 3 = 5 + 6\).

Solution

The equation was reversed—the left side and right side switched places. This is the symmetric property of equality: if \(a = b\), then \(b = a\).

Problem 2 — Solving by Addition (Undoing Subtraction)

Solve: \(n - 6 = 19\)

Solution
\(n - 6 = 19\)Given equation
\(n - 6 + 6 = 19 + 6\)Add 6 to both sides (addition property)
\(n = 25\)Simplify

Check: \(25 - 6 = 19\) ✓

The solution set is \(\{25\}\).

Problem 3 — Solving by Division

Solve: \(\dfrac{2x}{5} = 86\)

Solution
\(\dfrac{2x}{5} = 86\)Given equation
\(2x = 5 \cdot 86\)Multiply both sides by 5
\(2x = 430\)Simplify
\(x = \dfrac{430}{2}\)Divide both sides by 2
\(x = 215\)

Check: \(\dfrac{2(215)}{5} = \dfrac{430}{5} = 86\) ✓

The solution set is \(\{215\}\).

Problem 4 — Combining Like Terms

Solve: \(7x + 3x - 4 = 12 + 39\)

Solution
\(7x + 3x - 4 = 12 + 39\)Given equation
\(10x - 4 = 51\)Combine like terms on each side
\(10x = 51 + 4\)Add 4 to both sides
\(10x = 55\)Simplify
\(x = 5.5\)Divide both sides by 10

Check: \(7(5.5) + 3(5.5) - 4 = 38.5 + 16.5 - 4 = 51\) and \(12 + 39 = 51\) ✓

The solution set is \(\{5.5\}\).

Problem 5 — Variable on Both Sides

Solve: \(x + 4x - 8 = 6 + 2x + 1\)

Solution
\(x + 4x - 8 = 6 + 2x + 1\)Given equation
\(5x - 8 = 2x + 7\)Combine like terms on each side
\(5x - 2x - 8 = 7\)Subtract \(2x\) from both sides
\(3x - 8 = 7\)Simplify
\(3x = 15\)Add 8 to both sides
\(x = 5\)Divide both sides by 3

Check: \(5 + 20 - 8 = 17\) and \(6 + 10 + 1 = 17\) ✓

The solution set is \(\{5\}\).

Problem 6 — An Equation with No Solution

Solve: \(1 + 3(2s + 4) = 15 + 6s\)

Solution
\(1 + 3(2s + 4) = 15 + 6s\)Given equation
\(1 + 6s + 12 = 15 + 6s\)Distribute the 3
\(6s + 13 = 15 + 6s\)Combine like terms
\(13 = 15\)Subtract \(6s\) from both sides

This is a false statement for every value of \(s\). The equation has no root.

The solution set is \(\varnothing\) (the empty set).

Solving Strategy Summary
  1. Simplify — carry out indicated multiplications; combine similar terms in each member.
  2. Undo addition/subtraction — use the inverse operation to isolate variable terms.
  3. Undo multiplication/division — use the inverse operation to find the value of the variable.
  4. Check — substitute the value into the original equation to verify.
