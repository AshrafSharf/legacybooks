10-1 · The Graphic Method

When the graphs of two linear equations in the same two variables are drawn on the same set of axes, three outcomes are possible:

  • No point in common — the lines are parallel (inconsistent system).
  • All points in common — the lines coincide (dependent system).
  • Exactly one point in common — the lines intersect (independent, consistent system).
Definition — System of Simultaneous Equations

Two equations that impose two conditions on the same variables at the same time form a system of simultaneous equations. To solve such a system means to find all ordered pairs \((x, y)\) that satisfy both equations.

Figure 10-1. The system \(y = x + 4\) and \(y = 3x\) has exactly one solution at \((2, 6)\).

Key Insight — Types of Systems
  • Inconsistent: No common root (parallel lines). Example: \(y = x + 4\) and \(y = x - 1\).
  • Consistent & Dependent: Infinitely many solutions (lines coincide). Example: \(y = x + 4\) and \(2y = 2x + 8\).
  • Consistent & Independent: Exactly one solution (lines intersect). Example: \(y = x + 4\) and \(y = 3x\).

10-2 · The Addition and Subtraction Method

Graphing can be imprecise. An algebraic method avoids inaccuracies. If a variable has the same (or opposite) coefficient in both equations, you can add or subtract the equations to eliminate it.

Method — Addition / Subtraction (Elimination)
  1. Write both equations with like terms aligned.
  2. Add or subtract the equations to eliminate one variable.
  3. Solve the resulting equation for the remaining variable.
  4. Substitute back into either original equation to find the other variable.
  5. Check the solution in both original equations.
Worked Example 1 — Simple Elimination

Solve: \(x + 4y = 27\) and \(x + 2y = 21\)

1 Subtract the second equation from the first:
$$(x + 4y) - (x + 2y) = 27 - 21$$ $$2y = 6$$
2 Solve for \(y\):
$$y = 3$$
3 Substitute \(y = 3\) into \(x + 2y = 21\):
$$x + 2(3) = 21 \implies x + 6 = 21 \implies x = 15$$
4 Check in both equations:
$$15 + 4(3) = 15 + 12 = 27 \;\checkmark \qquad 15 + 2(3) = 15 + 6 = 21 \;\checkmark$$

Solution set: \(\{(15, 3)\}\)

10-3 · Solving Problems with Two Variables

Many word problems become simpler when you introduce two variables instead of one. The strategy is:

  1. Choose two variables to represent the unknown quantities.
  2. Translate the given conditions into two equations.
  3. Solve the system.
  4. Check the answer against the original wording of the problem.
Worked Example 2 — Library Charges

Problem: A lending library has a fixed charge for the first three days and an additional charge for each day thereafter. Tom paid 27 cents for a book he kept 7 days, while Sue paid 21 cents for one she kept 5 days. Find the fixed charge and the daily extra charge.

1 Let \(x\) = fixed charge (cents), \(y\) = extra daily charge (cents).
2 Tom kept his book 7 days = 3 fixed + 4 extra days:
$$x + 4y = 27$$
3 Sue kept hers 5 days = 3 fixed + 2 extra days:
$$x + 2y = 21$$
4 Subtract: \(2y = 6\), so \(y = 3\). Then \(x = 21 - 6 = 15\).

The fixed charge is 15 cents and each extra day costs 3 cents.

Worked Example 3 — Digit Problem

Problem: The sum of the digits of a two-digit numeral is 10. When the digits are interchanged, the resulting number is 18 more than the original. Find the original number.

1 Let \(t\) = tens digit and \(u\) = units digit. The original number is \(10t + u\).
2 The sum of the digits is 10:
$$t + u = 10$$
3 The reversed number exceeds the original by 18:
$$(10u + t) - (10t + u) = 18 \implies 9u - 9t = 18 \implies u - t = 2$$
4 Solve the system \(t + u = 10\) and \(u - t = 2\). Adding: \(2u = 12\), so \(u = 6\) and \(t = 4\).
5 Check: \(4 + 6 = 10 \;\checkmark\). And \(64 - 46 = 18 \;\checkmark\).

The original number is 46.

10-4 · Multiplication in the Addition/Subtraction Method

When no variable has the same absolute-value coefficient in both equations, you must first multiply one or both equations by suitable constants so that corresponding coefficients match.

Strategy

Given \(ax + by = c\) and \(dx + ey = f\), multiply the first equation by \(d\) and the second by \(a\) (or find the LCM of the coefficients of one variable) so that when you add or subtract, that variable is eliminated.

Worked Example 4 — Multiply One Equation

Solve: \(3x + 4y = 45\) and \(6x - 2y = 30\)

1 Multiply the first equation by 2 so the \(x\)-coefficients match:
$$2(3x + 4y) = 2(45) \implies 6x + 8y = 90$$
2 Subtract the second equation from the new equation:
$$(6x + 8y) - (6x - 2y) = 90 - 30$$ $$10y = 60 \implies y = 6$$
3 Substitute \(y = 6\) into \(3x + 4(6) = 45\):
$$3x + 24 = 45 \implies 3x = 21 \implies x = 7$$
4 Check: \(3(7) + 4(6) = 21 + 24 = 45 \;\checkmark\) and \(6(7) - 2(6) = 42 - 12 = 30 \;\checkmark\).

Solution set: \(\{(7, 6)\}\)

Worked Example 5 — Multiply Both Equations

Solve: \(2x + 5y = 28\) and \(3x + 2y = 31\)

1 To eliminate \(y\), multiply the first equation by 2 and the second by \(-5\):
$$\begin{aligned} -2(2x + 5y) &= -2(28) &\implies& \quad -4x - 10y = -56 \\ 5(3x + 2y) &= 5(31) &\implies& \quad 15x + 10y = 155 \end{aligned}$$
2 Add the equations:
$$11x = 99 \implies x = 9$$
3 Substitute into \(3x + 2y = 31\): \(27 + 2y = 31\), so \(2y = 4\) and \(y = 2\).
4 Check: \(2(9) + 5(2) = 28 \;\checkmark\) and \(3(9) + 2(2) = 31 \;\checkmark\).

Solution set: \(\{(9, 2)\}\)

10-5 · The Substitution Method

You can solve either equation for one variable in terms of the other, then substitute that expression into the remaining equation. This is especially convenient when one equation is already solved for a variable or has a coefficient of 1.

Method — Substitution
  1. Solve one equation for one variable (pick the easiest one).
  2. Substitute the expression into the other equation.
  3. Solve the resulting single-variable equation.
  4. Back-substitute to find the other variable.
  5. Check in both original equations.
Worked Example 6 — Substitution

Solve: \(x + 4y = 3\) and \(2x - 3y = 17\)

1 Solve the first equation for \(x\):
$$x = 3 - 4y$$
2 Substitute into the second equation:
$$2(3 - 4y) - 3y = 17$$ $$6 - 8y - 3y = 17$$ $$-11y = 11 \implies y = -1$$
3 Back-substitute: \(x = 3 - 4(-1) = 3 + 4 = 7\).
4 Check: \(7 + 4(-1) = 3 \;\checkmark\) and \(2(7) - 3(-1) = 14 + 3 = 17 \;\checkmark\).

Solution set: \(\{(7, -1)\}\)

When to Use Each Method
  • Graphing: Good for understanding; less precise.
  • Addition/Subtraction (Elimination): Best when coefficients are easy to match.
  • Substitution: Best when one variable already has a coefficient of 1 or is already isolated.

10-6 · Graphs of Pairs of Linear Inequalities

Graphs can also determine the solution set of simultaneous inequalities. Each inequality defines a half-plane; the intersection of those half-planes is the solution set (the feasible region).

Definition — Feasible Region

The feasible region (or solution set) of a system of inequalities is the set of all points \((x, y)\) that satisfy every inequality in the system simultaneously.

Figure 10-2. The solution set of \(y > 3x - 2\) and \(x + y < 6\) is the shaded region. The boundary lines are dashed because the inequalities are strict.

Convex Regions and Linear Programming

When a finite number of straight lines separate a plane into regions, the resulting bounded regions are called convex regions. A remarkable property: over any closed convex polygon, a linear expression \(mx + ny\) achieves its maximum and minimum values at the vertices of the polygon. This fact is the foundation of linear programming.

Practice Problems

Practice 1 — Graphing

Solve graphically: \(y = 3 - x\) and \(y = 1 + x\).

Show Solution

Setting equal: \(3 - x = 1 + x \implies 2 = 2x \implies x = 1\), so \(y = 2\).

Solution: \((1, 2)\)

Practice 2 — Addition/Subtraction

Solve: \(x + y = 74\) and \(x - y = 16\).

Show Solution

Add the equations: \(2x = 90\), so \(x = 45\). Then \(y = 74 - 45 = 29\).

Check: \(45 + 29 = 74 \;\checkmark\) and \(45 - 29 = 16 \;\checkmark\).

Solution: \(\{(45, 29)\}\)

Practice 3 — Word Problem

Half the perimeter of a house, which is 12 feet longer than it is wide, is 72 feet. What are the dimensions?

Show Solution

Let \(l\) = length and \(w\) = width.

$$l = w + 12 \quad \text{and} \quad l + w = 72$$

Substituting: \((w + 12) + w = 72 \implies 2w = 60 \implies w = 30\), so \(l = 42\).

The house is 42 ft long and 30 ft wide.

Practice 4 — Multiplication with Elimination

Solve: \(3p - q = 10\) and \(2p - q = 1\).

Show Solution

Subtract the second from the first: \((3p - q) - (2p - q) = 10 - 1\), giving \(p = 9\).

Then \(q = 3(9) - 10 = 17\).

Check: \(3(9) - 17 = 10 \;\checkmark\) and \(2(9) - 17 = 1 \;\checkmark\).

Solution: \(\{(9, 17)\}\)

Practice 5 — Investment Problem

A man wishes to earn $33 per year. He invests $600, part at 4% and the rest at 6%. How much does he invest at each rate?

Show Solution

Let \(x\) = amount at 4% and \(y\) = amount at 6%.

$$x + y = 600$$ $$0.04x + 0.06y = 33$$

From the first equation: \(x = 600 - y\). Substituting:

$$0.04(600 - y) + 0.06y = 33$$ $$24 - 0.04y + 0.06y = 33$$ $$0.02y = 9 \implies y = 450$$

So \(x = 600 - 450 = 150\).

Check: \(0.04(150) + 0.06(450) = 6 + 27 = 33 \;\checkmark\).

\$150 at 4% and \$450 at 6%.

Practice 6 — Inequalities

Graph the solution set of: \(y < 2x\) and \(x + y \leq 6\).

Show Solution

Draw the line \(y = 2x\) as a dashed line (strict inequality). The solution set of \(y < 2x\) is the half-plane below this line.

Draw the line \(x + y = 6\) as a solid line (\(\leq\)). The solution set of \(x + y \leq 6\) is the half-plane below and on this line.

The intersection of the two boundary lines: \(2x = -x + 6 \implies 3x = 6 \implies x = 2, y = 4\). The vertex is \((2, 4)\).

The feasible region is the overlap below both lines, with the intersection point at \((2, 4)\).

Quick Reference

Three Methods for Solving Systems
Method Procedure Best When
Graphing Graph both lines; read intersection Visualizing; estimating solutions
Elimination Add/subtract equations to eliminate a variable Coefficients easily matched
Substitution Solve one eq. for a variable; substitute into the other One variable has coefficient 1
System Classification
  • Consistent & Independent: Exactly one solution (lines intersect).
  • Consistent & Dependent: Infinitely many solutions (lines coincide).
  • Inconsistent: No solution (lines are parallel).
Systems of Inequalities

To graph a system of linear inequalities:

  1. Graph each boundary line (solid for \(\leq\) or \(\geq\); dashed for \(<\) or \(>\)).
  2. Shade the half-plane satisfying each inequality.
  3. The feasible region is the overlap of all shaded half-planes.
Linear Programming Principle

Over a closed convex polygon, any linear expression \(mx + ny\) assumes its maximum and minimum values at vertices of the polygon. Therefore, to optimize a linear objective over a system of linear inequalities, evaluate the expression at each vertex of the feasible region.

Common Mistakes
  • Forgetting to multiply both sides of an equation when preparing for elimination.
  • Subtracting only one term instead of the entire equation.
  • Substituting back into the derived equation rather than an original one (which can mask errors).
  • Confusing strict (\(<, >\)) and non-strict (\(\leq, \geq\)) inequalities when drawing boundary lines.
  • Forgetting to check the answer in both original equations.
