9-1 Open Sentences in Two Variables

Many practical problems lead naturally to equations with two variables. For example, if Nancy has $1.20 to buy cookies costing 2¢ and 3¢ each, and she buys \(x\) of the first and \(y\) of the second, then:

$$2x + 3y = 120$$
Definition — Solution of a Two-Variable Sentence
A root (or solution) of an open sentence in two variables is an ordered pair \((x, y)\) that makes the sentence true when \(x\) is replaced by the first element and \(y\) by the second.

Unlike one-variable equations that have at most a few solutions, an equation in two variables typically has infinitely many solutions. To find specific solutions, you fix a value for one variable and solve for the other.

Key Insight — Ordered Pairs
Order matters! The pair \((3, 5)\) is not the same as \((5, 3)\). Two ordered pairs \((a, b)\) and \((c, d)\) are equal if and only if \(a = c\) and \(b = d\).
Example
Find the solution set of \(2x + 3y = 120\) if \(x \in \{0, 15, 30, 45, 60\}\) and \(y \in \{\text{whole numbers}\}\).

Solve for \(y\): \(\;y = \dfrac{120 - 2x}{3}\)

\(x\)015304560
\(y\)403020100

Solution set: \(\{(0,40),\,(15,30),\,(30,20),\,(45,10),\,(60,0)\}\)

9-2 Coordinates in a Plane

Each root of a one-variable equation is a single number graphed on a number line. Each root of a two-variable equation is an ordered pair, graphed on two number lines intersecting at right angles.

Definition — The Coordinate Plane
  • The horizontal number line is the x-axis (horizontal axis).
  • The vertical number line is the y-axis (vertical axis).
  • Their point of intersection is the origin, with coordinates \((0, 0)\).
  • The first number in \((x, y)\) is the abscissa (x-coordinate); the second is the ordinate (y-coordinate).

The axes divide the plane into four quadrants, numbered counterclockwise starting from the upper right. Points on the axes do not belong to any quadrant.

9-3 The Graph of a Linear Equation

If \(\{\text{directed numbers}\}\) is the replacement set for both \(x\) and \(y\), every root of a linear equation corresponds to a point in the coordinate plane. The remarkable fact is that all these points lie on a straight line, and every point on the line satisfies the equation.

Definition — Linear Equation in Two Variables
An equation is linear if each term is either a constant or a monomial of degree 1. Thus \(5x - 4y = 3\) is linear, but \(\dfrac{1}{x} + y = 3\), \(x^2 - 4y = 3\), and \(xy = 6\) are not linear.

Because the graph is a straight line, two points are enough to draw it. Plotting a third point as a check is always good practice. Two particularly convenient points are the intercepts.

Finding the Intercepts
  • x-intercept: Set \(y = 0\) and solve for \(x\).
  • y-intercept: Set \(x = 0\) and solve for \(y\).
Example — Graphing by Intercepts

Graph \(2x + 3y = 12\).

Solve for \(y\): \(\;y = 4 - \tfrac{2}{3}x\)

\(x\)036
\(y\)420

The x-intercept is \((6, 0)\) and the y-intercept is \((0, 4)\). Plot these points and draw the line through them; the third point \((3, 2)\) confirms the line is correct.

9-4 Slope of a Line

To describe the steepness of a road, engineers use grade: the vertical rise per 100 feet of horizontal run. For a line in the coordinate plane, we measure steepness with the slope.

The Slope Formula
For two distinct points \(P(x_1, y_1)\) and \(Q(x_2, y_2)\) on a line, the slope is: $$m = \frac{\text{rise}}{\text{run}} = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\text{difference of ordinates}}{\text{difference of abscissas}}$$ provided \(x_1 \neq x_2\).
Figure 9.2 — Computing slope as rise over run between two points
Key Insight — Sign of the Slope
  • A line that rises from left to right has a positive slope.
  • A line that falls from left to right has a negative slope.
  • A horizontal line has slope \(m = 0\).
  • A vertical line has no slope (undefined — division by zero).
Caution
The slope of a vertical line is undefined, not zero. A horizontal line has slope \(0\); a vertical line has no slope at all. Do not confuse the two!

9-5 The Slope-Intercept Form

Any equation of the form \(y = mx\) passes through the origin and has slope \(m\). Adding a constant \(b\) shifts the line vertically:

Slope-Intercept Form
$$y = mx + b$$ where \(m\) is the slope and \(b\) is the y-intercept (the ordinate of the point where the line crosses the y-axis).

The y-intercept is found by setting \(x = 0\). For example, in \(y = 3x + 4\), the slope is \(3\) and the y-intercept is \(4\). This means the line crosses the y-axis at \((0, 4)\).

Example — Graphing Using Slope and y-Intercept

Draw the line with \(m = \frac{3}{4}\) and \(b = -2\), then find its equation.

  1. Mark the y-intercept: \((0, -2)\).
  2. From \((0, -2)\), move 4 units right and 3 units up to locate a second point: \((4, 1)\).
  3. Draw the line through these two points.

The equation is \(\;y = \tfrac{3}{4}x - 2\;\) or equivalently \(\;4y = 3x - 8\).

Key Insight — Parallel Lines
Two non-vertical lines are parallel if and only if they have the same slope. For instance, \(y = 3x + 4\) and \(y = 3x - 1\) are parallel (both have slope 3), but they cross the y-axis at different points.

9-6 Writing the Equation of a Line

Given the slope \(m\) and a point \((x_1, y_1)\) on the line, you can find the equation by substituting into the slope-intercept form and solving for \(b\).

Method: Finding an Equation from a Point and Slope
  1. Start with \(y = mx + b\).
  2. Substitute the known slope \(m\) and the coordinates of the known point \((x_1, y_1)\).
  3. Solve for \(b\).
  4. Write the equation: \(y = mx + b\).
Method: Finding an Equation from Two Points
  1. Compute the slope: \(\;m = \dfrac{y_2 - y_1}{x_2 - x_1}\).
  2. Use either point with the slope to find \(b\) as above.
Example

Find the equation of the line through \((-4, -3)\) with slope \(\tfrac{5}{2}\).

Substitute into \(y = mx + b\):

$$-3 = \tfrac{5}{2}(-4) + b \quad\Longrightarrow\quad -3 = -10 + b \quad\Longrightarrow\quad b = 7$$

The equation is \(\;y = \tfrac{5}{2}x + 7\;\) or \(\;2y = 5x + 14\).

9-7 Graphing Inequalities in Two Variables

The graph of a linear equation divides the coordinate plane into two half-planes. Each half-plane is the graph of one of the corresponding inequalities.

Graphing a Linear Inequality
  1. Solve the inequality for \(y\).
  2. Graph the boundary line (the corresponding equation).
    • Use a solid line for \(\geq\) or \(\leq\) (boundary included).
    • Use a dashed line for \(>\) or \(<\) (boundary excluded).
  3. Shade the half-plane above the line for \(y >\) or \(y \geq\); shade below for \(y <\) or \(y \leq\).
Figure 9.3 — The graph of \(y > x - 2\): the shaded half-plane above the dashed boundary line
Key Insight — Testing a Point
If you are unsure which side to shade, pick a test point not on the line (the origin \((0, 0)\) is often convenient). Substitute into the inequality: if the result is true, shade the side containing the test point; if false, shade the other side.

9-8 / 9-9 Functions

Many situations in science and daily life involve quantities that depend on each other. The concept of a function formalizes this idea of dependence.

Definition — Function
A function is a set of ordered pairs in which no two different pairs have the same first element. Equivalently, a function assigns to each value in its domain exactly one value in its range.
Definition — Domain and Range
  • The domain of a function is the set of all first elements (inputs).
  • The range of a function is the set of all second elements (outputs).

The equation \(y = 2x + 1\) defines a function: for each input \(x\), there is exactly one output \(y\). We can write this as \(f(x) = 2x + 1\), and read “\(f\) of \(x\)” to mean “the value of the function \(f\) at \(x\).”

Caution — Not Every Equation Defines a Function
The equation \(x^2 + y^2 = 25\) is not a function of \(x\), because for some values of \(x\), there are two corresponding values of \(y\). For example, when \(x = 3\), \(y = 4\) or \(y = -4\).
Key Insight — Vertical Line Test
A graph represents a function if and only if every vertical line intersects the graph in at most one point. If any vertical line hits the graph in two or more points, the relation is not a function.

Worked Problems

Worked Problem 1 — Plotting Points and Identifying Quadrants
Plot the points \(A(3, 4)\), \(B(-2, 5)\), \(C(-3, -1)\), and \(D(4, -3)\). State which quadrant each point lies in.
Solution
  1. \(A(3, 4)\): both coordinates positive, so \(A\) is in Quadrant I.
  2. \(B(-2, 5)\): negative \(x\), positive \(y\), so \(B\) is in Quadrant II.
  3. \(C(-3, -1)\): both coordinates negative, so \(C\) is in Quadrant III.
  4. \(D(4, -3)\): positive \(x\), negative \(y\), so \(D\) is in Quadrant IV.
Worked Problem 2 — Graphing a Linear Equation
Graph \(3x + 2y = 6\) by finding the intercepts.
Solution
  1. x-intercept: Set \(y = 0\): \(\;3x = 6\), so \(x = 2\). The point is \((2, 0)\).
  2. y-intercept: Set \(x = 0\): \(\;2y = 6\), so \(y = 3\). The point is \((0, 3)\).
  3. Check point: Let \(x = 4\): \(\;12 + 2y = 6\), so \(2y = -6\), \(y = -3\). The point \((4, -3)\) should also lie on the line.
  4. Plot \((2, 0)\), \((0, 3)\), and \((4, -3)\); draw the straight line through them.

Answer: The graph is a straight line passing through \((0, 3)\) and \((2, 0)\), with equation \(y = -\tfrac{3}{2}x + 3\).

Worked Problem 3 — Computing Slope
Find the slope of the line through \(P(-3, 4)\) and \(Q(5, -2)\).
Solution
  1. Apply the slope formula: $$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{-2 - 4}{5 - (-3)} = \frac{-6}{8} = -\frac{3}{4}$$
  2. The slope is negative, confirming the line falls from left to right.

Answer: \(\;m = -\dfrac{3}{4}\)

Worked Problem 4 — Writing the Equation of a Line
Find the equation of the line through \((2, 3)\) and \((5, 6)\).
Solution
  1. Compute the slope: $$m = \frac{6 - 3}{5 - 2} = \frac{3}{3} = 1$$
  2. Substitute \(m = 1\) and the point \((2, 3)\) into \(y = mx + b\): $$3 = 1(2) + b \quad\Longrightarrow\quad b = 1$$

Answer: \(\;y = x + 1\)

Check: At \((5, 6)\): \(6 = 5 + 1 = 6\). ✓

Worked Problem 5 — Graphing an Inequality
Graph the inequality \(x - y < 2\).
Solution
  1. Solve for \(y\): $$x - y < 2 \quad\Longrightarrow\quad -y < 2 - x \quad\Longrightarrow\quad y > x - 2$$ (Remember: multiplying by \(-1\) reverses the inequality.)
  2. Graph the boundary line \(y = x - 2\). Since the inequality is strict (\(>\), not \(\geq\)), use a dashed line.
  3. Shade the half-plane above the line, since we need \(y > x - 2\).
  4. Check: Test the origin \((0, 0)\): Is \(0 > 0 - 2 = -2\)? Yes. The origin is in the shaded region. ✓
Worked Problem 6 — Function Evaluation
Given \(f(x) = 3x^2 - 2x + 1\), find \(f(-2)\) and determine whether the set \(\{(-1, 6),\; (0, 1),\; (2, 9),\; (0, 3)\}\) defines a function.
Solution
  1. Evaluate \(f(-2)\): $$f(-2) = 3(-2)^2 - 2(-2) + 1 = 3(4) + 4 + 1 = 12 + 4 + 1 = 17$$
  2. Examine the set \(\{(-1, 6),\;(0, 1),\;(2, 9),\;(0, 3)\}\). The input \(x = 0\) appears in two pairs: \((0, 1)\) and \((0, 3)\) with different outputs. Since the same first element is paired with two different second elements, this set does not define a function.

Answers: \(f(-2) = 17\); the given set is not a function.
