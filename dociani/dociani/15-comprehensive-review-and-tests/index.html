Key Insight

Algebra is not a collection of disconnected rules. The properties of real numbers (commutative, associative, distributive) form the foundation, and every technique you have learned — from factoring to solving quadratics to trigonometry — is built logically on that foundation.

Key Formulas and Properties Reference

Fundamental Properties of Real Numbers

Properties of Addition and Multiplication

Closure: If \(a\) and \(b\) are real numbers, then \(a + b\) and \(a \cdot b\) are real numbers.

Commutative: \(a + b = b + a\) and \(a \cdot b = b \cdot a\)

Associative: \((a + b) + c = a + (b + c)\) and \((a \cdot b) \cdot c = a \cdot (b \cdot c)\)

Distributive: \(a(b + c) = ab + ac\)

Identity: \(a + 0 = a\) and \(a \cdot 1 = a\)

Inverse: \(a + (-a) = 0\) and \(a \cdot \tfrac{1}{a} = 1\) (for \(a \neq 0\))

Zero property: \(a \cdot 0 = 0\)

Laws of Exponents

Exponent Rules

\(a^m \cdot a^n = a^{m+n}\)   \(\dfrac{a^m}{a^n} = a^{m-n}\) (for \(a \neq 0\))   \((a^m)^n = a^{mn}\)

\((ab)^n = a^n b^n\)   \(\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}\)   \(a^0 = 1\) (for \(a \neq 0\))

Special Products and Factoring

Key Factoring Patterns

Difference of squares: \(a^2 - b^2 = (a + b)(a - b)\)

Trinomial square: \(a^2 + 2ab + b^2 = (a + b)^2\)   \(a^2 - 2ab + b^2 = (a - b)^2\)

Quadratic trinomial: \(ax^2 + bx + c\) — find factors of \(ac\) that add to \(b\)

Linear Equations and Graphing

Lines and Slope

Slope-intercept form: \(y = mx + b\) where \(m\) is slope and \(b\) is the \(y\)-intercept

Slope formula: \(m = \dfrac{y_2 - y_1}{x_2 - x_1}\)

Parallel lines: Same slope, different intercept   Standard form: \(ax + by = c\)

Quadratic Equations

The Quadratic Formula and Discriminant

For \(ax^2 + bx + c = 0\) with \(a \neq 0\):

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Discriminant: \(\Delta = b^2 - 4ac\)

If \(\Delta > 0\): two distinct real roots   If \(\Delta = 0\): one repeated root   If \(\Delta < 0\): no real roots

Sum of roots: \(r_1 + r_2 = -\tfrac{b}{a}\)   Product of roots: \(r_1 \cdot r_2 = \tfrac{c}{a}\)

Radicals and Real Numbers

Square Root Properties

Product property: \(\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}\)   (for \(a \geq 0, b \geq 0\))

Quotient property: \(\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\)   (for \(a \geq 0, b > 0\))

Rationalizing: \(\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}\)   \(\dfrac{1}{a + \sqrt{b}} = \dfrac{a - \sqrt{b}}{a^2 - b}\)

Pythagorean theorem: In a right triangle, \(a^2 + b^2 = c^2\)

Variation

Direct, Inverse, and Joint Variation

Direct: \(y = kx\)   (as \(x\) increases, \(y\) increases proportionally)

Inverse: \(xy = k\) or \(y = \dfrac{k}{x}\)   (as \(x\) increases, \(y\) decreases)

Joint: \(z = kxy\)   \(z\) varies jointly as \(x\) and \(y\)

Proportions: If \(\dfrac{a}{b} = \dfrac{c}{d}\), then \(ad = bc\) (cross-multiplication)

Trigonometric Functions

Right Triangle Trigonometry

For a right triangle with acute angle \(A\), opposite side \(a\), adjacent side \(b\), and hypotenuse \(c\):

$$\sin A = \frac{a}{c} \qquad \cos A = \frac{b}{c} \qquad \tan A = \frac{a}{b}$$

Pythagorean identity: \(\sin^2 A + \cos^2 A = 1\)

Relationship: \(\tan A = \dfrac{\sin A}{\cos A}\)

Similar triangles: The sides of two similar triangles are proportional: \(\dfrac{a}{a'} = \dfrac{b}{b'} = \dfrac{c}{c'}\)

Common Geometry Formulas

Area, Perimeter, and Volume

Rectangle: \(A = lw\), \(P = 2l + 2w\)   Square: \(A = s^2\), \(P = 4s\)

Triangle: \(A = \tfrac{1}{2}bh\)   Circle: \(A = \pi r^2\), \(C = 2\pi r\)

Trapezoid: \(A = \tfrac{1}{2}h(B + b)\)

Rectangular solid: \(V = lwh\)   Cube: \(V = s^3\)   Cylinder: \(V = \pi r^2 h\)

Vectors

Vector Operations

Resultant of perpendicular vectors: \(|\mathbf{R}| = \sqrt{V_1^2 + V_2^2}\)

Direction: \(\tan \theta = \dfrac{V_2}{V_1}\)

Components: Horizontal: \(V_x = V \cos \theta\),   Vertical: \(V_y = V \sin \theta\)

Cumulative Review Problems with Full Solutions

These eight problems span the entire course. Each one combines ideas from multiple chapters. Work through them carefully, and refer to the chapter summaries and formulas above as needed.

Problem 1 — Properties and Simplification (Ch 1–3, 6)
Problem

Give a reason (property, definition, or principle) to justify each step:

$$729 + (93 + 71) = 729 + (71 + 93) = (729 + 71) + 93 = 800 + 93 = 893$$
Solution

Step 1: \(729 + (93 + 71) = 729 + (71 + 93)\) — Commutative property of addition (reordering within the parentheses).

Step 2: \(729 + (71 + 93) = (729 + 71) + 93\) — Associative property of addition (regrouping to make computation easier).

Step 3: \((729 + 71) + 93 = 800 + 93 = 893\) — Substitution principle (replacing \(729 + 71\) with its value, 800).

Problem 2 — Factoring and Solving a Quadratic Equation (Ch 7, 13)
Problem

Solve by factoring: \(3x^2 - 21x^3 = 0\). Then solve \(x^2 - 6x + 3 = 0\) using the quadratic formula.

Solution

Part (a): Factor out the GCF:

$$3x^2 - 21x^3 = 3x^2(1 - 7x) = 0$$

Setting each factor to zero: \(3x^2 = 0 \Rightarrow x = 0\), and \(1 - 7x = 0 \Rightarrow x = \tfrac{1}{7}\).

Solution set: \(\left\{0,\; \tfrac{1}{7}\right\}\).

Part (b): For \(x^2 - 6x + 3 = 0\), we have \(a = 1\), \(b = -6\), \(c = 3\):

$$x = \frac{-(-6) \pm \sqrt{(-6)^2 - 4(1)(3)}}{2(1)} = \frac{6 \pm \sqrt{36 - 12}}{2} = \frac{6 \pm \sqrt{24}}{2}$$

Simplify: \(\sqrt{24} = 2\sqrt{6}\), so \(x = \dfrac{6 \pm 2\sqrt{6}}{2} = 3 \pm \sqrt{6}\).

Solution set: \(\{3 + \sqrt{6},\; 3 - \sqrt{6}\}\).

Problem 3 — Algebraic Fractions and Equations (Ch 8, 5)
Problem

Solve: \(\dfrac{2t}{3} + \dfrac{3t}{4} + \dfrac{17}{6} = 0\)

Solution

The LCD of 3, 4, and 6 is 12. Multiply every term by 12:

$$12 \cdot \frac{2t}{3} + 12 \cdot \frac{3t}{4} + 12 \cdot \frac{17}{6} = 0$$ $$8t + 9t + 34 = 0$$ $$17t + 34 = 0$$ $$17t = -34$$ $$t = -2$$

Check: \(\tfrac{2(-2)}{3} + \tfrac{3(-2)}{4} + \tfrac{17}{6} = -\tfrac{4}{3} - \tfrac{3}{2} + \tfrac{17}{6} = -\tfrac{8}{6} - \tfrac{9}{6} + \tfrac{17}{6} = \tfrac{0}{6} = 0\) ✓

Problem 4 — Systems of Equations and Word Problems (Ch 5, 10)
Problem

Mrs. Adams buys 2 yards of silk and 8 yards of cotton for $8.30. Mrs. Sherman pays $7.85 for 3 yards of the silk and 5.5 yards of the cotton. Find the cost per yard of each.

Solution

Let \(s\) = cost per yard of silk, \(c\) = cost per yard of cotton.

System:

$$2s + 8c = 8.30 \quad \text{...(1)}$$ $$3s + 5.5c = 7.85 \quad \text{...(2)}$$

Multiply (1) by 3 and (2) by 2 to eliminate \(s\):

$$6s + 24c = 24.90$$ $$6s + 11c = 15.70$$

Subtract: \(13c = 9.20\), so \(c = \$0.708 \approx \$0.71\).

Hmm, let us be more precise. \(c = \frac{9.20}{13} \approx 0.708\). To avoid rounding issues, substitute back exactly:

From (1): \(2s = 8.30 - 8(0.708) = 8.30 - 5.664 = 2.636\), so \(s \approx 1.318 \approx \$1.32\).

More cleanly in fractions: multiply (1) by 10: \(20s + 80c = 83\). Multiply (2) by 10: \(30s + 55c = 78.5\), then by 2: \(60s + 110c = 157\). Multiply first by 3: \(60s + 240c = 249\). Subtract: \(130c = 92\), giving \(c = \tfrac{92}{130} = \tfrac{46}{65} \approx 0.708\). Then \(s = \tfrac{83 - 80 \cdot \frac{46}{65}}{20} = \tfrac{83 - \frac{3680}{65}}{20} = \tfrac{\frac{5395 - 3680}{65}}{20} = \tfrac{1715}{1300} = \tfrac{343}{260} \approx 1.32\).

Silk costs approximately $1.32 per yard; cotton costs approximately $0.71 per yard.

Problem 5 — Radicals and the Pythagorean Theorem (Ch 11)
Problem

Find the diagonal of a cube whose edge measures 4 inches.

Solution

First find the diagonal of one face. A face is a square with side 4.

$$d_{\text{face}} = \sqrt{4^2 + 4^2} = \sqrt{16 + 16} = \sqrt{32} = 4\sqrt{2}$$

The space diagonal goes from one corner to the opposite corner, using the face diagonal as one leg and the edge as the other:

$$d_{\text{space}} = \sqrt{(4\sqrt{2})^2 + 4^2} = \sqrt{32 + 16} = \sqrt{48} = 4\sqrt{3}$$

Since \(\sqrt{3} \approx 1.732\), the diagonal is approximately \(4(1.732) = 6.93\) inches.

The diagonal of the cube is \(4\sqrt{3} \approx 6.9\) inches.

Problem 6 — Functions and Variation (Ch 12)
Problem

The force \(F\) varies inversely as the square of the distance \(d\). If \(F = 28\) when \(d = 6\), find \(F\) when \(d = 9\).

Solution

Since \(F\) varies inversely as \(d^2\), we write \(F = \dfrac{k}{d^2}\).

Find \(k\): When \(F = 28\) and \(d = 6\):

$$28 = \frac{k}{6^2} = \frac{k}{36} \quad \Rightarrow \quad k = 28 \times 36 = 1008$$

Find \(F\) when \(d = 9\):

$$F = \frac{1008}{9^2} = \frac{1008}{81} = 12\tfrac{4}{9} \approx 12.4$$

\(F = \dfrac{1008}{81} = 12\tfrac{4}{9}\).

Problem 7 — Graphing, Slope, and Inequalities (Ch 5, 9, 10)
Problem

(a) Find the equation of the line parallel to \(3x - y = 2\) and passing through \((2, 4)\).

(b) Graph the solution set of \(x^2 + 2x > 3\).

Solution

Part (a): Rewrite \(3x - y = 2\) in slope-intercept form: \(y = 3x - 2\). The slope is \(m = 3\).

A parallel line has the same slope. Using point-slope form with \((2, 4)\):

$$y - 4 = 3(x - 2) \quad \Rightarrow \quad y = 3x - 2$$

Interestingly, the point \((2, 4)\) lies on the original line: \(3(2) - 4 = 2\) ✓. So the answer is the same line: \(y = 3x - 2\), or equivalently, \(3x - y = 2\).

Part (b): Solve \(x^2 + 2x - 3 > 0\). Factor: \((x + 3)(x - 1) > 0\).

The roots are \(x = -3\) and \(x = 1\). The product is positive when both factors have the same sign:

When \(x < -3\): both negative, product positive ✓

When \(-3 < x < 1\): opposite signs, product negative ✗

When \(x > 1\): both positive, product positive ✓

Solution set: \(\{x \mid x < -3 \text{ or } x > 1\}\). On the number line, shade the rays to the left of \(-3\) and to the right of \(1\), with open circles at \(-3\) and \(1\).

Problem 8 — Trigonometry and Vectors (Ch 14)
Problem

A pilot begins descent 4300 feet from the runway at an altitude of 750 feet. (a) Find the angle of descent to the nearest degree. (b) If a west wind blows at 60 m.p.h. while an airplane heads north at 300 m.p.h., find the resultant speed and direction.

Solution

Part (a): The plane descends from height 750 ft over a distance of 4300 ft. Using the sine ratio (opposite over hypotenuse):

$$\sin \theta = \frac{750}{4300} = 0.1744$$

From the table, \(\sin 10^{\circ} \approx 0.1736\). So \(\theta \approx 10^{\circ}\).

The angle of descent is approximately 10°.

Part (b): The airplane velocity (300 m.p.h. north) and wind velocity (60 m.p.h. east) are perpendicular. The resultant:

$$|\mathbf{V}| = \sqrt{300^2 + 60^2} = \sqrt{90000 + 3600} = \sqrt{93600} \approx 306 \text{ m.p.h.}$$

Direction: \(\tan A = \dfrac{60}{300} = 0.2000\). From the table, \(\tan 11^{\circ} \approx 0.1944\), \(\tan 12^{\circ} \approx 0.2126\). So \(A \approx 11^{\circ}\) east of north.

The airplane flies at approximately 306 m.p.h. at a heading 11° east of north.

Test Preparation

Test Preparation Guide

As the textbook says: “When you climb a mountain trail, you pay close attention to each obstruction until at some moment you pause, look back, and realize how far you have come.” Here are strategies and pitfalls to help you prepare for your final examination.

Study Strategies

Know the Properties Cold

Many test questions ask you to justify each step. Be sure you can name the commutative, associative, distributive, identity, and inverse properties on sight.

Practice Factoring Fluently

Factoring is the gateway to solving quadratics, simplifying fractions, and reducing expressions. Drill all four types:

  • GCF extraction
  • Difference of squares
  • Trinomial squares
  • General trinomials

Draw Diagrams Always

For word problems, geometry, and trigonometry, a sketch will clarify which formula to use and which values you know.

Check Your Answers

Substitute solutions back into the original equation. This catches sign errors, extraneous roots (from squaring both sides), and arithmetic mistakes.

Common Pitfalls to Avoid

Sign Errors with Negatives

Remember: \(-(-a) = a\), and when distributing a negative sign, every term inside changes sign. The most common source of mistakes in all of algebra.

Forgetting to Flip the Inequality

When you multiply or divide both sides of an inequality by a negative number, the direction of the inequality reverses: if \(a > b\) and \(c < 0\), then \(ac < bc\).

Squaring Is Not Distributive

\((a + b)^2 \neq a^2 + b^2\). The correct expansion is \(a^2 + 2ab + b^2\). This error appears in factoring, completing the square, and the Pythagorean theorem.

Division by Zero

Never divide by an expression that could equal zero. When solving fractional equations, always check that your solution does not make a denominator zero.

Extraneous Roots from Squaring

When you square both sides of an equation (radical equations), you may introduce false solutions. Always check by substituting back.

Mixing Up Sin, Cos, and Tan

Use the mnemonic SOH-CAH-TOA: Sin = Opposite/Hypotenuse, Cos = Adjacent/Hypotenuse, Tan = Opposite/Adjacent. Label your triangle before computing.

Final Thought

Mathematics is cumulative. Every new topic rests on what came before. If you find yourself struggling with Chapter 13 or 14, trace back through the roadmap to identify the earlier concept that needs strengthening. A solid grasp of the properties of real numbers and equation-solving techniques will carry you through every challenge ahead.
