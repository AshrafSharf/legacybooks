13-1 Quadratic Equations with Perfect Squares

A quadratic equation can be written in the standard form \(ax^2 + bx + c = 0\), where \(a\), \(b\), and \(c\) are real numbers and \(a \neq 0\). When \(b = 0\), the equation becomes a pure quadratic of the form \(ax^2 + c = 0\), which can be solved directly.

Square-Root Property of Equal Numbers

If \(r\) and \(s\) are real numbers, then \(r^2 = s^2\) if and only if \(r = s\) or \(r = -s\).

$$r^2 = k \quad \Longrightarrow \quad r = \pm\sqrt{k} \quad (k \geq 0)$$

This property also handles equations where one side is a trinomial square. If you recognize that \(t^2 - 6t + 9 = (t-3)^2\), then an equation like \((t-3)^2 = 25\) yields \(t - 3 = \pm 5\), giving \(t = 8\) or \(t = -2\).

Caution

If \(k < 0\), the equation \(x^2 = k\) has no real solutions. For example, \(64x^2 + 1 = 0\) leads to \(x^2 = -\frac{1}{64}\), which is impossible in the real number system.

Sum and Product of Roots

For a quadratic equation \(x^2 + bx + c = 0\) with roots \(r\) and \(s\):

$$r + s = -b \qquad \text{and} \qquad r \cdot s = c$$

This provides a quick check: verify that the sum and product of your answers match \(-b\) and \(c\).

13-2 Completing the Square

Not every quadratic is a pure quadratic. When \(b \neq 0\), we need a method to handle the linear term. Completing the square transforms any equation \(x^2 + bx = k\) into one with a perfect-square trinomial on the left.

The Key Idea

To make \(x^2 + bx\) a perfect square, add \(\left(\frac{b}{2}\right)^2\) to both sides:

$$x^2 + bx + \left(\frac{b}{2}\right)^2 = k + \left(\frac{b}{2}\right)^2$$

$$\left(x + \frac{b}{2}\right)^2 = k + \frac{b^2}{4}$$

Step-by-Step Method

  1. Isolate the variable terms: Move the constant to the right side.
  2. Ensure the leading coefficient is 1: If the coefficient of \(x^2\) is not 1, divide every term by that coefficient.
  3. Complete the square: Take half the coefficient of \(x\), square it, and add to both sides.
  4. Factor the left side as a perfect square.
  5. Apply the square-root property and solve both resulting linear equations.
Example: Completing the Square

Solve \(x^2 + 2x - 8 = 0\).

\(x^2 + 2x = 8\)
\(x^2 + 2x + 1 = 8 + 1\)
\((x + 1)^2 = 9\)
\(x + 1 = \pm 3\)
\(x = 2\)  or  \(x = -4\)

Check: \(2 + (-4) = -2 = -b\) and \(2 \cdot (-4) = -8 = c\). Confirmed.

13-3 The Quadratic Formula

Completing the square on the general quadratic \(ax^2 + bx + c = 0\) produces a universal formula that solves every quadratic equation.

Derivation

Starting from \(ax^2 + bx + c = 0\) with \(a \neq 0\):

\(x^2 + \frac{b}{a}x = -\frac{c}{a}\)

\(x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} = \frac{b^2}{4a^2} - \frac{c}{a}\)

\(\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}\)

\(x + \frac{b}{2a} = \pm \frac{\sqrt{b^2 - 4ac}}{2a}\)

The Quadratic Formula

The solutions of \(ax^2 + bx + c = 0\) (where \(a \neq 0\)) are:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Key Insight

The quadratic formula always works — even when factoring is difficult or impossible. It is the most general method for solving any quadratic equation. The expression under the radical, \(b^2 - 4ac\), is called the discriminant and determines the nature of the roots.

13-4 The Discriminant

The quantity \(\Delta = b^2 - 4ac\) under the square root in the quadratic formula completely determines what kind of roots the equation has, without solving it.

Definition: The Discriminant

For the quadratic equation \(ax^2 + bx + c = 0\), the discriminant is:

$$\Delta = b^2 - 4ac$$

Three Cases

  • If \(\Delta > 0\): Two distinct real roots. The parabola crosses the \(x\)-axis at two points.
  • If \(\Delta = 0\): One repeated real root (a double root). The parabola touches the \(x\)-axis at its vertex.
  • If \(\Delta < 0\): No real roots. The parabola does not intersect the \(x\)-axis.

Furthermore, if \(a\), \(b\), \(c\) are rational and \(\Delta\) is a perfect square, then both roots are rational.

Figure 13-1. The discriminant determines how a parabola meets the x-axis.
Example: Using the Discriminant

Determine the nature of the roots of \(2x^2 - 3x + 5 = 0\).

\(\Delta = (-3)^2 - 4(2)(5) = 9 - 40 = -31\)

Since \(\Delta < 0\), the equation has no real roots.

13-5 Graphing Quadratic Equations

The graph of \(y = ax^2 + bx + c\) (with \(a \neq 0\)) is a parabola — a smooth U-shaped curve. Every parabola has a vertex (turning point) and an axis of symmetry (a vertical line through the vertex).

Vertex and Axis of Symmetry

For \(y = ax^2 + bx + c\):

Axis of symmetry: \(\displaystyle x = -\frac{b}{2a}\)

Vertex: \(\displaystyle \left(-\frac{b}{2a},\; c - \frac{b^2}{4a}\right)\)

If \(a > 0\), the parabola opens upward (vertex is a minimum). If \(a < 0\), it opens downward (vertex is a maximum).

Figure 13-2. Key features of the parabola \(y = ax^2 + bx + c\) when \(a > 0\).
Key Insight

Because of symmetry, the axis of symmetry is always halfway between the two roots (if they exist). The vertex lies on this axis, so its \(x\)-coordinate is \(x = \frac{r_1 + r_2}{2} = -\frac{b}{2a}\).

13-6 Solving Problems with Quadratic Equations

Many real-world situations — areas, distances, projectile motion, rates of work — lead to quadratic equations. The general approach is:

Problem-Solving Strategy

  1. Read carefully and identify the unknown quantity. Assign it a variable.
  2. Translate the word problem into a quadratic equation.
  3. Solve using factoring, completing the square, or the quadratic formula.
  4. Check each solution against the original problem — reject any root that does not make sense in context (for example, a negative length).
  5. State the answer clearly.
Caution

Always check whether both roots are valid in the context of the problem. A quadratic equation may have two mathematical solutions, but the problem's constraints (positive length, non-negative time, etc.) may rule one out.

13-7 Quadratic Inequalities

A quadratic inequality has the form \(ax^2 + bx + c > 0\), \(ax^2 + bx + c < 0\), or their non-strict counterparts. Solving them combines finding the roots of the corresponding equation with sign analysis.

Method: Solving Quadratic Inequalities
  1. Solve the corresponding equation \(ax^2 + bx + c = 0\) to find the critical values (roots).
  2. Divide the number line into intervals using the roots.
  3. Test each interval: substitute a value from each interval into the inequality to determine where it is satisfied.
  4. Write the solution set.
Key Insight

For \(a > 0\): the parabola opens upward, so \(ax^2 + bx + c > 0\) outside the roots and \(ax^2 + bx + c < 0\) between the roots. For \(a < 0\): the opposite holds.

Example: Quadratic Inequality

Solve \(x^2 - 5x + 6 > 0\).

Step 1. Solve \(x^2 - 5x + 6 = 0\): roots are \(x = 2\) and \(x = 3\).

Step 2. Test intervals: for \(x < 2\), try \(x = 0\): \(6 > 0\) (true). For \(2 < x < 3\), try \(x = 2.5\): \(6.25 - 12.5 + 6 = -0.25 < 0\) (false). For \(x > 3\), try \(x = 4\): \(16 - 20 + 6 = 2 > 0\) (true).

Solution: \(x < 2\) or \(x > 3\), i.e., \(\{x \mid x < 2 \text{ or } x > 3\}\).

Worked Problems

Problem 1: Solving a Pure Quadratic

Solve \(3x^2 - 75 = 0\).

Step 1:\(3x^2 = 75\)Add 75 to both sides
Step 2:\(x^2 = 25\)Divide both sides by 3
Step 3:\(x = \pm 5\)Square-root property
Solution

The solution set is \(\{-5,\; 5\}\).

Check: \(3(5)^2 - 75 = 75 - 75 = 0\).   \(3(-5)^2 - 75 = 75 - 75 = 0\). Confirmed.

Problem 2: Completing the Square

Solve \(3x^2 - 2x - 9 = 0\) by completing the square.

Step 1:\(x^2 - \frac{2}{3}x - 3 = 0\)Divide every term by 3
Step 2:\(x^2 - \frac{2}{3}x = 3\)Move constant to right side
Step 3:\(x^2 - \frac{2}{3}x + \frac{1}{9} = 3 + \frac{1}{9}\)Add \(\left(\frac{1}{3}\right)^2 = \frac{1}{9}\) to both sides
Step 4:\(\left(x - \frac{1}{3}\right)^2 = \frac{28}{9}\)Factor left; combine right
Step 5:\(x - \frac{1}{3} = \pm \frac{2\sqrt{7}}{3}\)Square-root property
Step 6:\(x = \frac{1 \pm 2\sqrt{7}}{3}\)Add \(\frac{1}{3}\) to both sides
Solution

The solution set is \(\left\{\dfrac{1 + 2\sqrt{7}}{3},\; \dfrac{1 - 2\sqrt{7}}{3}\right\}\).

Problem 3: Using the Quadratic Formula

Solve \(2x^2 + 5x - 3 = 0\).

Identify:\(a = 2, \; b = 5, \; c = -3\)Standard form coefficients
Formula:\(x = \dfrac{-5 \pm \sqrt{25 - 4(2)(-3)}}{2(2)}\)Substitute into formula
Simplify:\(x = \dfrac{-5 \pm \sqrt{25 + 24}}{4}\)Evaluate under the radical
\(x = \dfrac{-5 \pm \sqrt{49}}{4} = \dfrac{-5 \pm 7}{4}\)\(\sqrt{49} = 7\)
Solve:\(x = \dfrac{-5 + 7}{4} = \dfrac{1}{2}\)  or  \(x = \dfrac{-5 - 7}{4} = -3\)Two linear equations
Solution

The solution set is \(\left\{-3,\; \frac{1}{2}\right\}\).

Check (sum/product): \(-3 + \frac{1}{2} = -\frac{5}{2} = -\frac{b}{a}\).   \(-3 \cdot \frac{1}{2} = -\frac{3}{2} = \frac{c}{a}\). Confirmed.

Problem 4: Quadratic Formula with Irrational Roots

Solve \(x^2 + 6x - 1 = 0\).

Identify:\(a = 1, \; b = 6, \; c = -1\)
Discriminant:\(\Delta = 36 - 4(1)(-1) = 36 + 4 = 40\)Positive: two real roots
Formula:\(x = \dfrac{-6 \pm \sqrt{40}}{2}\)Substitute
Simplify:\(x = \dfrac{-6 \pm 2\sqrt{10}}{2} = -3 \pm \sqrt{10}\)\(\sqrt{40} = 2\sqrt{10}\)
Solution

The solution set is \(\{-3 + \sqrt{10},\; -3 - \sqrt{10}\}\).

Check: Sum \(= -6 = -b\). Product \(= (-3)^2 - (\sqrt{10})^2 = 9 - 10 = -1 = c\). Confirmed.

Problem 5: Using the Discriminant

Without solving, determine the nature of the roots of \(4x^2 - 12x + 9 = 0\).

Identify:\(a = 4, \; b = -12, \; c = 9\)
Discriminant:\(\Delta = (-12)^2 - 4(4)(9) = 144 - 144 = 0\)
Conclusion:Since \(\Delta = 0\), there is exactly one double root.
Solution

The equation has one real, rational double root. (In fact, \(4x^2 - 12x + 9 = (2x - 3)^2 = 0\), so \(x = \frac{3}{2}\).)

Problem 6: Application — Area Problem

A rectangular garden is 3 meters longer than it is wide. Its area is 88 square meters. Find its dimensions.

Setup:Let \(w\) = width. Then length = \(w + 3\).
Equation:\(w(w + 3) = 88\)Area = length × width
Expand:\(w^2 + 3w - 88 = 0\)Standard form
Formula:\(w = \dfrac{-3 \pm \sqrt{9 + 352}}{2} = \dfrac{-3 \pm \sqrt{361}}{2}\)Quadratic formula
Simplify:\(w = \dfrac{-3 \pm 19}{2}\)\(\sqrt{361} = 19\)
Solve:\(w = \dfrac{16}{2} = 8\)  or  \(w = \dfrac{-22}{2} = -11\)
Reject:\(w = -11\) (width cannot be negative)
Solution

The garden is 8 meters wide and 11 meters long.

Check: \(8 \times 11 = 88\) square meters and \(11 - 8 = 3\) meters. Confirmed.
